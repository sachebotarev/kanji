**Кандзи дэс нэ** — Android-приложение для изучения японских иероглифов. Каталог учебников, личный словарь и тренировка с рукописным вводом. Проверка формы и читаемости выполняется на устройстве, без обязательного интернета.

Интерфейс и переводы ориентированы на **русскоязычных** учеников; английская локализация тоже есть.

## Возможности

- **Главная** — прогресс, активность, быстрый запуск тренировки.
- **Каталог** — учебники, главы, кандзи, ключи и слова с переводами.
- **Мой словарь** — свои слова и выражения; в пустом списке — подсказка и добавление через общую кнопку экрана.
- **Практика** — поле для письма, подсказки, таймер, настройки проверки (форма, читаемость, порядок штрихов).
- **Офлайн** — эталоны KanjiVG и учебный контент в assets приложения.

## Дизайн каталога

Обновлённый макет каталога синхронизирован с текущим Android-приложением. Все 17 экранов переданы на повторное согласование и имеют статус «Не согласовано». Изменения и статусы показаны в [интерактивном макете](doc/design-system/prototypes/textbooks/index.html), [обзоре экранов](doc/design-system/05-screens/catalog/review/index.html) и [едином реестре](doc/design-system/05-screens/catalog/review-status.json). [Инструкция запуска](doc/design-system/prototypes/textbooks/README.md).

Нативный каталог использует отдельную палитру, фильтры числа черт и JLPT, языковые примечания, классификации кандзи и отрисовку KanjiVG. Просмотр, подробности и выбор фильтров имеют отдельные типизированные состояния и ViewModel. [Устройство каталога](doc/decisions/catalog-presentation.md), [контракт интерфейса](doc/implementation/catalog-ui.md), [проверки Android](doc/verification/catalog/refactor-2026-11-02/README.md).

База рассчитана на чистую установку без миграций. Тесты и снимки подтверждают перечисленные сценарии, но не заменяют пользовательское согласование обновлённого дизайна. Остальные разделы сохраняют собственные статусы.

## Сборка

Нужны **Android Studio** (или SDK + JDK 21), Gradle из wrapper проекта:

```bash
./gradlew :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/`.
