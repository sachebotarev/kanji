# Кандзи дэс нэ

<p align="center">
  <img src="doc/readme-icon-transparent.png" alt="Иконка приложения — кот в ученической шапке" width="220">
</p>

**«Кандзи дэс нэ»** — мобильное Android-приложение для изучения японских иероглифов и лексики. Сочетает структурированный каталог учебников, персональный словарь и интерактивные рецепты с рукописным вводом.

Проверка формы и порядка черт выполняется на устройстве. Японская модель читаемости ML Kit скачивается один раз; пока её нет, форма и порядок черт всё равно дают вердикт, а читаемость остаётся недоступной. После загрузки распознавание идёт на устройстве. Состояние модели показано в настройках: загрузка, готова, нужна повторная загрузка.

Интерфейс, подсказки и переводы ориентированы прежде всего на **русскоязычную аудиторию** (с доступной английской локализацией).

## Ключевые возможности

- **Главная панель (Dashboard):** сводка прогресса, следы тренировок и серия дней, управление рецептами и быстрый старт тренировки.
- **Каталог учебных материалов:** иерархия «Учебник → Глава → Кандзи / Слова», фильтрация по числу черт, уровням JLPT, ключам и учебникам. Поиск и фильтры разделены по вкладкам и сохраняются при смене языка; успешные изменения личного словаря обновляют открытые экраны каталога.
- **Мой словарь:** сохранение персональных слов, выражений и предложений с транзакционным хранением в локальной базе данных.
- **Интерактивная практика:** холст рукописного ввода с плавным сглаживанием, анимированные подсказки порядка штрихов, настраиваемый таймер и алгоритмическая проверка написания (Procrustes + ML Kit Digital Ink + словарные правила).
- **Полная автономность:** база эталонов KanjiVG и начальный учебный пакет встроены в приложение.

## Архитектура и дизайн

Приложение построено на базе **Clean Architecture** и **Jetpack Compose**:
- **19 Gradle-модулей:** строгое разделение на уровни `:core:*`, `:data:*`, `:domain:*` и `:feature:*`.
- **Локальное хранение:** Room (`kanji.db`, схема 13), многоязычные переводы (`_translations`), личные записи, теги, рецепты и тренировки. Переход 12→13 сохраняет данные и добавляет хранение мягко принятой формы. Более старые неподдержанные схемы до выпуска заменяются с повторной загрузкой каталога. [Решение о допуске и миграции](doc/decisions/shape-soft-acceptance.md).
- **Дизайн-система:** собственные токены типографики и цветов в светлой и тёмной темах на основе Material 3.

## Сборка и разработка

### Требования к окружению

- **JDK 21** (рекомендуется JetBrains Runtime / OpenJDK 21)
- **Android SDK:** Compile SDK 37, Target SDK 37, Min SDK 24
- Настроенные переменные среды:
  ```bash
  export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"  # macOS
  export ANDROID_HOME="$HOME/Library/Android/sdk"
  ```

### Основные команды Gradle

- **Сборка Debug APK:**
  ```bash
  ./gradlew :app:assembleDebug
  ```
  Итоговый APK: `app/build/outputs/apk/debug/app-debug.apk`.

- **Запуск всех модульных тестов (JVM):**
  ```bash
  ./gradlew testDebugUnitTest
  ```

- **Статический анализ кода (Android Lint):**
  ```bash
  ./gradlew lintDebug
  ```

- **Статический анализ Kotlin (detekt):**
  ```bash
  ./gradlew detekt
  ```
  Проверяет исходники всех модулей и также входит в задачи `check`. Новые замечания за пределами baseline завершают проверку ошибкой. HTML-отчёт: `build/reports/detekt/detekt.html`. Полный аудит с существующими замечаниями: `./gradlew detektAll`, отчёты — в `build/reports/detekt-all/`. [Правила, baseline и ограничения анализа](doc/decisions/detekt.md).

## Реализация и дизайн-макет

Интерфейс приложения построен на Jetpack Compose с соблюдением дизайн-системы на базе Material 3 ([реестр экранов](doc/design-system/theme/screens.json), [карта проекта](doc/project-map.md)).

### Реализованные модули:

- **Главная панель (`HOME`):** сводка прогресса дня, серия дней активности, навигационные карточки в разделы «Учебники», «Справочники», «Мой словарь» и «Рецепты тренировок».
- **Каталог учебных материалов (`BOOKS` & `REFS`):** учебники с разбивкой по главам, общие справочники кандзи и ключей, фильтрация по числу черт, уровням JLPT и ключам с сохранением состояния фильтров.
- **Мой словарь (`DICT`):** персональный словарь с поддержкой отдельных слов, выражений и предложений; многоязычные переводы по тегам языков (`language_tag`), локализованные пользовательские теги со стабильными цветами, полноэкранный поиск и валидация.
- **Конструктор рецептов (`RECIPE`):** создание, редактирование, дублирование, удаление и сортировка рецептов перетаскиванием (Android Drag and Drop); гибкое комбинирование материалов четырёх типов (учебник, словарь, кандзи, точные слова), настройка подсказок в задании («Без подсказок» по умолчанию) и параметров тренировки.
- **Настройки (`SETTINGS`):** независимый экран параметров хода тренировки (автопереход к следующему кандзи и к следующему слову, оба по умолчанию включены), подсказок (лимит подсказок и таймер эталона), независимых чекеров (читаемость, письмо, форма знака) и управления японской моделью ML Kit; подтверждение очистки истории. Калибровка формы кандзи (`SETTINGS.01`) доступна в develop/debug-сборках.
- **Практика и тренировки (`PRACTICE`):** рукописный холст, миниатюры знаков, чтение и перевод, подсказки и таймер. Заголовок — «Задание N из M». Помощь в строке проверок показывает общий счётчик использованных подсказок задания `0/3…3/3` (подсказки слов заголовка + подсказки черт/знака): после принятия без помощи — зелёная, частичный расход — жёлтый, полный расход — красный. При исчерпании лимита помощь заканчивается без блокировки ввода, самостоятельное письмо продолжается. Форма с недобором меньше настроенного допуска (по умолчанию 10 п.п.) до порога принимается со штрафом 20% (множитель 0.8), отображается жёлтой и делает «Далее» жёлтой; «Знак» и «Черты» остаются строгими. Детали остатка и понятные причины снижения оценки доступны в диалогах по клику на показатели. Автопереход к следующему знаку и к следующему заданию включён по умолчанию и не блокируется подсказками; приостанавливается только исправимыми неточностями (форма со штрафом оставляет знак выбранным для перерисовки и требует ручного нажатия «Далее»), ошибкой или таймаутом. Итог `PRACTICE.01` показывает процент, статистику и маскота. [Оценка](doc/implementation/hint-scoring.md), [допуск формы](doc/decisions/shape-soft-acceptance.md).
