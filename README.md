## Зачем это вообще

Память на «一、二、三» держится ровно до первой встречи с реальным текстом. **Кандзи дэс нэ** заточено под практику: смотреть знак, писать его пальцем, сразу понимать, попали вы в форму или пока «похоже на правду, но нет». Без очереди в облако и без ощущения, что приложение вас оценивает как на экзамене в Todai — хотя стремиться можно сколько угодно.

Наш маскот — кремовый кот в ученической шапке. Он машет лапой на главной, ищет с лупой в пустом словаре и в целом на вашей стороне. Проверку штрихов он не подменяет: за математику отвечают алгоритмы, за настроение — кот.

## Что уже умеет

| | |
| --- | --- |
| **Главная** | Сводка прогресса, активность, быстрый старт тренировки — «Ня! Начнём?» не просто так. |
| **Каталог** | Учебники, главы, кандзи, ключи и слова — всё в одном месте, с переводами под ваш язык. |
| **Мой словарь** | Свои слова, фразы и предложения; пустой список не пугает пустотой — там кот-детектив и кнопка «Добавить слово». |
| **Практика** | Поле для рукописного ввода, подсказки, таймер, настройки проверки — форма, читаемость и порядок штрихов по вашим правилам. |
| **Офлайн** | Эталоны и учебный контент живут на устройстве; учиться можно в метро, где «пять палочек» у оператора — не про кандзи. |

## Для кого

- Начинающим и тем, кто уже прошёл первый учебник, но хочет **писать**, а не только узнавать.
- Русскоязычным ученикам — интерфейс и подстановки переводов сделаны с приоритетом на русский.
- Тем, кому важны **честная обратная связь** по почерку и аккуратный тёмно-зелёный интерфейс без визуального шума.

## Статус

Проект в **активной разработке**: функции появляются по мере готовности, документация и макеты лежат в [`doc/`](doc/README.md). Это не «ещё один словарь в списке» — это учебник, который смотрит на ваш палец и честно кивает или мягко поправляет.

## Разработчикам

Стек: **Kotlin**, **Jetpack Compose**, **Material 3**, модульная Clean Architecture. Подробности — в [архитектурных требованиях](doc/architecture.md) и [документации](doc/README.md).

Сборка — обычный Android-проект (Gradle). JDK и Android SDK — как в Android Studio; мы не изобретаем отдельную вселенную, только кандзи.
