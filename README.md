# Кандзи дэс нэ

<p align="center">
  <img src="doc/readme-icon-transparent.png" alt="Иконка приложения — кот в ученической шапке" width="220">
</p>

**«Кандзи дэс нэ»** — мобильное Android-приложение для изучения японских иероглифов и лексики. Сочетает структурированный каталог учебников, персональный словарь и интерактивные тренировки с рукописным вводом.

Проверка написания кандзи (геометрическая форма штрихов и распознавание) выполняется полностью на устройстве — приложение не требует постоянного подключения к интернету.

Интерфейс, подсказки и переводы ориентированы прежде всего на **русскоязычную аудиторию** (с доступной английской локализацией).

## Ключевые возможности

- **Главная панель (Dashboard):** сводка прогресса, серия дней непрерывных занятий, управление тренировочными наборами и быстрый старт практики.
- **Каталог учебных материалов:** иерархия «Учебник → Глава → Кандзи / Слова», фильтрация по числу черт, уровням JLPT, ключам и учебникам. Поиск и фильтры разделены по вкладкам и сохраняются при смене языка; успешные изменения личного словаря обновляют открытые экраны каталога.
- **Мой словарь:** сохранение персональных слов, выражений и предложений с транзакционным хранением в локальной базе данных.
- **Интерактивная практика:** холст рукописного ввода с плавным сглаживанием, анимированные подсказки порядка штрихов, настраиваемый таймер и алгоритмическая проверка написания (Procrustes + ML Kit Digital Ink + словарные правила).
- **Полная автономность:** база эталонов KanjiVG и начальный учебный пакет встроены в приложение.

## Архитектура и дизайн

Приложение построено на базе **Clean Architecture** и **Jetpack Compose**:
- **19 Gradle-модулей:** строгое разделение на уровни `:core:*`, `:data:*`, `:domain:*` и `:feature:*`.
- **Локальное хранение:** библиотека Room (`learning.db`, версия схемы 4) с поддержкой многоязычности (`_translations`) и защитой пользовательских записей.
- **Дизайн-система:** собственные токены типографики и цветов в светлой и тёмной темах на основе Material 3.

## Сборка и разработка

### Требования к окружению

- **JDK 21** (рекомендуется JetBrains Runtime / OpenJDK 21)
- **Android SDK:** Compile SDK 37, Target SDK 37, Min SDK 24
- Настроенные переменные среды:
  ```bash
  export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"  # macOS
  export ANDROID_HOME="$HOME/Library/Android/sdk"
  ```

### Основные команды Gradle

- **Сборка Debug APK:**
  ```bash
  ./gradlew :app:assembleDebug
  ```
  Итоговый APK: `app/build/outputs/apk/debug/app-debug.apk`.

- **Запуск всех модульных тестов (JVM):**
  ```bash
  ./gradlew testDebugUnitTest
  ```

- **Статический анализ кода (Android Lint):**
  ```bash
  ./gradlew lintDebug
  ```

- **Статический анализ Kotlin (detekt):**
  ```bash
  ./gradlew detekt
  ```
  Проверяет исходники всех модулей и также входит в задачи `check`. Новые замечания за пределами baseline завершают проверку ошибкой. HTML-отчёт: `build/reports/detekt/detekt.html`. Полный аудит с существующими замечаниями: `./gradlew detektAll`, отчёты — в `build/reports/detekt-all/`. [Правила, baseline и ограничения анализа](doc/decisions/detekt.md).

## Дизайн-макет и конструктор тренировок

Все 17 экранов каталога **согласованы пользователем 2026-11-03**; остальные 11 экранных вариантов ожидают согласования. В [едином просмотрщике](doc/design-system/prototypes/index.html#home) главная, практика, словарь, конструктор и настройки используют общую светлую/тёмную тему Material 3. [Тема приложения](doc/design-system/prototypes/index.html#theme) позволяет менять Primary, Secondary, Tertiary и Error сразу во всём просмотрщике, экспортировать JSON и сбрасывать черновик.

[Конфигурация темы](doc/design-system/theme/theme-source.json) и [статусы экранов](doc/design-system/theme/screens.json) отделены от JavaScript экранов. [Инструкция](doc/design-system/theme/README.md), [проверки и галерея](doc/verification/material-theme/README.md). Общая Android-тема и 17 экранов каталога используют текущую систему Material 3: вертикальные карточки слов, компактный выбор глав, квадратную ячейку написания и четыре тональные заливки ключей. Проверки качества не заменяют пользовательскую приёмку; статус согласования не меняется автоматически. [Поведение каталога](doc/implementation/catalog-ui.md), [проверки переноса](doc/verification/catalog/material-implementation.md). Остальные разделы просмотрщика не означают завершённую Android-реализацию соответствующих макетов.

В [конструкторе](doc/design-system/prototypes/index.html#training-builder) доступны 10 демонстрационных рецептов, создание, подробности, изменение, дублирование, выбор и удаление. Источники объединяют учебники, главы, отдельные слова и слова с заданными кандзи/JLPT. Число заданий независимо от объёма набора, порядок повторения и таймер на слово настраиваются. [Модель хранения](doc/database/trainings.md), [контракт](doc/design-system/05-screens/training-builder.md). Сохранение живёт в памяти браузера; Android-конструктор, миграция БД, запуск составленных сессий и таймер ещё не подключены.
