В БД данные пока не импортированы. Отдельная копия CSV в `doc/` не поддерживается.

## Формат

- UTF-8 с BOM; при чтении использовать `utf-8-sig`.
- Разделитель столбцов — `|`, кавычка — `"`. Нужен полноценный CSV-парсер: внутри заключённых в кавычки ячеек чтений также встречается `|`.
- 7 столбцов; первоначально 2005 строк данных. Текущее состояние очистки описано ниже.

| CSV column | Целевые данные |
| --- | --- |
| `Слово кандзи` | `words.written_form` |
| `Чтение слова` | `words.reading` |
| `Изучаемый кандзи` | Поиск `kanji.id` по исходному символу; связь в `source_kanji` и `source_words` |
| `Номер кандзи в Tobira` | `source_kanji.kanji_number` |
| `Глава в Tobira` | Число главы → `source_kanji.chapter_number`; оба тома относятся к одному источнику `Tobira` |
| `Чтение по кандзи` | Проверенное разбиение → `word_reading_parts` |
| `Перевод на русский` | `words_translations.translation`, `language_tag = 'ru'` |

## Результаты первичного осмотра

- 1581 уникальное написание, 1604 уникальные пары написания и чтения.
- 329 изучаемых кандзи, 18 обозначений глав: Tobira I, главы 3–10; Tobira II, главы 11–20.
- 367 пар написания и чтения встречаются более одного раза.
- В 18 парах различаются русские переводы; требуется согласование без молчаливой перезаписи.
- 48 строк не содержат разбиения чтения. Для повторяющихся пар заполнение разбиения не конфликтует.
- Разбиение может включать кану рядом с кандзи: `お正月 → おしょう|がつ`, `男の子 → おとこの|こ`. Прямое сопоставление «один элемент = один символ» недопустимо; части написания требуют проверки.
- Обнаружен один повтор полной связи «написание, чтение, изучаемый кандзи, номер, глава». При импорте повторная связь не создаётся.

## Очистка 20 октября 2026 года

Удалены 49 строк с заполнителями `～`: незавершённые слова, суффиксы и грамматические шаблоны.

По указанию пользователя 76 строк (59 разных записей со скобками) приведены к словарной форме: `大切（な） → 大切`, `食事（を）する → 食事する`, `次々（に） → 次々`. Чтения и их разбиение изменены согласованно. Скобок в написаниях больше нет. Вежливая форма `来ます` объединена с существующей записью `来る / くる` с той же учебной привязкой.

После уточнения назначения словаря восстановлены формы `来ない`, `住んでいる`, `知っている`, ранее объединённые с исходными глаголами. Они сохраняют самостоятельный учебный смысл и перевод. Словарь допускает не только отдельные слова, но также выражения и полные предложения; наличие частиц или окончаний не является основанием для удаления.

Осталось 1955 строк. Полные исходные записи, изменения и причины удаления или восстановления сохранены в [журнале очистки](cleanup-2026-10-20.json). Фамилии с `さん` сохранены по явному указанию пользователя; обычные слова родства и `赤ちゃん` также сохранены. Самостоятельные фразы, включая `本当ですか`, сохраняются как допустимые учебные записи. Устойчивые выражения `仕方がない`, `元気がない` не подвергаются механическому преобразованию. Остальные записи не объединялись.

Модель и правила объединения: [словарь слов и источники](../../database/words.md).

Пять переводов (`お手洗い`, `予習する`, `困難`, `授業`, `泣き声`) согласованы с Basic Kanji Book: [формулировки и журнал изменений](../basic-kanji-book/README.md#согласование-пяти-переводов-с-tobira).

## Согласование внутренних переводов

20 октября 2026 года согласованы все 20 пар с разными переводами внутри Tobira: `二日`, `三日`, `私立`, `生活`, `大変`, `地下`, `体験する`, `次回`, `聞く`, `荷物`, `分野`, `最後`, `意思`, `最高`, `両親`, `自由`, `絵`, `最初`, `駅`, `幸せ`. Изменения перенесены на совпадающие записи Basic Kanji Book. Всего на этом этапе изменено 47 строк двух CSV; количество записей, чтения и учебные привязки сохранены.

Для дат сохранены длительность и календарное значение (`二日` — «два дня; второе число месяца»), для слов с несколькими частями речи — оба употребления (`自由` — «свобода; свободный», `幸せ` — «счастье; счастливый»). Синонимичные формулировки приведены к одному варианту без автоматического выбора первого перевода.

[Полный список переводов и журнал изменений](../basic-kanji-book/translation-resolution.json). Проверено: для каждой пары «написание + чтение» перевод един во всех строках обоих CSV. Это редакционная согласованность, а не гарантия единственного японского ответа по русской подсказке.
