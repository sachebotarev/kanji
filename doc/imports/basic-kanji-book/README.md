# Basic Kanji Book: словарь обоих томов

Дата подготовки: 20 октября 2026 года.

Итог: [`data/catalog/basic-kanji-book.csv`](../../../data/catalog/basic-kanji-book.csv). Это подготовленный учебный набор для последующего импорта, а не постраничная транскрипция конкретного издания. Основа — лексика обоих томов из наиболее оценённой найденной колоды, дополненная примерами из официальных списков изменений издателя. Старая лексика, исключённая из нового издания, не удаляется, если она остаётся полезной и законченной учебной записью.

## Состав и формат

- 2003 строки связей, 1716 уникальных пар «написание + чтение».
- Том I: 988 строк, главы 1–22; том II: 1015 строк, главы 23–45.
- 500 изучаемых символов: 499 кандзи и знак повтора `々`. Нумерация общая: 1–500; том I заканчивается №251, том II начинается с №252.
- UTF-8 с BOM, разделитель `|`, стандартное CSV-экранирование кавычками `"`, LF. Внутреннее разбиение чтения также использует `|`, поэтому сначала требуется CSV-парсер.
- У 2001 строки заполнено разбиение чтения. Для `小人 / こども` и `風邪 / かぜ` оставлено пустым: искусственное распределение чтения по отдельным символам не выполняется. Некоторые заполненные части относятся к группе символов, а не ровно одному кандзи.

Семь столбцов соответствуют структуре Tobira; название источника в двух заголовках заменено на Basic Kanji Book:

| CSV column | Назначение |
| --- | --- |
| `Слово кандзи` | Слово, выражение или предложение. |
| `Чтение слова` | Полное чтение. Несколько чтений одной исходной карточки разделены на отдельные записи. |
| `Изучаемый кандзи` | Символ, к которому привязана запись. Для согласованного исключения допускается `々`. |
| `Номер кандзи в Basic Kanji Book` | Номер изучаемого символа в книге. |
| `Глава в Basic Kanji Book` | Том и глава. |
| `Чтение по кандзи` | Упорядоченные части чтения; кана рядом с кандзи может входить в его часть. |
| `Перевод на русский` | Краткая подсказка для восстановления японской записи, с контекстом или уточнением чтения при необходимости. |

При импорте оба тома относятся к одному источнику `Basic Kanji Book`. Сквозной номер символа сохраняется в `source_kanji.kanji_number`, число главы — отдельно в `source_kanji.chapter_number`; оба поля числовые. Каждый символ изучается в источнике один раз. Текст с томом и подписью главы остаётся исходным форматом CSV, а не форматом хранения в БД.

Одно слово может повторяться в строках разных изучаемых кандзи. Это разные учебные связи, а не дубли словаря. Перевод для одной пары написания и чтения внутри итогового файла одинаковый.

## Источники вне Anki

1. [Материалы издателя Bonjinsha](https://publishing.bonjinsha.co.jp/support/bkb): официальные списки изменений примеров для обоих томов. По ним добавлены конкретные примеры с явной привязкой к номеру кандзи; они отмечены `publisher_revision_list` в журнале происхождения. Включение изменений не означает полного соответствия лексике последнего издания.
2. [Университет Кюсю: том I](https://contsrv.icer.kyushu-u.ac.jp/web/QKANJI/index_vol1.html) и [том II](https://contsrv.icer.kyushu-u.ac.jp/web/QKANJI/index_vol2.html): получены все 45 списков уроков, проверены 500 номеров. В университетском списке №360 записан как `倒`; в выбранной колоде — `到`. Для набора оставлено `到`, соответствующее словам `到達する`, `到着する`, `到る`; расхождение явно сохранено, а не скрыто нормализацией. Дополнительное подтверждение №360: [учебная выписка по главам 29–34](https://www.studocu.vn/vn/document/truong-dai-hoc-ngoai-ngu-dai-hoc-da-nang/csvh22cna/basic-kanji-book-vol-2-bai-29-34-kanji-nghia-tieng-viet/130672412).
3. [Mohammad Akhlaghi: Japanese Vocabulary](https://www.astr.tohoku.ac.jp/~akhlaghi/blog/JapaneseVocab.html): независимые CSV первого тома и части второго. Сравнение пар записано в [sources.json](sources.json). В источнике встречаются вежливые глагольные формы и собственные опечатки, поэтому его строки не добавлялись автоматически.
4. [JMdict через jmdict-simplified](https://github.com/scriptin/jmdict-simplified): русские словарные подсказки для проверки, выпуск `3.6.2+20261019180022`. Краткие переводы подготовлены редакционно, часть точно совпавших записей использует уже принятые переводы Tobira. Полные статьи словаря не включены в assets.
5. [JmdictFurigana](https://github.com/Doublevil/JmdictFurigana): выпуск `2.3.1+2026-09-25`, источник разбиения чтений. Для форм с буквальными окончаниями `する`, `な`, `の` допускается подтверждённая словарная основа с присоединением окончания. Отдельные имена и выражения сегментированы редакционно. Источник и ручные дополнения отражены в [reading-parts.json](reading-parts.json).

Дополнительно осмотрены [Tanoshii Japanese](https://www.tanoshiijapanese.com/lists/collection_display.cfm?collection_id=33), [KanjiBox](https://kanjibox.net/kb/set/45/name/basic_kanji_book_vol_1) и [KanjiDraw](https://kanjidraw.com/collections/basic-kanji-book-1/). Они не стали основой: неполный охват, отсутствие точной привязки или замеченные несогласованности. Например, на видимой странице KanjiDraw встречается `お金 / かね`; такое чтение не соответствует полному написанию. Данные этих сайтов в итоговый CSV не копировались.

## Исправления и ограничения проверки

В [validation.json](validation.json) записаны 12 исправленных исходных записей:

- Три неверных чтения: `遠い / とい → とおい`, `指す / ゆす → さす`, `お手洗い / おてらい → おてあらい`.
- Два незавершённых написания: `小さ → 小さい`, `大き → 大きな`.
- Три несоответствия чтения написанию: удалено лишнее `な` у `大切`, `困難`, `便利`.
- Удалён посторонний пробел в `結婚 する`; цифровое `２たい３` заменено полным чтением `にたいさん`.
- Две ошибочные привязки главы: `位` перенесено из метки 39 в главу 40, `全く` из метки 44 в главу 45, согласно главе изучения записанного кандзи. Это исправленные связи набора, не подтверждение первого появления слова на странице книги.

17 исходных карточек с незавершёнными заполнителями `～` исключены. Полные глаголы `賛成する` и `賛同する` включены по официальному списку изменений, без заполнителя. Законченные слова, выражения и предложения не удалялись только из-за длины, частиц или грамматической формы.

Одна запись `鳴く / なく` не включена в основной CSV и сохранена в разделе `held_for_review`: в колоде указан урок 36, где изучается `泣`, а `鳴` в основной список 500 символов не входит. Подменять один кандзи другим без подтверждения нельзя. В наборе остаётся корректное `泣く / なく` — «плакать».

**Большинство связей «слово → изучаемый кандзи» восстановлено по метке главы колоды и буквальному наличию кандзи этой главы в слове.** Если подходящих кандзи несколько, сохраняются несколько связей. Они не выдаются за точное расположение примеров под заголовками кандзи в печатной книге. Прямые привязки из официальных изменений отмечены отдельно. Происхождение каждой строки: [provenance.json](provenance.json).

Переводы прошли редакционную подготовку и сопоставление со словарными подсказками, но не заявляются как полностью проверенные преподавателем или как гарантия единственного возможного японского ответа. Где важны чтение, написание или контекст, в подсказках есть уточнения.

### Согласование пяти переводов с Tobira

В обоих CSV приняты единые формулировки:

| Запись | Русская подсказка |
| --- | --- |
| `お手洗い / おてあらい` | туалет — вежливое название |
| `予習する / よしゅうする` | готовиться к предстоящему уроку |
| `困難 / こんなん` | трудный, затруднительный; трудность, затруднение |
| `授業 / じゅぎょう` | учебное занятие, урок |
| `泣き声 / なきごえ` | плач, звук плача |

Здесь расхождения были преимущественно разной подробностью перевода, а не противоположными значениями. У `困難` сохранены употребления и как прилагательного, и как существительного. Затронутые строки и исходные формулировки сохранены в [translation-resolution.json](translation-resolution.json); сборщик применяет эти решения и к повторной сборке. Дополнительно согласованы все 20 внутренних расхождений Tobira; решения применяются и к совпадающим записям Basic Kanji Book. После проверки обеих таблиц ни внутри одного CSV, ни между ними нет разных переводов одной пары написания и чтения. Полный список единых формулировок и исходные варианты находятся в том же журнале.

## Особый случай `々`

По явному решению пользователя `々` добавлен в `kanji.csv` с `id = 12293`, пустыми ключом и чтениями. Все шесть учебных связей, включая `先々週` из официальных изменений, сохраняются с номером символа 397 в книге и ссылаются на `kanji.id = 12293`. При импорте ключ самого знака — `NULL`; связи слов со знаком полноценные. См. [модель кандзи](../../database/kanji.md).

## Воспроизводимость и права источников

Идентификаторы колод, версии и SHA-256 входов сохранены в [sources.json](sources.json). Исходная колода, независимые CSV, оглавления и PDF изменений хранятся локально в игнорируемом `doc/dictionaries/local/basic-kanji-book/`. Они не включаются в assets. Основной CSV находится в `data/catalog/` и попадёт в последующие сборки, поскольку этот каталог уже подключён к assets.

Локальная повторная сборка:

```sh
python3 doc/imports/basic-kanji-book/build_catalog.py
```

Сборщик использует сохранённый локальный снимок и редакционные материалы рядом с ним; с чистого checkout без локальных входов его запуск потребует восстановления исходных снимков. Все используемые поля перевода и чтения фиксируются в журнале подготовки.

Страницы Anki и учебных материалов не предоставляют единой явной лицензии на весь полученный состав. Отдельная открытая публикация или распространение набора не объявляется разрешённой только на основании доступности скачивания. Условия словарных данных EDRDG: [лицензия](https://www.edrdg.org/edrdg/licence.html); JmdictFurigana — MIT, с сохранением исходного уведомления. Для существующих заимствований Tobira сохраняются их исходные условия. Общая лицензия на весь CSV здесь не выдумывается.
