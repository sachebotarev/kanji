# Навигация и состояние каталога

[Реестр экранов](../05-screens/catalog/README.md). Маршруты используют идентификаторы, не переведённые подписи. В карточки слова/кандзи/ключа передаётся необязательный контекст учебника. Он ограничивает связанные списки; без него открывается общий справочник.

## Переходы

Каталог → учебник → глава → слово/кандзи. Слово → кандзи в написании. Кандзи → ключ или связанные слова. Ключ → кандзи. Связанные слова → слово. Каталог → все кандзи / ключи Канси. Учебных привязок и переходов из карточки слова в учебник/главу нет.

Нажатие плитки подробностей открывает объект. Нажатие плитки на экране выбора возвращает выбранное значение в исходный список. Это разные события одного визуального компонента; виджет не решает, куда переходить.

Верхняя стрелка и системный Back возвращают в предыдущий контекст. Корень каталога возвращает на главную. Возврат сохраняет запросы, вкладку, фильтры и позицию списка. У вкладок отдельные запросы и позиции. В Android состояние задаётся ViewModel/SavedStateHandle, позиции — средствами lazy-компоновки. Не помещать весь каталог в Bundle.

## Поиск

Поиск скрыт до нажатия лупы. В открытом состоянии лупа заменяется согласованным search_off. Очистка поля оставляет поиск открытым; закрытие очищает запрос и сохраняет фильтры. Стрелка возврата выполняет возврат из экрана. Системная клавиатура и Back требуют Android-проверки.

Главы ищутся по точному номеру после нормализации ввода: 3 не совпадает с 13. Ошибка показывает фактический диапазон. Для слов поиск по написанию, чтению и переводу; для кандзи — по знаку, значениям и чтениям; для ключей — по знаку, названию и номеру. Катакана и хирагана нормализуются согласно domain-контракту. Поиск не меняет порядок остальных записей.

## Фильтры

| Список | Порядок условий |
| --- | --- |
| Кандзи учебника | Глава, черты, ключ |
| Кандзи главы | Черты, ключ |
| Слова учебника | Глава, кандзи |
| Слова главы | Кандзи |
| Все кандзи | Черты, ключ, JLPT |
| Ключи Канси | Черты |

Класс японской школы не является фильтром. Он остаётся сведением в карточке кандзи. Условия скрытой вкладки не ограничивают выбор текущей: выбор главы из слов получает только главу и выбранный кандзи, без черт, ключа и JLPT. Состояние другой вкладки сохраняется. JLPT выбирает точный N5–N1 либо отсутствие данных, не сумму уровней. Соответствия не объявляются официальным списком экзамена.

Условия пересекаются. Варианты и количества рассчитываются с учётом остальных условий, без ограничения самого выбираемого измерения. «Все» снимает одно условие; галочки на этой кнопке нет. Конкретный выбор имеет галочку/доступное состояние. Выбранная плашка показывает значение и крестик, без стрелки; невыбранная — подпись и стрелку. Сброс не очищает поиск и другие условия.

Плашки переносятся по строкам. Заголовок, вкладки и поле поиска закреплены. Плашки и счётчик уезжают при прокрутке вниз и возвращаются сразу при движении вверх; их внутренние отступы при этом не сжимаются. Если содержимое под открытой панелью помещается целиком, список не прокручивается и панель остаётся на месте. Нижний край списка — 24 плюс системный жест. Вкладка «Слова» учебника не группирует строки по главам. Липкий заголовок группы у связанных слов учебника непрозрачен на всю ширину и располагается под видимой частью панели. Перенос фильтров может увеличить высоту панели — это принятое поведение, важнее не скрывать значения за краем.

## Состояния

Loading → Ready или Error; Retry → Loading. Возврат доступен всегда. Ошибка содержит предметный текст и одну кнопку повтора. Пустой набор отличается от пустого поиска. Пустой поиск показывает кота с лупой, заголовок и предметное пояснение над клавиатурой; при нехватке места уменьшается кот, фраза остаётся. Очистка запроса — кнопка «Очистить» в поле поиска; она сохраняет фильтры. Выбранные фильтры остаются видимыми и сбрасываются по одному.

Прототип переключает загрузку вручную и не доказывает работу хранения. [Android-приёмка](../06-quality/README.md).
