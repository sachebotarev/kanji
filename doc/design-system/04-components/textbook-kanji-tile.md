# KanjiTile, RadicalTile, SymbolGrid

## Входы и события

KanjiTile: id, symbol, previewMeaning, optional placement(chapter,ordinal), optional strokeCount, optional selected, onActivate(id). RadicalTile: id, symbol, previewName, radicalNumber, optional selected, onActivate(id). Элемент не получает объект repository или маршрут.

SymbolGrid получает готовый упорядоченный список и stable key=id. Экран определяет семантику onActivate: подробности или выбор. В карточке слова размещение не показывается. В общих справочниках учебные номера не выдумываются; ключ всегда имеет свой номер Канси.

## Оформление

catalogActionSurface, радиус 24, боковые отступы 8, вертикальные 10. Японский знак 36/44 акцентом. Значение 14/20 основным цветом в слоте двух строк; черты и номер 12/16 вторичным. У нумерованной плитки верхний отступ 24 с масштабом текста; номер справа сверху, знак не пересекается с ним.

Минимум колонки 88 с учётом масштаба, учебник gap 12 / min-height 120, прочие компактные сетки gap 10 / min-height 96. Высота может расти. Одиночная плитка не растягивается во всю строку. Номер не пересчитывается после отбора.

Альтернативные значения убираются целиком для двухстрочного превью; если одно длинное — многоточие. Нельзя модифицировать полный перевод. Полное значение открывается в подробностях. В режиме выбора ключа название показывается целиком: слот подписи имеет минимальную высоту двух строк и растёт по содержимому без многоточия.

## Выбор и доступность

При выборе галочка и selected-семантика; выбранность не должна зависеть только от оттенка. На нажатии primaryContainer. Шеврон отсутствует. Доступное имя включает знак, полный смысл, количество черт и при наличии размещение. Весь элемент один фокус. Озвучивание японского текста получает корректный язык.

Число колонок пересчитывается по реальной ширине и шрифту, не по модели телефона. Нельзя механически копировать CSS line-clamp/auto-fill в Compose. [Android-план](../../implementation/catalog-ui.md).
