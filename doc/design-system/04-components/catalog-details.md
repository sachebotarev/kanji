# Информационные виджеты подробностей

Все блоки ниже некликабельны, кроме RelatedMaterialRow и плиток состава слова. Для просмотра catalogViewSurface, для перехода catalogActionSurface. Общий радиус 24.

| Виджет | Входы | Композиция / события |
| --- | --- | --- |
| InformationPanel | content, optional label | Padding 20; подпись внутри панели, без отдельного наружного заголовка |
| WordIdentity | written, reading, translation | Центрирование; написание 40/48 акцентом, чтение 24/32 основным, перевод 16/24 вторичным; длинный вариант по токенам |
| UsagePanel | localizedUsageNote | Подпись «Употребление» 14/20 и текст 16/24 вторичным цветом; отсутствующее примечание скрывает весь блок |
| ReadingPartsPanel | list(writtenPart, readingPart) | Подпись внутри; реальные пары 20/28, без выдуманного посимвольного деления |
| KanjiIdentity | symbol, strokeVector, meaning, strokeCount | Одна плашка. Высота рисунка следует границам черт, не выше 188; толщина и геометрия остаются на сетке 109. Значение 22/28, черты 12/16 вторичным; без клика |
| KanjiReadings | on, kun | Текст на фоне экрана, заголовки вторичные, чтения 28/36; отсутствие данных явно локализуется; названия онъёми и кунъёми пояснены, отдельная подпись напоминает проверять чтение целого слова |
| KanjiClassification | schoolStage, schoolYear?, jlptLevel?, joyo/kyoiku/jinmeiyo | Плашка просмотра; школа отдельной строкой, остальные значения переносятся целиком с gap 4/12; 14/20 вторичным. Списки подписаны 常用, 教育, 人名 с локализованными пояснениями. Школьная ступень явно относится к Японии |
| RadicalIdentity | symbol, name, radicalNumber, strokeCount | Знак по центру 64/76, название 22/28, номер и черты 12/16 вторичным |
| RelatedMaterialRow | title, subtitle?, targetId, onOpen(id) | Карточка перехода: padding 16, радиус 24, заливка действия, название над значением, шеврон. В списках выбора та же карточка |

В карточке кандзи переходы ключа и слов — карточки действия, отдельно от плашки со знаком и плашки классификации. Подпись содержит реальное количество связанных слов.

Состав слова использует SymbolGrid без размещений. Полная карточка слова не содержит учебных привязок или действий редактора. Сам по себе contextTitle не является ссылкой.

Перевод и usageNote разрешаются совместно: полный language_tag → базовый → ru. Школьный класс/JLPT — независимые от языка значения; названия ступеней и списков локализованы. Отсутствующий год не заменяется номером класса из стороннего кода. Канонические данные и KanjiVG не меняются ради уменьшения UI.

Векторы и загрузка ресурсов выполняются через внешние адаптеры. Виджет не читает assets и не запускает repository. Тяжёлые данные не загружаются в рекомпозиции. KanjiVG сохраняет лицензии. [Экраны](../05-screens/catalog/README.md).
