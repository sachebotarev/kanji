# CatalogFilterChip и CatalogFilterBar

Входы плашки: kind, label, optional selectedValue, clearLabel, onOpen(kind), onClear(kind). Панель получает упорядоченные FilterChipState, а не сама вычисляет набор условий.

Пустая плашка — спокойная catalogFilterSurface и стрелка раскрытия. Выбранная — та же заливка, акцентная подпись и самостоятельный крестик; стрелки нет. Рамки и разделителя перед крестиком нет. Открытие по подписи продолжает работать. Сброс не меняет соседние условия и поиск.

Области открытия и сброса минимум 48 по высоте; сброс 48 по ширине, не сжимается. Подпись 14/20. Панель имеет поля 20, сверху 12, снизу 4, gap 8; плашки переносятся на новую строку. Длинная подпись переносится внутри границ. Горизонтальной прокрутки/скрытых условий нет.

Состав и приоритеты — [UX](../02-ux/README.md). В справочнике: черты → ключ → JLPT. Ни класса японской школы, ни «Ещё» нет. Выбранность передаётся доступным состоянием, сброс имеет локализованное имя с названием условия.

Панель скрывается при прокрутке вниз и возвращается сразу при движении вверх. Заголовок, вкладки и поле поиска остаются. Сдвиг не сжимает поля панели. Изменение числа строк меняет её высоту. Липкий заголовок слов сохраняет свои поля и не перекрывается шапкой. Виджет компоновки не хранит бизнес-фильтры.
