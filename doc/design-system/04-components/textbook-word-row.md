# CatalogWordRow и WordChapterHeader

## CatalogWordRow

Входы: wordId, written, reading, resolvedTranslation, languageTag. Событие onOpen(wordId). Слова/выражения/предложения допустимы. Разные чтения одного написания имеют разные id и строки.

catalogActionSurface, радиус 24, padding 16, минимум 72, gap между карточками 12. Слева написание 24/32 японским акцентом и чтение 16/24 основным цветом. Справа перевод 14/20 вторичным цветом, по верхнему краю написания; соотношение ширин около 1 : 1.35, gap 12. При узкой ширине, крупном тексте или длинной записи перевод переносится ниже. Текст не обрезается.

Шеврона, обводки, номера главы и иконки редактирования нет. На нажатии primaryContainer. Одна область и один фокус; доступное имя включает написание, чтение, перевод и действие открытия. UI не удаляет полезное примечание из данных: отдельное usageNote показывается в подробностях. Обработка точного повтора чтения относится к подготовке контента.

## WordChapterHeader

Входы: chapterNumber, displayedGroupCount. Некликабельный заголовок 18/24, вес 500, объём на той же строке 14/20 вторичным цветом. Формат «Глава N · 13 слов» с устойчивым разделителем и правильным склонением. При поиске количество относится к видимым словам группы. Общий счётчик результатов показывается отдельно. Доли «A из B» не используются. Название учебника не повторяется, если оно уже есть в заголовке экрана.

Заголовок липкий под видимой панелью фильтров, непрозрачный на всю ширину списка, включая собственные поля. Между группами 28 без линии. На вкладке «Слова» учебника его нет: там плоский список. Он остаётся у связанных слов внутри учебника и не показывается при уже выбранной главе. Группировка — ответственность domain/presentation, не виджета.

Размещение: общая строка в core/wordui, предметная группировка в feature/catalog. [Экран слов](../05-screens/catalog/textbook-words.md).
