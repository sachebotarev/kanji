# TextbookCard

Назначение: открыть учебник. Входы: sourceId, локализованное название, количества кандзи/слов, illustration; событие onOpen(sourceId).

Целиком кликабельная карточка с catalogImportantSurface. Радиус 24, padding 16, минимум высоты 80. Книга в слоте 48, промежуток до текста 12. Название 18/24, вес 500; объёмы 14/20 вторичным цветом, зазор 4. Отдельного описания и шеврона нет. Длинное название переносится, высота растёт.

Рисунки: sage для Tobira (id 1), blue для Basic Kanji Book (id 2). У неизвестного источника общая книга. Цвет не несёт учебного уровня. Рисунок декоративный; доступное имя содержит название, состав и действие открытия, одна кнопка/фокус. Нажатие — primaryContainer, фокус видим, hover-стиль не требуется.

Применение: [каталог](../05-screens/catalog/catalog-screen.md). [Токены](../03-foundations/README.md).
