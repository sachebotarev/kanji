# ChapterCard и ChapterPreview

Входы карточки: chapterNumber, kanjiCount, wordCount, symbols в исходном порядке, необязательный selected и признак отображения количества слов. Событие onActivate(number). Смысл события задаёт экран: открыть главу либо вернуть выбор фильтра. В выборе главы для кандзи количество слов скрыто; в обычном списке глав и выборе главы для слов оно сохраняется. Сами данные и результаты фильтрации это не меняет.

catalogActionSurface, радиус 24, padding 16, промежуток подпись → превью 16. Название главы 18/24, вес 500, объём 14/20 вторичным цветом с зазором 2. Превью — японский акцент 26/36, по горизонтали 12, между строками 8. Число строк определяется доступным местом; остаток распределяется сбалансированно, порядок не меняется.

Превью целиком показано, не является набором отдельных кнопок. Шевронов нет. Выбор главы отмечается видимой галочкой и selected-семантикой; галочка декоративна для озвучивания. Нажатие primaryContainer. Доступное имя содержит главу и объёмы без длинного перечисления знаков; полный состав доступен на странице главы.

Родитель лениво выводит карточки, поля 20, сверху 16, снизу 24, gap 12. Главы не перенумеровываются по индексу списка. [Экран](../05-screens/catalog/textbook-chapters.md), [выбор](../05-screens/catalog/select-chapter.md).
