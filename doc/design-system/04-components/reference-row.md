# ReferenceCard

Назначение: открыть общий справочник. Входы: kind (Kanji/Radicals), title, description, illustration; событие onOpen(kind).

Каждый справочник — отдельная карточка catalogActionSurface, без общего контейнера и внутренних линий. Радиус 24, padding 16, минимум 80, промежуток между карточками 12. Значок 36 в слоте 48, до текста 12. Название 18/24, вес 500; назначение 14/20 вторичным цветом. Шеврон отсутствует.

Вся карточка нажимается, доступное имя состоит из текста назначения и открытия. Иконка декоративная. Назначение и переход не определяются сравнением русской подписи. Тексты переносятся, источник данных и весь список в компонент не передаются.

Применение: [каталог](../05-screens/catalog/catalog-screen.md). В Kotlin допустимо сохранить существующее имя строки при соблюдении нового контракта; отдельный дубликат ReferenceRow не нужен.
