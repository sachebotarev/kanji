# Выбор значения фильтра

## FilterOptionRow

Входы: stableValue, title, count, selected, onSelect(value). Средняя catalogActionSurface, радиус 24, padding 16; заголовок 18/24, объём 14/20. Выбранное конкретное значение имеет галочку справа и selected-семантику. Стрелки перехода нет: действие выбирает и закрывает экран.

Количество — результат фасета с учётом других условий. Порядок готовит presentation/domain. Компонент не решает, включает ли JLPT другие уровни; контракт — точное соответствие.

## ClearFilterButton

Входы: label, onClear. «Все главы/ключи/кандзи/черты/уровни» — спокойная заливка инструмента, минимум высоты 48, радиус 24, 14/20. Галочки нет независимо от текущего ограничения. Снимает только соответствующий фильтр и возвращает в родительский список.

## SelectionMark

Галочка у выбранного пункта декоративна для доступности: выбранность объявляется состоянием самой кнопки. Не использовать галочку как признак загрузки, изученности или доступности действия. В сетке ключей/кандзи та же роль. Выбор главы имеет текстовую отметку по ChapterCard.

Состояние экрана: Ready/Loading/Error/Empty; список выбора и источник запроса принадлежат ViewModel. Back отменяет выбор. Результат передаётся типизированным значением в back-stack родителя. Не передавать enum фильтра русской строкой.
