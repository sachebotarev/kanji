# CatalogLoadStatus, CatalogEmptyState, CatalogEndMarker

## CatalogLoadStatus

Входы: Loading/Error, предметные title/body, illustration, onRetry. Заголовок экрана и возврат остаются снаружи. Содержимое центрируется в доступной области, при малой высоте прокручивается.

Loading: статичный кот расставляет книги, предметный заголовок 20/28 и три точки. Двигаются только точки; reduced motion отключает движение. Error: кот с закрытой книгой, предметный текст цвета error и одна залитая primary-кнопка «Повторить» (минимум 48, ширина около 220). Повтор инициирует внешнюю загрузку; виджет не выбирает исход. Отдельной кнопки «На главную» нет.

Иллюстрация декоративна, loading объявляется статусом без повторного чтения каждого кадра. Ошибка доступна средствам доступности. Фокус и результат retry проверяются в Android.

## CatalogEmptyState

Входы: hasQuery, explanation?. Пустой поиск: кот с лупой 156, заголовок 18/24, пояснение 14/20. Очистка запроса — кнопка «Очистить» в поле поиска; фильтры она сохраняет. Для главы пояснение включает реальный диапазон.

Нет материала и нет результатов различаются. Сохраняются запрос и фильтры для исправления. Не обещать сетевой поиск, если его нет. Кот с лупой стоит в состоянии «ничего не найдено». Состояние «материалов нет» остаётся без маскота.

## CatalogEndMarker

Входы: scope (Chapter/Textbook), visible. Кот 120, подпись «Вот и вся глава» / «Вот и все слова учебника», статично. Показывается после полного списка, скрыт при поиске/отборе. Это конец списка, не успешное завершение обучения. Не озвучивать декоративное изображение отдельно.

Все тексты локализуются в resources, значения для plurals вычисляются с учётом языка. [Состояния экрана](../02-ux/README.md).
