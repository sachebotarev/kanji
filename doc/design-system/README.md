# Дизайн-система «Кандзи дэс нэ»

Каталог реализован в Android. Его обновлённый макет отражает текущие компоненты и подписи и передан на повторное согласование: **все 17 экранов не согласованы**. У 13 изменены основные элементы или варианты содержимого, у остальных — общие состояния загрузки и ошибки.

Русский — основной язык и fallback. Тёмная тема основная, светлая равноценна по функциям.

[Исходные эталоны](05-screens/catalog/approved/index.html) сохранены для сравнения. Они не означают согласование изменённой версии. Совпадение снимков, успешная сборка и тесты не заменяют решение пользователя о дизайне.

Главная согласована по направлению. Тренировка, личный словарь и настройки имеют собственные статусы: [реестр модулей](05-screens/README.md). Изменение статуса каталога не меняет их статус.

Требования проекта и локализации обязательны. Текущие экранные спецификации описывают представленный макет; утверждёнными они становятся после явного согласования. При расхождении прототипа и реализации фиксировать различие и обновлять затронутые материалы, а не считать автоматически согласованным любой из вариантов. [Правила поддержки](workflow.md).
