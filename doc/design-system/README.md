# Дизайн-система «Кандзи дэс нэ»

**Все 28 экранных вариантов не согласованы**, включая 17 экранов каталога. Это текущие дизайн-макеты в единой светлой/тёмной теме Material 3. Android-код не менялся; его оформление будет переноситься отдельно после согласования.

Русский — основной язык и fallback. Обе темы равноправны. Текущие базовые цвета определены только в `theme/theme-source.json`; производные роли доступны на экране настройки темы.

Новый цвет допускается только как именованный смысловой акцент общей темы с light/dark-парами и проверкой контраста. Экран не объявляет собственную палитру. Статусы не меняются от тестов, экспорта или переключения темы. [Правила поддержки](workflow.md).

Исторические снимки `approved/` сохранены для сравнения; они не являются согласованием текущей редакции. Нативные IME, Back, TalkBack, жизненный цикл и физика Compose не моделируются HTML. [Архитектура Android](../architecture.md).
