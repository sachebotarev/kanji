# Снимки актуальной реализации

1 ноября 2026 года. 32 PNG без редактирования, получены через `adb exec-out screencap -p`. Метаданные и SHA-256 APK — в `manifest.json`, просмотр — `index.html`.

Сборка `:app:assembleDebug` успешна. Установлена в Medium_Phone_API_37.0, API 37, 1080 × 2400 px, плотность 420 dpi, логическая ширина около 411 dp.

Сняты главная, тренировка (пусто, подсказка, один штрих и подробности), настройки проверки, личный словарь (пусто, список, карточка, пустой и заполненный редактор, клавиатура), учебники, главы, кандзи и слова главы, карточка учебного слова. Основные экраны представлены в двух темах. Дополнительно сняты главная и тренировка с системным масштабом текста 1.3 и главная на английском.

Эмулятор был новым. Пустой словарь снят до заполнения. Для остальных снимков в локальную БД только этого эмулятора добавлены две тестовые записи с `ru`/`en`: «木漏れ日» и «日本語を勉強しています。». Исходная БД проекта и Android-код не менялись. Это подготовка состояния для снимков, не проверка создания этих записей через Android UI.

После съёмки восстановлены масштаб текста 1.0, обычные системные анимации, светлая тема. Приложение оставлено на главной с русской локализацией.

## Наблюдения

- Главная сохраняет характер и при масштабе текста 1.3, но карточки статистики становятся разной высоты; это вариант для дальнейшего обсуждения, не автоматически дефект.
- В тренировке подтверждено отсутствие видимой кнопки возврата. Системный Back работает.
- У тренировки заметный промежуток между рядом ячеек и проверками: следствие нижней привязки поля. Решать вместе с поведением длинного задания, а не убирать отступ отдельно.
- Один штрих даёт «Ввод не завершён» в подробностях формы. Нельзя смешивать это состояние с окончательной ошибкой.
- Заполненный редактор с двумя языками длиннее пустого; с клавиатурой сохранение уходит ниже видимой области. Нужна отдельная оценка размещения основного действия.
- В каталоге уже есть главы, вкладки, поиск и фильтры; HTML v1 воспроизводит только часть этого поведения. Удаление остальных возможностей не согласовано.

Полный аудит TalkBack, все виды ошибок, выход с несохранёнными изменениями в Android, завершение реальной многословной сессии и планшеты этой съёмкой не проверены. Системная ширина эмулятора не менялась.
