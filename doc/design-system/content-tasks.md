# Вопросы для проработки учебного контента

Контент прорабатывается отдельно от оформления экранов. Подготовлены [данные, редакционные решения и проверяемые источники](../imports/main-content/README.md). Это подготовительный пакет основного контента, не обновление Android-БД: интеграция в приложение описана в спецификации каталога.

## Переводы и учебные пояснения слов

**Решение принято, данные подготовлены:** перевод — значение записи; примечание — регистр/употребление/особенности написания. В списке показывается перевод, в подробностях дополнительно отдельное примечание. Подготовлены все 2491 перевода: 13 точных повторов чтения исключены из отображаемого перевода, 9 пояснений выделены; оригиналы сохранены. Разрешение языка применяется к переводу и примечанию как единому блоку, с русским fallback. [Полный журнал и правила](../imports/main-content/README.md). [Контекст экрана](05-screens/catalog/chapter-words.md).

## Классификация кандзи

**Подготовлены данные для всех 3001 записей справочника** в [пакете классификаций](../../data/catalog/content/kanji-classifications.json):

- Год обучения (класс), в котором иероглиф изучают в японской школе.
- Уровень JLPT.

Источник школьного распределения — KANJIDIC с проверенными изменениями MEXT 2017, действующими с 2020 года: 1026 знаков по 1–6 годам начальной школы. Для остальных точный год не установлен (`null`), коды 8/9/10 не трактуются как классы. JLPT N1–N5 — неофициальные соответствия Tanos через закреплённый снимок kanji-data: 2211 значений, 790 пропусков. Происхождение, хеши, правила отбора описаны в [паспорте подготовки](../imports/main-content/README.md).

Исходные требования: при подготовке контента определить источники, актуальность классификаций и правила для кандзи без указанных значений. Для школьной классификации уточнить ступень обучения, чтобы номер класса был однозначным. Для JLPT зафиксировать происхождение и статус соответствий, не выдавая неофициальную классификацию за официальную.

Эти характеристики предназначены для подробной карточки, отбора в справочнике и будущего конструктора заданий. В согласованном справочнике есть фильтр JLPT; школьный класс остаётся только сведением в карточке, без фильтра. Не добавлять отдельные справочники для каждого признака. [Принятое направление отбора](05-screens/catalog/kanji-selection.md).

Классификационные значения и идентификаторы не зависят от языка. Названия, пояснения и подписи локализуются, русский — основной и язык подстановки. Отсутствующие значения не подменяются предположениями.
