# Единые основы Material 3

Статус: **весь дизайн не согласован**. Это спецификация и интерактивные HTML-макеты; Android-код сохраняет свою текущую тему. Реализация общей Android-темы будет отдельным этапом после согласования дизайна.

## Единый источник

[theme-source.json](../theme/theme-source.json) задаёт базовые цвета, типографику, формы, высоту и состояния. [screens.json](../theme/screens.json) отдельно задаёт статусы 28 экранных вариантов. [Как менять конфигурации](../theme/README.md). [Экран настройки темы](../prototypes/index.html#theme) позволяет менять цвета сразу во всём просмотрщике, переключать тему, видеть роли и выгружать JSON.

| Базовая роль | Key color | Назначение |
| --- | --- | --- |
| Primary | `key_colors.primary` | Главное действие, фокус, выбранная тренировка |
| Secondary | `key_colors.secondary` | Вторичные действия, фильтры, учебные материалы |
| Tertiary | `key_colors.tertiary` | Дополнительное смысловое выделение, лимит времени, помощь |
| Error | `key_colors.error` | Ошибка, неудачная проверка, удаление |

Цвета одинаковы по смыслу на всех экранах. Светлая и тёмная темы имеют полные отдельные схемы, вычисленные из одной основы. Тёмная тема не является CSS-инверсией светлой. Обои/динамический цвет не переопределяют зафиксированную палитру.

## Цветовые роли

Группы Primary, Secondary, Tertiary и Error имеют основной цвет, `on*`, `*Container` и `on*Container`. Для первых трёх также определены fixed/fixed-dim пары. Поверхности: surface, dim, bright, пять container-уровней; текст: onSurface / onSurfaceVariant; границы: outline / outlineVariant; inverse-роли — для контрастного уведомления; shadow и scrim — для высоты и модальных слоёв. Подсказки в текстовых полях (`placeholder` / пустой `label`) используют `onSurfaceVariant` с прозрачностью 48%, чтобы не выглядеть как введённый текст; в Android — `MaterialTheme.inputPlaceholderColor` / `kanjiOutlinedTextFieldColors()`.

Полная текущая схема находится в [material-theme.json](../prototypes/shared/material-theme.json) и на экране настройки. `material-theme.css` генерируется автоматически. Текст используется с парным `on*` цветом. Обычные карточки используют поверхности; смысловые акценты — роли трёх основных групп. Каталог и конструктор не объявляют собственных HEX-палитр. Цвет дополняется подписью, иконкой или признаком выбранности.

В конструкторе «Учебник» использует SecondaryContainer, «Кандзи / JLPT» — PrimaryContainer, «Мои слова» — TertiaryContainer, смешанный набор — нейтральную поверхность. Выбранная карточка имеет приоритетный Primary / onPrimary и лапку; таймер — TertiaryContainer / onTertiaryContainer. Произвольные голубые, розовые, сиреневые и песочные наборы больше не образуют отдельную систему.

Дополнительный цвет допускается только как именованный акцент общей темы с назначением, light/dark-парой, парными foreground-ролями и проверкой контраста. Сейчас дополнительных семейств нет. Цвета пикселей маскота и исходных иллюстраций — часть графики, а не новый UI-токен.

## Типографика

UI — Roboto; японский учебный текст — Noto Sans CJK JP с JP-глифами. В конфигурации заданы все 15 базовых Material-стилей: Display 57/64, 45/52, 36/44; Headline 32/40, 28/36, 24/32; Title 22/28, 16/24, 14/20; Body 16/24, 14/20, 12/16; Label 14/20, 12/16, 11/16. Вес и tracking также находятся в конфигурации. Учебные знаки используют крупные контентные размеры; длинные выражения и предложения допустимы.

## Формы, состояния и геометрия

Шкала углов: 0, 4, 8, 12, 16, 28 и Full. Карточки — Medium 12, FAB — Large 16, кнопки — Full, диалоги — ExtraLarge 28, outlined-поля — ExtraSmall 4. Шкала высоты: 0, 1, 3, 6, 8, 12. Surface container передаёт иерархию без произвольных цветных теней.

Область касания минимум 48 CSS px в макете; Android будет использовать dp, типографику — sp. Поля основного списка — 20, карточек — 16, промежутки — 8/12/16/24. Сетка меняет число колонок с учётом ширины и масштаба. Фокус виден; disabled не имитирует доступное действие; reduced motion отключает необязательное движение. Состояния hover/focus/pressed и disabled задаются общей конфигурацией и компонентами.

Статичные [маскоты](../assets/mascot/README.md) сохраняют узнаваемость в обеих темах. Нативные IME, Back, TalkBack, физика Compose и системная клавиатура проверяются на отдельном этапе реализации. [Проверки HTML](../../verification/material-theme/README.md).

Основание: [цветовые роли Material 3](https://m3.material.io/styles/color/the-color-system), [типографика](https://m3.material.io/styles/typography/applying-type), [Material Color Utilities](https://github.com/material-foundation/material-color-utilities).
