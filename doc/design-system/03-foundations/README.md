# Токены текущего макета каталога

Все значения ниже — целевые дизайн-токены. В Android размеры компоновки задаются в dp, шрифты и межстрочные интервалы — в sp. Физические пиксели PNG не переводятся в dp напрямую. Системный масштаб текста сохраняется.

Заливка передаёт роль: просмотр → обычный переход → важный переход. Фильтры слабее карточек материала. Не усиливать учебники до primary-заливки: различие с обычными карточками умеренное. «Повторить» — небольшая кнопка действия с primary-заливкой. Акцент японского текста не означает прогресс или выбранность.

Нажатие использует согласованную primaryContainer-поверхность темы; содержимое остаётся читаемым. Фокус и выбор не обозначаются только цветом: выбор дополнен галочкой, состоянием/текстом. Кнопка «Назад» без постоянной заливки. Тени, градиенты и декоративные обводки не добавляются.

## Геометрия

- Поля основного списка: 20 по бокам, 24 снизу. Карточка/инфопанель: радиус 24, стандартный внутренний отступ 16; главный блок подробностей — 20.
- Между карточками 12, между группами слов 28; разделы обычно 24, подробности кандзи/ключа 20.
- Иконка управления 24 внутри области минимум 48 × 48. Минимум кликабельной словарной строки 72, карточки каталога 80.
- Сетка: минимальная ширина ячейки 88 с учётом масштаба текста. На обычном телефоне три колонки; ширина и крупный текст меняют их число. Неполный ряд и один результат не растягиваются.
- Интервал сетки учебника 12, остальных компактных сеток 10. Высота определяется содержимым с одинаковыми слотами подписи. Минимум учебной плитки 120, остальных 96.
- Плитка: боковые отступы 8, вертикальные 10. Номер справа сверху. Для нумерованной плитки верхняя полоса 24 с учётом масштаба текста, чтобы знак не пересекался с номером.
- Подпись плитки имеет две строки 14/20. Альтернативы значений убираются целиком до заполнения слота; единственное длинное значение допускает многоточие. Полные данные доступны в подробностях.

Фильтры переносятся по строкам, без горизонтального выхода. Между плашками 8; область нажатия 48. Длинная подпись переносится, крестик не сжимается. В Android использовать стабильную собственную компоновку, если подходящий FlowRow требует opt-in в текущем стеке.
