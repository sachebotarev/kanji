# Маскот: идеи для будущего этапа

Статус: отложено. Вернуться после завершения основного функционала. Это идеи для макетов, не реализованные возможности Android и не утверждение всех предложений.

## Направление

Кот помогает учиться, а не украшает каждый экран. Характер передаётся иллюстрациями и уместными реакциями; подписи действий остаются ясными, без обязательного «мяу».

## Обсуждённые идеи

- Пользователю понравилась сцена пустого поиска: кот заглядывает в пустую коробку, ищет вместе с пользователем, без грустного выражения. Заменить существующую иллюстрацию, не добавлять второй блок. Сохранить короткое сообщение и сброс поиска.
- Загрузка и пустые состояния уже имеют иллюстрации: не создавать дублирующие сцены без проверки существующих ассетов.
- Завершение тренировки: кот с исписанным листом рядом с результатом — награда за действие.
- Подсказка в практике: кот внутри раскрытой подсказки; не заменять понятную иконку управления загадочным символом.
- Небольшие фирменные детали: закладка с ушами у текущей тренировки, лапка для личного рекорда, кошачья деталь обложек учебников. Это предложения, отдельно не согласованы.
- Ненавязчивые реакции на завершённое действие можно рассмотреть позднее; постоянную анимацию не добавлять.

## Ограничения

Не размещать декоративного кота в сетках кандзи и ключей, внутри прописной ячейки, возле каждого чтения или фильтра. Не возвращать удалённый блок «Вот и вся глава» в конец списка слов главы.

Сначала проверить существующие изображения в `assets/mascot/` и прототипах. Новые иконки и сцены создавать только для недостающих задач, сохраняя персонажа, пропорции и стиль. Новая генерация пока не выполнялась.

Пользовательские подписи и описания доступности локализуются; русский — основной и резервный язык.
