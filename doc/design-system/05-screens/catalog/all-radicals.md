# Ключи Канси — CAT-14

[Текущий макет](../../prototypes/index.html#catalog/CAT-14) · [Статус и изменения](review-status.json).

Статус: согласовано. HTML-маршрут: `all-radicals`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Заголовок «Ключи Канси», поиск, фильтр числа черт, полный объём или «Показано N из M ключей» и сетка ключей. Черты считаются у самих ключей. Номер на плитке остаётся номером Канси. Отдельной подписи над списком нет.

Порядок — число черт, затем номер Канси. Плитка содержит знак, краткое название и собственный номер ключа. Поиск работает по знаку, названию, номеру. Плитка открывает ключ без контекста учебника.

Краткая подпись ограничена двумя строками; полное название доступно в карточке. При крупном тексте число колонок уменьшается, номер занимает выделенную верхнюю полосу.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.

Исходные снимки предыдущей редакции: [тёмная тема](approved/cat-14-dark.png), [светлая тема](approved/cat-14-light.png). Дополнительные состояния — [галерея](approved/index.html). Требования Android — [план переноса](../../../implementation/catalog-ui.md).

Под заголовком показана область «Общий справочник». Учебные ограничения не наследуются скрыто.
