# Кандзи учебника — BOOKS.01.01

[Текущий макет](../../prototypes/index.html#catalog/BOOKS.01.01) · [Статус и изменения](../../theme/screens.json).

Статус: согласовано. HTML-маршрут: `source/2?tab=1`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Общий каркас учебника, активная вкладка «Кандзи». Фильтры: глава, число черт, ключ. Ни JLPT, ни школьный класс здесь не добавляются.

Над сеткой реальный объём учебника или «Показано N из M кандзи». Плитка содержит размещение «глава–сквозной номер», знак, краткое значение и число черт. Нумерация не меняется при отборе. Сетка имеет минимальную ширину 88 с учётом текста и интервал 12.

Плитка открывает подробности кандзи с sourceId. Возврат сохраняет поиск, фильтры и позицию. Одна плитка сохраняет ширину колонки. Подписи превью ограничены двумя строками, полные значения доступны в подробностях.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.

Требования Android — [контракт реализации](../../../implementation/approved-ui-handoff.md).
