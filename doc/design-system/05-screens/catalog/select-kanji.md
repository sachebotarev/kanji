# Выбор кандзи — CAT-11

[Текущий макет](../../prototypes/index.html#catalog/CAT-11) · [Статус и изменения](review-status.json).

Статус: согласовано. HTML-маршрут: `filter/kanji`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Выбор конкретного кандзи для списка слов: заголовок «Выбор кандзи», «Все кандзи», счётчик и сетка. Карточка содержит только знак и краткое значение, без учебного номера и числа черт. Повторяющая заголовок инструкция и легенда нумерации не выводятся. Дополнительных фильтров и вложенных ступеней выбора нет.

Состав рассчитывается в контексте исходного учебника/главы и остальных условий. Текущая плитка имеет галочку и доступное selected-состояние. «Все кандзи» снимает одно ограничение, без галочки. Выбор возвращает стабильный id в исходный список, Back не меняет его. Нельзя перенумеровывать размещения.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.
