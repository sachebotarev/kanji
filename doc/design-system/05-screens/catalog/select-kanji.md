# Выбор кандзи — CAT-11

[Текущий макет](../../prototypes/textbooks/index.html#filter/kanji) · [Статус и изменения](review-status.json).

Статус: не согласовано. HTML-маршрут: `filter/kanji`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Выбор конкретного кандзи для списка слов. Подпись «Выберите кандзи, чтобы отфильтровать слова» объясняет действие. Легенда номера плитки: «глава — номер кандзи в учебнике». Заголовок «Выбор кандзи», «Все кандзи», счётчик и общая сетка. Она отличается от просмотра событием выбора и отмеченным значением, а не новым стилем карточек.

Состав рассчитывается в контексте исходного учебника/главы и остальных условий. Текущая плитка имеет галочку и доступное selected-состояние. «Все кандзи» снимает одно ограничение, без галочки. Выбор возвращает стабильный id в исходный список, Back не меняет его. Нельзя перенумеровывать размещения.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.
