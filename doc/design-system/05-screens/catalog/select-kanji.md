# Общий выбор кандзи — SELECT.02 и DICT.03

[Каталог](../../prototypes/index.html#shared/SELECT.02) · [Личный словарь](../../prototypes/index.html#dictionary/DICT.03).

HTML-композиция общего множественного выбора требует согласования. Текущий статус задаёт `doc/design-system/theme/screens.json`; старые снимки SELECT.02 относятся к одиночному выбору. Android в этой правке не изменён.

## Общий экран

`CatalogSelection.kanjiPicker()` задаёт общую компоновку для каталога, личного словаря, учебного материала и фильтра набора слов: панель «Кандзи», поиск под лупой, фильтры по чертам/ключу/JLPT, число выбранных, просмотр выбранных, снятие выбора, общая сетка с одинаковой отметкой и FAB «Применить». Общие классы определяют поля, интервалы, прокрутку и место под FAB. Вложенные справочники обслуживают фильтры, но не создают отдельную версию выбора кандзи.

Меняется доступный набор: учебник/главы, личные записи или весь каталог. Поиск, временные фильтры и просмотр выбранных не сбрасывают отмеченные знаки. Идентификаторы, порядок учебных размещений и бизнес-логика не зависят от перевода.

## Выбор и возврат

Нажатие плитки переключает её отметку, не закрывая экран. Допускается несколько кандзи. «Применить» принимает набор; стрелка назад отменяет сделанные здесь изменения. Возврат из вложенного фильтра сохраняет текущие отметки. Снятие всего выбора означает отсутствие ограничения по кандзи. Несколько выбранных знаков фильтруют слова по **ИЛИ**.

В прототипах остаются адаптеры к разным моделям данных; это один общий рендерер, а не копии HTML для каждого места входа. Состояние не записывается в Android.

## Проверки

`prototypes/web/test_kanji_picker.cjs` проверяет множественный выбор, применение и отмену в учебном материале и каталоге. `test_dictionary_tags.cjs` проверяет те же действия в личном словаре. `test_recipes.cjs` покрывает фильтр кандзи внутри выбора слов и остальные сценарии конструктора. Каталожная матрица проверяет ширины 360/411/480, масштабы, языки и состояния.
