# Все кандзи — REFS.01

[Текущий макет](../../prototypes/index.html#references/REFS.01) · [Статус и изменения](../../theme/screens.json).

Статус: согласовано. HTML-маршрут: `all-kanji`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Общий справочник с заголовком «Кандзи», подписью «Общий справочник», поиском и тремя фильтрами в порядке значимости: черты → ключ → JLPT. Школьного фильтра и меню «Ещё» нет.

Объём — кандзи с ключом, 3000 записей; список начинается с 一. Знак повтора 々 в эту сетку не входит и открывается поиском по знаку или по «знак повтора». Активный отбор показывает «Показано N из M кандзи». Сетка без учебных номеров и без легенды. Знак, краткое значение и количество черт соответствуют общему виджету.

JLPT — точное соответствие выбранному N5–N1 или отсутствию данных. Условия пересекаются, сброс независимый. Плитки открывают кандзи без sourceId. Поиск/пустые состояния общие.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.

Требования Android — [контракт реализации](../../../implementation/approved-ui-handoff.md).
