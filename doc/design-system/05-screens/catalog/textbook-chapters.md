# Учебник · главы — CAT-02

[Текущий макет](../../prototypes/index.html#catalog/CAT-02) · [Статус и изменения](review-status.json).

Статус: согласовано. HTML-маршрут: `source/2`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Верхняя панель с полным названием учебника, поиском и вкладками «Главы», «Кандзи», «Слова». Вкладки без счётчиков. Заголовок и вкладки закреплены.

Карточка главы — номер, объём и полный состав кандзи. Номер 18/24, метаданные 14/20, превью 26/36 японским акцентом. Между подписью и превью 16. Знаки сохраняют порядок базы и распределяются по строкам без короткого хвоста. Минимум двух строк не требуется. Карточка целиком открывает главу, шеврона нет; отдельный знак внутри превью не является кнопкой.

Поиск по точному номеру, лупа в заголовке. Нет совпадения — кот с лупой и фактический диапазон. Очистка запроса остаётся в поле поиска. Полное отсутствие глав — состояние отсутствия материалов. Диапазон не перенумеровывается: Tobira начинается с главы 3.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.
