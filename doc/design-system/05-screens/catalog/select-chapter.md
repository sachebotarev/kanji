# Выбор глав — SELECT.01

[Макет](../../prototypes/index.html#shared/SELECT.01). Маршрут `filter/chapter`. Новая множественная компоновка требует согласования; источник статуса — `doc/design-system/theme/screens.json`.

Полноэкранный выбор использует общую компоновку, счётчик выбранных, снятие выбора, карточки глав с одинаковой отметкой и FAB «Применить». Подробный контракт: [множественные фильтры](multiselect-filters.md).

Состав учитывает другие ограничения. При входе из вкладки «Кандзи» карточка показывает подходящие кандзи и их превью, без количества слов. При входе из «Слова» количество слов сохраняется. Порядок и реальные номера глав не меняются. Поиск под лупой сопоставляет точный номер, не подстроку.

Несколько глав объединяются по ИЛИ. Нажатие карточки не закрывает экран; применение подтверждает набор, назад отменяет. Очистка не меняет другие фильтры. Фиксированная глава открытой карточки главы остаётся контекстом, а не редактируемым фильтром.

Android-реализация проверяется отдельно по контракту переноса.
