# Выбор главы — CAT-10

[Текущий макет](../../prototypes/index.html#catalog/CAT-10) · [Статус и изменения](review-status.json).

Статус: согласовано. HTML-маршрут: `filter/chapter`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Полноэкранный выбор для исходного списка: заголовок, «Все главы», объём и карточки глав. Состав учитывает другие активные ограничения. При выборе из вкладки «Кандзи» карточка показывает только количество подходящих кандзи и их превью; количество слов не отображается. При выборе из вкладки «Слова» количество слов сохраняется. Назначение выбора передаётся явно в маршруте и сохраняется при восстановлении. Обычная вкладка «Главы» сохраняет оба количества. Карточки сохраняют порядок и реальные номера. Карточки компактные: название и количество слева, приглушённое превью справа в одну строку с многоточием. Галочки и акцентной заливки текущей главы нет; доступное selected-состояние сохранено.

Если в исходном списке доступна только уже выбранная глава, открытие выбора недоступно, а независимый сброс остаётся доступным. «Все главы» снимает только фильтр главы. Галочки у этой кнопки нет. Нажатие главы возвращает номер в родительский список и закрывает выбор. Back возвращает без изменений. Если поиск доступен в контексте выбора, он использует точный номер и общую схему пустого поиска; не подменять точность подстрокой.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.
