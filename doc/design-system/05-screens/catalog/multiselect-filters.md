# Множественный выбор в фильтрах

## Область

HTML-макеты каталога, справочников, личного словаря и конструктора тренировок. Главы, кандзи, ключи, число черт и JLPT поддерживают выбор нескольких значений. Существующий фильтр тегов также остаётся множественным. Доступные данные определяются местом входа; модели Android этой правкой не меняются. Новая компоновка каталожных селекторов требует согласования.

## Взаимодействие

- Нажатие строки или плитки переключает её отметку и не закрывает экран.
- «Выбрано: N» показывает выбранные значения; «← Все» возвращает полный список. Поиск и просмотр выбранных не сбрасывают набор.
- «Снять выбор» очищает временный набор. Пустой набор означает отсутствие ограничения.
- FAB «Применить» подтверждает набор. Стрелка назад отменяет изменения этого экрана, включая очистку. Возврат из вложенного фильтра сохраняет отметки внешнего выбора.
- Сброс на плашке удаляет только соответствующее ограничение.

Состояние выбора передаётся идентификаторами, независимо от перевода. В HTML адаптеры временно поддерживают исходные скалярные значения, но новые применения возвращают массивы без повторов.

## Логика результатов и плашки

Значения одного фильтра объединяются по **ИЛИ**, разные фильтры и поиск — по **И**. Например, главы 1/2 и ключи 木/水 означают кандзи из любой из двух глав с любым из двух ключей. Число черт и JLPT сравниваются точно, не как диапазоны. «Без JLPT» — отсутствие сведений, не уровень N0.

Плашка показывает первые два выбранных значения и `+N` для оставшихся. Ключи и кандзи отображаются знаками, JLPT — N5…N1 или «Без JLPT», главы и черты — числами. При очистке возвращается исходная подпись, активный стиль и кнопка сброса исчезают. Полный набор доступен при открытии селектора. Названия тегов локализуются, а не заменяются их идентификаторами.

Фасетный список рассчитывается с учётом других ограничений, но без собственного фильтра. Сохранённые отметки не теряются при сужении списка. У JLPT допускаются строки с нулевым количеством; отсутствие данных не маскируется предполагаемым уровнем.

## Общие компоненты и проверка

`CatalogSelection.kanjiPicker`, `symbolGrid`, `chapterCard`, `navRow`, `filterChip` и общие операции над наборами используются обоими прототипами. Подтверждение и отмена остаются в адаптерах состояния.

`prototypes/web/test_multiselect_filters.cjs` проверяет применение/отмену, независимую проверку результатов ИЛИ/И, подписи плашек, очистку одного фильтра, выбор глав и подзаголовки. Дополнительно выполняются сценарии конструктора и словаря, каталожная матрица размеров/масштабов/языков и проверка переходов между модулями. Это проверки HTML, не Android UI-тесты.
