# Отбор кандзи

Действующий экран — [Все кандзи](all-kanji.md), условия в порядке значимости: число черт, ключ, JLPT. Японский школьный класс показывается только в [карточке кандзи](kanji-card.md), фильтра класса нет. Отдельных каталогов по JLPT/школе нет.

JLPT — точные уровни N5–N1 и отдельное отсутствие данных. Источник и ограничения — [подготовленный контент](../../../imports/main-content/README.md). Не трактовать коды школьных списков как годы, не назначать средним школам выдуманный год.

Порядок выбора, пересечение условий и независимый сброс — [UX-контракт](../../02-ux/README.md). Конструктор заданий не входит в эту спецификацию.
