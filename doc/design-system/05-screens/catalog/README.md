Канонические статусы и распределение по разделам — в [реестре](../../theme/screens.json). [Контракт реализации](../../../implementation/approved-ui-handoff.md) отделяет целевую редакцию от существующего Android; старые отчёты и снимки не подтверждают перенос новых состояний.
