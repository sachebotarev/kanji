# Выбор JLPT — SELECT.05

[Макет](../../prototypes/index.html#shared/SELECT.05). Маршрут `filter/jlpt`. Новая множественная компоновка требует согласования; источник статуса — `doc/design-system/theme/screens.json`.

Общий экран содержит счётчик выбранных, снятие выбора, строки N5…N1 и «Без JLPT», FAB «Применить». Каталог сохраняет краткое пояснение неофициального учебного соответствия и количества подходящих кандзи. Контракт: [множественные фильтры](multiselect-filters.md).

Несколько уровней объединяются по ИЛИ. Это точные уровни, не накопительный диапазон. «Без JLPT» — отсутствие сведений, не уровень N0. Варианты с нулевым количеством допускаются; неизвестным знакам не назначается предполагаемый уровень. Данные не выдаются за официальный список JLPT.

Нажатие строки переключает отметку, не закрывая экран. «Применить» подтверждает набор, назад отменяет. Плашка показывает выбранные уровни; сброс снимает только JLPT.

Android-реализация проверяется отдельно по контракту переноса.
