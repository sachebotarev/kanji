# Выбор JLPT — CAT-17

[Текущий макет](../../prototypes/index.html#catalog/CAT-17) · [Статус и изменения](review-status.json).

Статус: не согласовано. HTML-маршрут: `filter/jlpt`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Заголовок «JLPT», «Все уровни», краткое пояснение неофициального учебного соответствия и строки N5, N4, N3, N2, N1, затем «Нет данных JLPT». У каждого значения количество кандзи с учётом остальных фильтров.

Точное соответствие уровня, не накопительный диапазон. Варианты без результатов не показываются, кроме сохранённого текущего выбора. Выбор отмечается галочкой; сброс — без галочки. Значение без данных является отдельным состоянием фильтра, а не уровнем N0.

Экран открывается только из общего справочника. Выбор возвращает значение в исходный список. Нельзя выдавать эти соответствия за официальный список JLPT или назначать неизвестным знакам предполагаемый уровень.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.
