# Выбор числа черт — SELECT.04

[Макет](../../prototypes/index.html#shared/SELECT.04). Маршрут `filter/strokes`. Новая множественная компоновка требует согласования; источник статуса — `doc/design-system/theme/screens.json`.

Общий экран содержит счётчик выбранных, снятие выбора, строки доступных чисел и FAB «Применить». Поиска нет. Контракт: [множественные фильтры](multiselect-filters.md).

В каталоге строка показывает число черт и количество подходящих кандзи с учётом остальных условий; из списка ключей — количество ключей. Выбранные строки имеют ту же отметку, что другие селекторы. Несколько значений объединяются по ИЛИ и сравниваются точно, не как диапазон.

Нажатие не закрывает экран. «Применить» подтверждает набор; назад отменяет, включая очистку. Плашка показывает выбранные числа, сброс снимает только это ограничение.

Android-реализация проверяется отдельно по контракту переноса.
