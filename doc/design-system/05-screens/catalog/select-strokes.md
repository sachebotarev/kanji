# Выбор числа черт — CAT-16

[Текущий макет](../../prototypes/textbooks/index.html#filter/strokes) · [Статус и изменения](review-status.json).

Статус: не согласовано. HTML-маршрут: `filter/strokes`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Заголовок «Число черт», действие «Все черты», список реально доступных чисел. Поиска нет. Строка показывает число черт и количество подходящих кандзи с учётом остальных условий.

Выбранное число отмечено галочкой; «Все черты» галочки не имеет. Строки используют среднюю заливку переходов/выбора, сброс — спокойную заливку инструмента. Выбор возвращает число в родительский список. Back ничего не меняет. Значения отсутствующих фасет не выдумываются.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.
