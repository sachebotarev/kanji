Заголовок «Ключ», необязательное название учебника. Спокойная панель по центру: знак 64/76, название 22/28, метаданные «Ключ № N · M черт» 12/16. Главный знак доминирует над метаданными.

Ниже «Кандзи с этим ключом», счётчик, при наличии sourceId легенда размещений и сетка. Внешние поля 20, между главным блоком и результатами 20, внутри секции 8; между счётчиком и сеткой 4. Не создавать двойных внешних отступов.

Поиск отбирает связанные кандзи. В контексте учебника список ограничен этим учебником; без sourceId используется весь справочник. Плитки открывают кандзи. Номера размещений показываются только при наличии данных контекста.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.
