# Связанные слова — SHARED.02.01

[Текущий макет](../../prototypes/index.html#shared/SHARED.02.01) · [Статус и изменения](../../theme/screens.json).

Статус: согласовано. HTML-маршрут: `words/26085/2`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Заголовок содержит исходный знак: «Слова с 日» / «Words with 日». Ниже необязательное название учебника и поиск. Пользователь видит, к какому кандзи относится список.

Над списком отдельная строка объёма, например «13 слов». Все связанные записи показываются общими строками слова без ограничения первыми несколькими. При sourceId сохраняется контекст учебника и группировка по его размещениям. Групповая подпись показывает главу и количество видимых слов, например «Глава 3 · 13 слов». При поиске это количество результатов в группе. Название учебника уже показано в заголовке и в счётчиках не повторяется. Долей «13 из 13» нет. Счётчик относится к этому материалу, не ко всем словам приложения.

Нажатие открывает слово, Back возвращает к исходному кандзи. Новых фильтров для этого списка нет. Пустой поиск очищается общим действием без потери контекста.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.

Требования Android — [контракт реализации](../../../implementation/approved-ui-handoff.md).
