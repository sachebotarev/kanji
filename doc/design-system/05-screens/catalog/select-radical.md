# Выбор ключа — CAT-12

[Текущий макет](../../prototypes/textbooks/index.html#filter/radical) · [Статус и изменения](review-status.json).

Статус: не согласовано. HTML-маршрут: `filter/radical`. Общие правила не дублируются: [токены](../../03-foundations/README.md), [поиск/состояние/возврат](../../02-ux/README.md), [Контракты виджетов](../../04-components/README.md).

Заголовок «Выбор ключа», поиск, «Все ключи», счётчик и сетка. Доступны только ключи текущего набора с учётом остальных ограничений. Порядок — число черт, затем номер Канси.

На плитке знак, краткое название и номер ключа. Выбранная плитка имеет галочку и доступное состояние. Полное название не теряется из данных. Поиск по знаку, имени и номеру. «Все ключи» снимает только этот фильтр. Выбор возвращает id, Back отменяет изменение.

## Состояния и реализация

Поддерживаются Ready, Loading, Error, отсутствие материала и пустой поиск там, где есть поиск. Реальная загрузка/ошибка определяется ViewModel, не виджетом. Все подписи и plurals локализованы ru/en, fallback русский. Типизированные id и контекст не зависят от языка.

Исходные снимки предыдущей редакции: [тёмная тема](approved/cat-12-dark.png), [светлая тема](approved/cat-12-light.png). Дополнительные состояния — [галерея](approved/index.html). Требования Android — [план переноса](../../../implementation/catalog-ui.md).

В выборе название ключа показывается полностью, без многоточия. Высота подписи растёт по содержимому и системному масштабу текста.
