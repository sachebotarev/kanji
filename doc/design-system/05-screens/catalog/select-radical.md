# Выбор ключей — SELECT.03

[Макет](../../prototypes/index.html#shared/SELECT.03). Маршрут `filter/radical`. Новая множественная компоновка требует согласования; источник статуса — `doc/design-system/theme/screens.json`.

Общий экран содержит поиск под лупой, счётчик выбранных, снятие выбора, сетку ключей и FAB «Применить». Контракт: [множественные фильтры](multiselect-filters.md).

Порядок — число черт, затем номер Канси. Плитка показывает знак, полное локализованное название и номер, выбранные плитки — общую отметку и доступное нажатое состояние. Высота подписи растёт по содержимому и масштабу текста. Поиск в каталоге работает по знаку, названию и номеру.

Можно выбрать несколько ключей; результаты внутри этого фильтра объединяются по ИЛИ. Плашка показывает знаки ключей, не внутренние id. Применение подтверждает набор, назад отменяет. Остальные фильтры при очистке не меняются.

Android-реализация проверяется отдельно по контракту переноса.
