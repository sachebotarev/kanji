# Тренировка — SCR-KANJI-PRACTICE

Статус текущего макета PRACTICE: **согласовано**. PRACTICE.01 (итог) — **согласовано**, Android подключён по тому же алгоритму оценки. Общая светлая/тёмная тема Material 3; [реестр](../../theme/screens.json).

## Назначение

Показать задание и дать написать требуемые кандзи с исправлением ошибок и подсказкой. Экран одного задания не управляет очередью тренировки. Локализованный учебный текст допускает слова, выражения и предложения.

## Требования

- Каждая пользовательская ячейка имеет собственные штрихи, историю, время и факт помощи; предзаполненные не редактируются.
- Проверка автоматическая. Недостаток штрихов — незавершённый ввод, а не окончательная ошибка.
- Подсказка показывает эталон и учитывается как помощь, но не завершает знак.
- Вместо заблокированной кнопки «Далее» во время ввода (пока не все знаки зафиксированы) отображается негативная кнопка «Пропустить» (активна сразу). Кнопка меняет надпись на «Далее», как только все пользовательские знаки зафиксированы (`isResolved`) или истёк дедлайн таймера (`timedOut`). При успешном заполнении всех знаков (`isComplete`) кнопка становится позитивной (Primary); если слово завершено с ошибками (исчерпаны подсказки) или по таймауту, кнопка остаётся негативной (красной), а её нажатие завершает слово с сохранением частичных баллов за верно написанные знаки и фиксацией ошибки. Таймер слова останавливается, когда все знаки зафиксированы (`isResolved`). При активной настройке «Автопереход к следующему слову» переход происходит автоматически при фиксации всех знаков слова (`isResolved`), а также по истечении времени таймера (с паузой в 1 секунду для ознакомления с эталоном).
- Исправление инвалидирует старый вердикт; устаревший асинхронный ответ не применяется.
- Перевод: до двух строк, при обрезке — просмотр полностью; поле не уменьшается из-за статуса, нижние действия достижимы. Выбор и результат не передаются одним цветом.
- Возврат не равен пропуску. «Назад» и системный Back спрашивают согласие прервать практику; прогресс сохраняется, продолжение — с главного экрана.

## Реализация

В шапке «Назад», название экрана и таймер. «Назад»/системный Back → диалог прерывания с сохранением. Ниже — задание, ряд ячеек, три показателя проверок, поле и инструменты. Счётчик слов — в шапке. Детали открываются по нажатию показателя; настройки проверки — в SETTINGS. При достаточной высоте верх прокручивается отдельно от нижнего блока письма; в коротком окне прокручивается весь контент. Нижние действия закреплены.

Читаемость, форма и порядок/направление — независимые проверки. Их бизнес-правила — [решение о чекерах](../../../decisions/three-checkers.md). Host PRACTICE ведёт очередь из рецепта и после последнего задания открывает PRACTICE.01.

## PRACTICE.01 — Итог тренировки

После завершения всех заданий: маскот (три варианта), текстовая оценка, процент, краткие счётчики и время, кнопка «На главную». Расчёт и пороги — [training-grade.md](../../../implementation/training-grade.md). В просмотрщике состояния оценки переключаются селектором «Оценка итога».

| Оценка | Маскот |
| --- | --- |
| Отлично (≥85%) | `mascot_sticker_completed_sheet` |
| Хорошо (55–84%) | `mascot_sticker_encourage` |
| Ещё потренируемся (&lt;55%) | `mascot_sticker_jp_shodo_retry` |

## Предложение

[HTML](../../prototypes/web/index.html#practice) для PRACTICE добавляет видимый возврат и компактные признаки результатов помимо цвета. Это предварительный вариант. Результаты задаются переключателем просмотра, реальное распознавание не выполняется. Иллюстративный прогресс не подтверждает готовность многословной тренировки.
