# Тренировка — SCR-KANJI-PRACTICE

Статус текущего макета: **не согласовано**. Общая светлая/тёмная тема Material 3; [реестр](../../theme/screens.json). Android-код не менялся.
## Назначение

Показать задание и дать написать требуемые кандзи с исправлением ошибок и подсказкой. Экран одного задания не управляет очередью сессии. Локализованный учебный текст допускает слова, выражения и предложения.

## Требования

- Каждая пользовательская ячейка имеет собственные штрихи, историю, время и факт помощи; предзаполненные не редактируются.
- Проверка автоматическая. Недостаток штрихов — незавершённый ввод, а не окончательная ошибка.
- Подсказка показывает эталон и учитывается как помощь, но не завершает знак.
- «Далее» доступна только при выполнении всех обязательных ячеек. Пропуск, таймаут, самостоятельное выполнение и помощь — разные результаты.
- Исправление инвалидирует старый вердикт; устаревший асинхронный ответ не применяется.
- Текст не обрезается, поле не уменьшается из-за статуса, нижние действия достижимы. Выбор и результат не передаются одним цветом.
- Возврат не равен пропуску. Поведение сохранения/возобновления полноценной сессии требует отдельного решения.

## Реализация

Верхняя панель содержит название и таймер; видимой кнопки назад сейчас нет, системный Back обрабатывается. Ниже — задание, ряд ячеек, три показателя проверок, поле и инструменты. Детали открываются по нажатию показателя, настройки доступны из деталей. При достаточной высоте верх прокручивается отдельно от нижнего блока письма; в коротком окне прокручивается весь контент. Нижние действия закреплены.

Читаемость, форма и порядок/направление — независимые проверки. Их бизнес-правила — [решение о чекерах](../../../decisions/three-checkers.md). Android-host использует фиксированное demo-задание и отдельный демонстрационный итог.

## Предложение

[HTML](../../prototypes/web/index.html#practice) добавляет видимый возврат и компактные признаки результатов помимо цвета. Это предварительный вариант. Результаты задаются переключателем просмотра, реальное распознавание не выполняется. Иллюстративный прогресс не подтверждает готовность многословной сессии.
