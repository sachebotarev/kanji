# Конструктор рецептов

Статус: **согласовано**. [Реестр экранов](../theme/screens.json), [контракт реализации](../../implementation/approved-ui-handoff.md), [модель данных](../../database/recipes.md).

## Общие требования

- **Поверхности и цвета**: нейтральные поверхности `SurfaceContainer` / `OnSurface`, выбранные варианты `SecondaryContainer` / `OnSecondaryContainer` без галочек, интервалы разделов 24 CSS px / dp.
- **Навигация**: экран просмотра `RECIPE.02` выведен. Нажатие на карточку рецепта в списке `RECIPE` сразу открывает редактор `RECIPE.01.01`.
- **Удаление рецепта**: меню действий («⋮», `RECIPE.01.01.W01.W03`) расположено в шапке редактора для сохранённых записей с подтверждением через модальный диалог `RECIPE.D02`. Также доступно удаление свайпом карточки в списке (Android).
- **Материалы рецепта**: добавление через полноширинную кнопку «Добавить материал». Карточка материала содержит корзину удаления; доступна отмена последнего удаления. Первые три материала отображаются развёрнуто, остальные сворачиваются под «Ещё материалов: N».
- **Слова рецепта**: вторичное действие «Посмотреть N слов» под списком материалов открывает отдельный экран со списком слов (написание, чтение, перевод).
- **Параметры тренировки**:
  - Число заданий: по числу слов либо положительное число (пресеты 10/20/30 и степпер ±).
  - Таймер: без ограничения либо секунды на символ.
  - Подсказка в задании: трёхсегментный переключатель («Перевод», «Чтение» по умолчанию, «Без подсказок»).
  - Подсказка знака: двухсегментный переключатель («Следующая черта» по умолчанию, «Весь кандзи»).
- **Ошибки валидации**: локализованные сообщения и значки отображаются рядом с соответствующими полями.
- **Сохранение**: закреплённая Extended FAB «Сохранить» со значком сохранения справа снизу. Форма прокручивается независимо; зарезервирован нижний отступ 112 CSS px / dp под FAB.

## 1. Сценарии пользователя

1. **Создание и настройка рецепта**:
   - Переход с главного экрана (`HOME.01` или `:feature:dashboard`) к списку рецептов `RECIPE`.
   - Создание нового рецепта через кнопку «+ Создать» (`RECIPE.01`) либо редактирование существующего по нажатию на карточку (`RECIPE.01.01`).
   - Задание названия, состава учебных материалов и параметров тренировки (число заданий, таймер, режим подсказок в задании и тип подсказки знака).

2. **Выбор учебного материала (отдельный экран)**:
   - Состояния: [RECIPE.01.02 — добавление](../prototypes/index.html#recipe-builder/RECIPE.01.02), [RECIPE.01.02.01 — изменение](../prototypes/index.html#recipe-builder/RECIPE.01.02.01), [RECIPE.01.03 — слова](../prototypes/index.html#recipe-builder/RECIPE.01.03).
   - «Назад» отбрасывает изменения материала, «Добавить» / «Применить» обновляет черновик рецепта без немедленной записи в базу.
   - Четыре типа материала:
     - **Из учебника**: выбор учебника из списка радиокарточек. Фильтры «Главы» и «Кандзи» открывают селекторы каталога с множественным выбором. Пустой выбор означает все главы / все кандзи.
     - **Из словаря**: личный словарь пользователя. Фильтры по тегам (объединение по ИЛИ) и кандзи (объединение по И).
     - **По кандзи**: все слова каталога и личного словаря, ограниченные выбранными кандзи и/или уровнями JLPT N5…N1.
     - **Набор слов**: произвольный набор конкретных слов через поисковый селектор слов.
   - Внутри одного источника фильтры пересекаются (**И**); разные источники в рецепте объединяются (**ИЛИ**) с автоматическим устранением дубликатов слов.

3. **Лимиты тренировки и подсказки**:
   - **Заданий за тренировку**: *«По числу слов»* (все уникальные слова один раз) или *«Задать число»* (любое целое положительное число). При превышении пула слова выбираются автоматически перемешанными циклами (`shuffled_cycles`).
   - **Время на символ**: *«Без ограничения»* или секунды на один practice-символ (по умолчанию 10 с). Лимит слова = секунды × число символов для письма.
   - **Подсказка в задании**:
     - *«Перевод»*: перевод скрыт под спойлер-подсказку; чтение показано; раскрытие снижает процент результата.
     - *«Чтение»*: чтение скрыто под спойлер; перевод показан; раскрытие снижает процент результата.
     - *«Без подсказок»* (по умолчанию): чтение и перевод показаны сразу; штраф к оценке тренировки отсутствует.
   - **Тип подсказки знака**:
     - *«Следующая черта»* (по умолчанию): нарисованные черты отображаются сразу, следующая плавно рисуется анимацией.
     - *«Весь кандзи»*: бледный фоновый эталон знака целиком под рисунком пользователя.

4. **Управление библиотекой рецептов**:
   - Нажатие на карточку сразу открывает редактирование `RECIPE.01.01`.
   - Перестановка рецептов осуществляется долгим нажатием на карточку и перетаскиванием (системный drag-and-drop). Доступны команды «Переместить выше/ниже» для TalkBack и клавиатуры. При активном поиске перестановка отключена.
   - Удаление: через меню в шапке редактора (`RECIPE.01.01.W01.W03` с диалогом `RECIPE.D02`) либо свайпом карточки в списке (Android: EndToStart). Учебные материалы и слова при удалении рецепта не удаляются.

## 2. Экранная структура списка рецептов

```text
Назад     Рецепты                     [поиск]
Выберите или создайте                     кот-мастер
11 рецептов

Tobira · глава 10                              >
Учебник
20 заданий                  [10 с на символ]

Слова с кандзи N5                              >
Кандзи / JLPT · JLPT N5
Все N слов                  [10 с на символ]

        прокручиваемый список рецептов
                                   [ + Создать ]
```

Поиск работает сразу по названиям и меткам источников (учебники, главы, JLPT, кандзи). Регистр, крайние пробелы и ё/е не влияют на совпадение.

Метки условий на карточке:

| Поля модели | Формат компактной метки |
| --- | --- |
| `source_id` | Название учебника («Tobira», «Basic Kanji Book») или «Мой словарь» |
| `chapter_from`, `chapter_to` | «Глава 10», «Главы 1–10», «С главы 3», «По главу 5» |
| `jlpt_level` | «Кандзи JLPT N5» |
| `kanji_id` | «Кандзи 日» |
| `word_id` | Полное написание записи |
| Без ограничений | «Все источники» |

На карточке списка показаны первая метка материала и текст «Ещё N» (число скрытых материалов). Полный состав отображается в редакторе `RECIPE.01.01`.

## 3. Таблица состояний и валидации

| Состояние | Поведение интерфейса |
| --- | --- |
| **Пустой список** | Иллюстрация кота, пояснение и кнопка создания. |
| **Создание рецепта** | Пустое название, пустой список источников, дефолтные параметры (весь пул, без таймера, подсказка «Без подсказок», подсказка знака «Следующая черта»). |
| **Пустой набор слов** | Индикатор «0 слов», предупреждение, блокировка сохранения с сообщением об ошибке. |
| **Некорректные поля** | Пустое имя, диапазон глав от большего к меньшему, 0 или отрицательные секунды вызывают сообщение ошибки у поля. |
| **Выход с несохранёнными изменениями** | Модальный диалог: «Сбросить изменения?» / «Отмена» / «Выйти». Сохранение — только через FAB. |

## 4. UI-компоненты (Jetpack Compose)

- `RecipeCard(plan, onOpen)`: карточка списка рецептов. Нажатие открывает `RECIPE.01.01`.
- `RecipeListIntro(count)`: вступительный блок списка с декоративным котом-мастером.
- `CreateRecipeFab(onClick)`: закреплённая Extended FAB «+ Создать».
- `RecipeMaterialRow(source, wordCount, onEdit, onRemove)`: плашка материала с бейджем типа и корзиной удаления.
- `RecipeLimitControl(title, isLimited, value, onToggle, onValueChange)`: выбор режима и значения параметра тренировки.
- `RecipeHintsControl`: трёхсегментный выбор подсказки в задании.
- `RecipeStrokeHintsControl`: двухсегментный выбор типа подсказки знака.
- `RecipePreviewSection(uniqueWordsCount, trainingTaskCount, wordsList, onToggleList)`: сводка состава слов.
