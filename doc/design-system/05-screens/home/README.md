# Главная — SCR-DASHBOARD

Статус текущего макета: **не согласовано**. Общая светлая/тёмная тема Material 3; [реестр](../../theme/screens.json). Android-код не менялся.
## Требования

Пригласить к занятиям и поддержать игровой характер. Статистика и активность расположены наверху намеренно. Далее — выбранная тренировка и её запуск, затем словари. Сохраняются кот, зелёная палитра и видимый призыв «Ня! Начнём?» без дублирующего названия действия.

Выбор, параметры и запуск относятся к одной тренировке. Название и параметры должны читаться без конкуренции с котом. Есть входы в каталог, личный словарь и настройки. Пустая история новой тренировки не изображается как существующий результат.

## Реализация

DashboardScreen состоит из независимых виджетов. Статистика и активность берутся из DashboardDemo, число личных записей — из реального репозитория; пока оно неизвестно, отображается описание. Выбор/создание/изменение тренировок и диалоги статистики существуют. Связка выбранной конфигурации с настоящей сессией ещё не реализована.

## Направление макета

[Визуальный ориентир v1](concept-v1.png): знакомый характер, название тренировки на полной ширине, кот в зоне запуска, последовательные формы и интервалы. Точные размеры, заливки и отдельные детали графики уточняются. Дополнительные стрелки словарей и фактурные заливки изображения не являются обязательными требованиями.
