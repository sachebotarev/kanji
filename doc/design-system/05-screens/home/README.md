# Главная — HOME

Статус: **согласовано 2026-11-07** (`HOME`, `HOME.01`). Настройки (`SETTINGS`) не входят в это согласование. Общая светлая/тёмная тема Material 3; [реестр](../../theme/screens.json). Согласование макета не означает готовую Android-реализацию.

## Требования

Пригласить к занятиям и поддержать игровой характер. Статистика и активность расположены наверху намеренно.

Запуск тренировки и рецепты тренировок — **отдельные блоки**:

1. **Запуск / продолжение** (`HOME.W06`):
   - Нет `in_progress`: «Ня! Начнём?» / «Начать тренировку» → выбор рецепта (`HOME.01`).
   - Есть незавершённая: на кнопке «Ня! Начнём?» и контрастный статус «Незавершённая тренировка» / «Unfinished training». Тап → диалог `HOME.D03`: заголовок «Продолжить или начать новую?», в теле рецепт и прогресс; primary «Продолжить», secondary «Начать новую».
2. **Рецепты тренировок** (`HOME.W07`): вход в список RECIPE для создания и настройки. Не запускает тренировку.

Далее — словари. Сохраняются кот, зелёная палитра и видимый призыв. На главной есть отдельные входы «Учебники», «Справочники», «Мой словарь» и настройки.

## HOME.01 — Выбор рецепта

Открывается из запуска тренировки. Пользователь выбирает рецепт тапом по карточке; затем открывается PRACTICE. Поиск как в списке RECIPE. Пустой список — обычный empty-state (маскот по центру, пояснение и CTA «Создать первый рецепт» → редактор нового рецепта). «Назад» возвращает на HOME. Радиокнопка «выбранный рецепт» и перестановка на этом экране не используются.

## Реализация

DashboardScreen состоит из независимых виджетов. Статистика и активность берутся из DashboardDemo, число личных записей — из реального репозитория. Отдельные входы открывают учебники, справочники и личный словарь; [проверки маршрутов](../../../verification/library-sections-android.md).

Android: запуск и рецепты тренировок разделены; `HOME.01` и `HOME.D03` подключены; empty-state выбора ведёт в создание рецепта.
