# Главная — SCR-DASHBOARD

Статус текущего макета: **согласовано пользователем 2026-11-04**. Общая светлая/тёмная тема Material 3; [реестр](../../theme/screens.json), [контракт реализации](../../../implementation/approved-ui-handoff.md). Согласование не означает готовую Android-реализацию; тренировки и статистика исключены из этапа.
## Требования

Пригласить к занятиям и поддержать игровой характер. Статистика и активность расположены наверху намеренно. Далее — выбранная рецепт и её запуск, затем словари. Сохраняются кот, зелёная палитра и видимый призыв «Ня! Начнём?» без дублирующего названия действия.

Выбор, параметры и запуск относятся к одной рецепте. Название и параметры должны читаться без конкуренции с котом. На главной есть отдельные входы «Учебники», «Справочники», «Мой словарь» и настройки. Учебники открывают главы и материал конкретного учебника; справочники — общие списки кандзи и ключей. Объединённого пункта «Каталог» нет. Пустая история новой рецепты не изображается как существующий результат.

## Иллюстрации входов

- Учебники: [`textbook.png`](../../assets/stationery/textbook.png).
- Справочники: [`inkstone.png`](../../assets/stationery/inkstone.png).
- Личный словарь: [`notebook.png`](../../assets/stationery/notebook.png).

Исходные PNG используются в Android без перерисовки, в поле 48 dp без дополнительного оптического увеличения. Для тёмной темы применяется фильтр макета `brightness(1.25) saturate(.7)` средствами Compose `ColorMatrix`.

Иконка настроек — исключение из HTML-эталона: сохраняется существующая Android-иллюстрация `art_settings` с прежними размером и палитрой. Контурная шестерёнка в HTML не является актуальным требованием и не должна заменять её.

## Реализация

DashboardScreen состоит из независимых виджетов. Статистика и активность берутся из DashboardDemo, число личных записей — из реального репозитория; пока оно неизвестно, отображается описание. Отдельные входы открывают учебники с главами, общие справочники кандзи/ключей и личный словарь; [проверки маршрутов](../../../verification/library-sections-android.md). Выбор рецепты связан с постоянным хранилищем рецептов и конструктором. Связка выбранной конфигурации с настоящей тренировкой не реализуется в текущем этапе. Визуальная доводка главной выполняется после завершения оставшихся функциональных доработок итерации.
