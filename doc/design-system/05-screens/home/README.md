# Главная — HOME

Статус: **согласовано 2026-11-07** (`HOME`, `HOME.01`). Следы тренировок (`HOME.02`, `HOME.02.01`) — **Android**; HTML-макет ещё не согласован. Настройки (`SETTINGS`) не входят в это согласование. Общая светлая/тёмная тема Material 3; [реестр](../../theme/screens.json).

## Требования

Пригласить к тренировкам и поддержать игровой характер. Статистика и активность расположены наверху намеренно.

Запуск тренировки и рецепты тренировок — **отдельные блоки**:

1. **Запуск / продолжение** (`HOME.W06`):
   - Нет `in_progress`: «Ня! Начнём?» / «Начать тренировку» → выбор рецепта (`HOME.01`).
   - Есть незавершённая: на кнопке «Ня! Начнём?» и контрастный статус «Незавершённая тренировка» / «Unfinished training». Тап → диалог `HOME.D03`: заголовок «Продолжить или начать новую?», в теле рецепт и прогресс; primary «Продолжить», secondary «Начать новую».
2. **Рецепты тренировок** (`HOME.W07`): вход в список RECIPE для создания и настройки. Не запускает тренировку.

Далее — словари. Сохраняются кот, зелёная палитра и видимый призыв. На главной есть отдельные входы «Учебники», «Справочники», «Мой словарь» и настройки.

`HOME.W02` открывает следы тренировок с фильтром «Сегодня»; `HOME.W03` — те же следы без периода. Спека: [training-history.md](training-history.md).

## HOME.01 — Выбор рецепта

Открывается из запуска тренировки. Пользователь выбирает рецепт тапом по карточке; затем открывается PRACTICE. Поиск как в списке RECIPE. Пустой список — обычный empty-state (маскот по центру, пояснение и CTA «Создать первый рецепт» → редактор нового рецепта). После успешного сохранения этого первого рецепта PRACTICE стартует сразу, без возврата в список RECIPE. Если в рецепте нет слов с записываемыми кандзи — диалог и возврат на `HOME.01` с уже созданным рецептом. «Назад» из редактора возвращает на `HOME.01`. Радиокнопка «выбранный рецепт» и перестановка на этом экране не используются.

## Реализация

DashboardScreen состоит из независимых виджетов. Число личных записей — из реального репозитория; `HOME.W02` (день) и `HOME.W03` (активность) — из завершённых заданий ([день](../../../implementation/home-word-stats.md), [активность](../../../implementation/home-activity.md)). Отдельные входы открывают учебники, справочники и личный словарь; [проверки маршрутов](../../../verification/library-sections-android.md).

Android: запуск и рецепты тренировок разделены; `HOME.01` и `HOME.D03` подключены; empty-state выбора ведёт в создание рецепта.
