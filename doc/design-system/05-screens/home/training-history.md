# Следы тренировок — HOME.02 / HOME.02.01

Статус: **реализовано в Android** (HTML-макет остаётся черновиком согласования). HTML: [`#training-history`](../../prototypes/web/index.html#training-history), [`#training-history-detail`](../../prototypes/web/index.html#training-history-detail). Код: `feature/dashboard/.../history/`.

## Назначение

Показать прошлые тренировки с группировкой по дням и открыть подробности одной тренировки со словами и статусами. Это просмотр истории, не экран итога `PRACTICE.01`. Каноническое имя: **Следы тренировок** / **Training footprints** (см. [глоссарий](../../../glossary.md): Training / «тренировка»).

## Входы

| Откуда | Куда | Фильтр |
|---|---|---|
| `HOME.W02` (слова дня) | `HOME.02` | Период **Сегодня** |
| `HOME.W03` (активность) | `HOME.02` | Период **Все** |
| Карточка в `HOME.02` | `HOME.02.01` | — |

Диалоги `HOME.D01` / `HOME.D02` с главной больше не открываются; ID выведены.

## HOME.02 — Следы тренировок

- **Заголовок:** «Следы тренировок» / «Training footprints»; назад на HOME.
- **`HOME.02.W01` — Поиск** (`UI-SEARCH`): лупа в app bar; поле по названию рецепта; запрос локален экрану.
- **`HOME.02.W02` — Фильтр дат** (`UI-FILTER`): чип периода с шевроном вниз, как у каталога. Пресеты макета: Сегодня / 7 дней / 30 дней / Все. Активный чип и сброс — как у каталога.
- **`HOME.02.W03` — Список по дням:** секции «Сегодня» / «Вчера» / полная дата.
  - **`HOME.02.W03.W01` — Карточка тренировки** (две строки):
    - уменьшенное кольцо как `HOME.W02` (верно / подсказка / пропуск|таймаут по словам тренировки);
    - название рецепта (ellipsis);
    - время старта и длительность; у `in_progress` — метка «Незавершённая» и прогресс «слово N из M» (долгие тренировки видны при любом периоде).
  - Тап → `HOME.02.01`.
  - Свайп EndToStart → удаление через `HOME.02.D01` (как у списка RECIPE), в том числе незавершённой.
- **`HOME.02.W04` — Пусто / нет совпадений:** маскот и пояснение; при фильтре — предложить сброс.

### HOME.02.D01 — Удалить тренировку

Подтверждение: отмена и деструктивное «Удалить». Удаляется запись тренировки; учебные материалы не трогаются.

## HOME.02.01 — Подробности тренировки

- App bar: назад на `HOME.02`; название рецепта.
- Сводка: дата, время, длительность, мини-кольцо, счётчики слов.
- Список слов: написание, чтение, перевод, статус (`correct` / `assisted` / `skipped` / `timed_out`), время на слово.
- Без маскота оценки и без «На главную» как завершения сессии (`PRACTICE.01`).
