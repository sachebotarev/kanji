## Входы и возврат

Главная → настройки приложения → параметры проверки. В тренировке: нажать показатель → детали → «Настройки». Возврат ведёт к месту входа; рисунок, история и выбранная ячейка сохраняются. Переключение во время незавершённого жеста недоступно.

Общие настройки показывают состояние японской модели: отсутствует, загружается, загружена. Ошибка и повторная попытка — по [контракту модели](../../../implementation/japanese-model.md). Без модели читаемость недоступна с пояснением.

## Параметры

Три чекера включаются независимо. В форме задаются порог и расстояние, пределы компенсаций, общий бюджет, словарные правила и порядок/направление. Для числовой компенсации 0 означает выключение, для общего бюджета — отсутствие общего ограничения; индивидуальные пределы сохраняются. Смысл этих нулей не смешивается.

Шаг процентов/градусов — целый, дрожания — 0.1%. Точные исходные значения и алгоритм — [реализация формы](../../../implementation/shape-checker.md) и [Procrustes](../../../implementation/procrustes.md). Для каждого параметра есть раскрываемая справка об единицах, строгости, нуле и ограничениях.

Параметры и сброс сохраняются в Preferences DataStore, загружаются до рабочих экранов. Ошибка хранения предлагает повтор. SavedStateHandle участвует в восстановлении/миграции, но не является единственным постоянным хранилищем. [Контракт хранения](../../../implementation/persistent-settings.md).

## Подробности

Три показателя открывают отдельные диалоги. Данные относятся к текущей позиции и ревизии. Целевой знак не раскрывается без учтённой подсказки или разрешённой предзаполненной ячейки. Невыполненная проверка не обозначается пройденной; при невозможности сопоставления порядок и направление — «Не проверено». Техническая отладка не должна загромождать основной учебный интерфейс.
