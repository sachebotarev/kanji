# Настройки и калибровка формы кандзи

Статус текущего макета: **не согласовано**. Общая светлая/тёмная тема Material 3; [реестр](../../theme/screens.json).

Экран настроек разделён на два логических уровня:
1. **`SETTINGS` — Общие настройки приложения:** доступны пользователю всегда.
2. **`SETTINGS.01` — Калибровка формы кандзи:** специализированный экран геометрических параметров и допусков алгоритма формы. Доступен **только в develop/debug-сборках** (`BuildConfig.DEBUG`); в релизе скрыт.

## Входы и навигация

- Главная (`HOME`) → кнопка шестерёнки в шапке → экран общих настроек (`SETTINGS`).
- Из экрана общих настроек (`SETTINGS`):
  - Карточка «Калибровка формы кандзи» (`SETTINGS.W02`) открывает `SETTINGS.01` (в develop/debug-сборках).
  - Кнопка «Очистить историю тренировок» (`SETTINGS.W04`) открывает подтверждающий диалог `SETTINGS.D01`.
- Из режима практики (`PRACTICE`):
  - В debug-сборке доступен маршрут `PracticeChecker` с живым превью текущего задания для проверки калибровки на реальном штриховом вводе; кнопка «Назад» возвращает в тренировку.
  - Диалоги показателей проверки на экране практики (`PRACTICE.D01`) только поясняют текущий вердикт и не содержат переходов в настройки.

## Структура экранов

### `SETTINGS` — Общие настройки

Экран сгруппирован по функциональным разделам:

1. **Ход тренировки (`SETTINGS.W05`):**
   - Переключатель автоперехода к следующему слову (`autoAdvanceOnSuccess`, по умолчанию выключен). При включении, когда все знаки слова приняты чекерами, экран сразу переходит к следующему заданию без ожидания нажатия «Далее». Таймаут и пропуск слова по-прежнему требуют явного подтверждения «Далее».

2. **Подсказки (`SETTINGS.W06`):**
   - «Максимум подсказок следующей черты» (`maxNextStrokeHints`): диапазон 1…12 (по умолчанию 3). Задаёт лимит показов подсказок на знак; значение сохраняется в сущность `Training` при создании и используется при итоговой оценке в `summarize()`.
   - «Показ полного знака» (`fullHintDisplayMillis`): диапазон 200…3000 мс с шагом 50 мс (по умолчанию 500 мс).

3. **Модули проверки (`SETTINGS.W07`):**
   - Независимые переключатели трёх модулей:
     - Читаемость («Распознавание рукописного текста», `readabilityEnabled`).
     - Письмо («Порядок и направление черт», `strokeWritingEnabled`).
     - Форма («Геометрия и пропорции формы», `shapeEnabled`).
   - Блок японской языковой модели ML Kit (`SETTINGS.W07.W01`): статус (готова / загружается / не загружена / ошибка) и кнопка загрузки модели. При отсутствии модели читаемость блокируется с подсказкой «Требуется загрузка японской модели», а сохранённое состояние чекбокса остаётся пользовательским.

4. **Калибровка формы кандзи (`SETTINGS.W02`):**
   - Отображается **только в develop/debug-сборках**.
   - Переход к экранным слайдерам и допускам формы (`SETTINGS.01`).

5. **Данные и память (`SETTINGS.W04`):**
   - Кнопка «Очистить историю тренировок». Открывает подтверждающий диалог `SETTINGS.D01` с предупреждением о необратимости действия. При согласии удаляет сохранённые прогоны через `TrainingsRepository.clearHistory` на фоновом IO-потоке.

### `SETTINGS.01` — Калибровка формы кандзи (develop-only)

Экран предназначен для точной отладки и калибровки алгоритма распознавания формы (`ShapeKanjiChecker` / Procrustes):

1. **Пресеты строгости:** «Мягкая», «Стандартная», «Строгая» и индикатор «Ручная настройка». Выбор пресета пакетно выставляет калибровочные коэффициенты; ручная правка любого слайдера переключает статус в «Ручная настройка».
2. **Предпросмотр (`SETTINGS.01.W02`):** тестовый холст кандзи с визуализацией эталона, пользовательского ввода и вердикта формы.
3. **Группы геометрических параметров:**
   - *Сходство формы:* порог сходства (`minMatchScore`, %), допустимое расстояние (`maxDistanceScore`).
   - *Компенсации трансформаций:* сдвиг (`maxTranslationRatio`), размер (`maxScaleDeviation`), растяжение по X/Y (`maxStretchRatio`), поворот (`maxRotationDeg`), наклон (`maxShearRatio`), дрожание руки (`maxJitterRatio`). Нулевое значение выключает конкретную компенсацию.
   - *Общий бюджет:* предел суммарной компенсации (`combinedBudget`). Нулевой бюджет снимает только общее ограничение, сохраняя индивидуальные лимиты.
   - *Словарные правила структуры черт:* флаг `checkStrokeStructure`, разница длин штрихов, допустимое соединение и выступы штрихов.
4. **Сброс (`SETTINGS.01.W01.W03`):** возврат параметров алгоритма к значениям по умолчанию.
5. **Справка (`SETTINGS.01.D01`):** контекстный диалог по каждому параметру с описанием единиц измерения, строгости и эффекта нуля.

## Постоянство и архитектура

- Параметры хранятся в `Preferences DataStore` (`files/datastore/recognition_settings.preferences_pb`) через `RecognitionSettingsRepository` в `:data:settings`.
- Сохранение выполняется единым снимком в транзакции. ViewModel последовательно сохраняет снимки под Mutex.
- Подробный контракт хранения: [persistent-settings.md](../../../implementation/persistent-settings.md).
