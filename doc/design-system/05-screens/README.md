# Экранные модули

| Модуль | Действующий статус |
| --- | --- |
| [Каталог](catalog/README.md) | Все 17 экранов не согласованы; текущий макет синхронизирован с реализованным Android-каталогом |
| [Главная](home/README.md) | Согласовано визуальное направление, не законченные токены и поведение |
| [Тренировка](practice/README.md) | Действующая реализация; отдельная проработка дизайна |
| [Личный словарь](dictionary/README.md) | Действующая реализация; новый экранный дизайн отдельно не согласован |
| [Настройки](settings/README.md) | Действующая реализация; новый дизайн отдельно не согласован |

Общие виджеты слова могут переиспользоваться личным словарём, но это не добавляет каталожному слову редактирование. [Границы переиспользования](word-library.md).
