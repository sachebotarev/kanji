# Унификация основных HTML-экранов

## Область и направление

Общие правила основных экранов `prototypes/web/`: каталог служит эталоном компонентов и типографики. Это HTML-дизайн, не реализация Android.

Характер — японская канцелярия: действующие бумажные поверхности, цвет туши `--ink`, зелёный акцент, киноварный Error. Новых независимых палитр интерфейса нет: используются роли общей темы, включая обе темы и контрастные парные On-роли. Цветные иллюстрации и кот сохраняются. Шрифт и шкала — существующий каталог; японские записи имеют `lang="ja"`.

Композиция: один компонент строки/деталей слова, сетка 8/16/24, плавающее основное действие справа снизу, достаточная прокрутка под кнопкой. Формы остаются спокойными; эмоциональный акцент сосредоточен на маскоте и цветных канцелярских изображениях главной, а не на дополнительных декоративных рамках.

## Решения по замечаниям

1. Детали словаря уже используют `CatalogSelection.wordDetails`, список словаря и выбор слов — `wordRow`. Превью слов тренировки и остальные списки используют тот же `wordRow` без отдельной типографики.
2. Подтверждение материала и селекторов уже плавающее; непрозрачный полноширинный футер не вводится. Для выбора показывается количество, для записи материала сохраняются смысловые «Добавить»/«Обновить», для пустого фильтра — «Применить» (нет ограничения).
3. Написание — однострочный по исходной высоте textarea с автоматическим ростом, без ограничения слов/предложений. Дополнительные переводы остаются отдельным экраном; язык выбирается доступными радиокнопками в диалоге, без ввода кодов и фиктивного «Другой».
4. Проверки письма используют роли Primary/Error, знак результата и спокойный контур. Поле сохраняет пунктирную каллиграфическую сетку. Инструменты и нижние действия переносят текст и сохраняют цели 48 px.
5. Системные настройки — SVG; канцелярские изображения главной согласованы с каталогом. У демонстрационных 1248 есть единица «изученных слов»; число не выдаётся за реальные данные обучения.
6. Наверху параметров — пресеты «Мягкая»/«Стандартная»/«Строгая». Инженерные коэффициенты доступны в закрытом разделе «Параметры алгоритмов». Пресеты — демонстрационные наборы HTML, не изменение алгоритма Android. Ручная настройка имеет отдельное состояние. Переключатели и слайдеры сохраняют нативную клавиатурную/доступную семантику при общей стилизации.

## Проверка

Пройдены регрессии конструктора, каталога, словаря и переходов между модулями. `test_design_unification.cjs` проверяет 15 основных состояний × light/dark × 360/412/480 × 100/130/160% × RU/EN (540 сочетаний): горизонтальное переполнение и ошибки JavaScript. Отдельно проверены закрытый инженерный раздел, применение пресета, ручное значение и синхронизация слайдера, рост длинного японского предложения без потери текста. Общая доступность и все возможные сочетания пользовательских данных этой матрицей не доказываются.
