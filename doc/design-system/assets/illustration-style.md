# Графика согласованного каталога

Характер: светлый кот, зелёная ученическая шапка, мягкий тёмно-зелёный контур, матовые кремовые/шалфейные/голубые заливки и сдержанные красные акценты. Без свечения, рамок-наклеек и внешних теней.

Один набор PNG в обеих темах. Книги отображаются 48 × 48, значки справочников 36 в слоте 48, кот каталога, состояния и пустого поиска 156, конца списка 120. Прозрачные поля сохраняются. Изображения декоративные, подписи передают назначение.

В HTML тёмный контур адаптируется через `catalog-dark-art`: маска тёмных пикселей и замена на #36543D внутри альфа-канала. Маскот дополнительно получает saturate(.82) contrast(.9), в светлой теме brightness(1.04). Это спецификация визуального результата. Для Android подготовить ресурс или стабильное преобразование с проверкой обеих тем, не переносить CSS-фильтр как готовый API.
