# Значки справочников

`kanji-sage.png` с 林 обозначает «Все кандзи», `radical-ochre.png` с 木 — «Ключи Канси». Прозрачные PNG отображаются 36 × 36 в общем слоте 48 × 48. Назначение передаётся локализованной подписью; значки декоративные.

Один набор в обеих темах, общая [адаптация контура](../illustration-style.md). Плоские SVG-замены, рамки и светящиеся каймы не добавляются. Промпты фиксируют происхождение выбранных изображений.
