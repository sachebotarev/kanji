# Системные иконки Material Round

Готовая пара Google Material Icons Round для поиска глав. Исходные SVG сохранены без изменения геометрии, размер 24 × 24. Лицензия [Apache 2.0](LICENSE).

| Файл | Назначение | Источник |
| --- | --- | --- |
| [search-round.svg](search-round.svg) | Открыть поиск | [Google: search](https://github.com/google/material-design-icons/blob/master/src/action/search/materialiconsround/24px.svg) |
| [search-off-round.svg](search-off-round.svg) | Скрыть поиск | [Google: search_off](https://github.com/google/material-design-icons/blob/master/src/action/search_off/materialiconsround/24px.svg) |

В рабочем HTML пара встроена как inline SVG с currentColor и aria-hidden. Кнопка имеет размер 48 × 48 и локализованные доступные подписи «Найти главу» / «Скрыть поиск». Цвет остаётся активным в обеих темах. Search_off скрывает поле и очищает запрос, верхняя стрелка выполняет обычный возврат. Символы поиска не относятся к рисованным предметным иллюстрациям: это функциональные знаки системной навигации.
