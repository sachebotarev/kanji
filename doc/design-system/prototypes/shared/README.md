# Общий просмотрщик дизайна

[Единый просмотрщик](../index.html#home): [каталог](../index.html#catalog), [тема приложения](../index.html#theme). Все 28 экранных вариантов не согласованы.

Общая конфигурация цветов и стилей — `../../theme/theme-source.json`; статусов — `../../theme/screens.json`. `material-theme.css` и JSON генерируются из исходника; `material-components.css` связывает роли с компонентами двух просмотрщиков. Цветовые литералы не объявляются в экранных CSS.

`theme-controls.js` загружает конфигурацию и локальный черновик цветов. `material-colors.js` — локальный пакет HCT-алгоритмов, собранный из официальных Material Color Utilities. Внешнего CDN/API для пересчёта нет. `theme-preview.html` даёт четыре color picker и HEX-поля, две темы, предупреждение контраста, экспорт и сброс. Локальный черновик синхронизируется между вкладками. Он привязан к исходной базовой палитре: новая конфигурация проекта не скрывается старым черновиком.

`screen-review.js` читает статус из общего реестра. Согласование не хранится в sessionStorage и не зависит от выбранной темы. Ошибка реестра не даёт согласования. Уведомления статусов расположены вне телефона. [Изменение конфигураций](../../theme/README.md), [проверка](../../../verification/material-theme/README.md).

Запускать HTTP-сервер для всей `doc/`. `file://` не поддерживается из-за fetch конфигурации, реестра и KanjiVG. Исторические снимки доступны по отдельным ссылкам и не подменяют текущий макет.

Общая оболочка описана в [prototypes/README.md](../README.md). Рендереры встраиваются через `viewer-bridge.js`; их внутренние панели скрываются `viewer-embed.css`. Старые публичные пути перенаправляются через `viewer-entry.js`.
