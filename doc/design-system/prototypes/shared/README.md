# Инструменты просмотра

[Макет каталога](../textbooks/README.md) синхронизирован с нативным приложением. Все 17 экранов переданы на повторное согласование. Статусы читаются из `review-status.json`; тема, ширина, масштаб, язык и состояние загрузки не меняют согласование.

Прототип `web/` обслуживает главную, практику и личный словарь. `screen-review.js` остаётся его инфраструктурой сравнения; каталог этот переключатель не использует. Общие уведомления `screen-review.css` находятся вне интерфейса телефона.

Требования и статусы каталога — [реестр экранов](../../05-screens/catalog/README.md). Системные возможности и доступность проверяются в Android. Оба прототипа запускаются сервером для всей директории `doc/`, как указано в их README.
