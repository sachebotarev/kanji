# Каталог: макет для повторного согласования

Текущий интерактивный макет отражает реализованные экраны каталога. Все 17 экранов имеют статус **«Не согласовано»**: у 13 изменены основные подписи, компоненты или варианты содержимого; у остальных актуализированы общие состояния загрузки и ошибки.

Статусы, названия и причины пересмотра хранятся в [едином реестре](../../05-screens/catalog/review-status.json). Прототип читает его при открытии. Предыдущий выбор варианта в sessionStorage не может сделать экран согласованным. Фильтр «Требуют согласования» и пояснения находятся вне интерфейса телефона.

## Открыть

Из корня репозитория:

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory doc
```

- Макет: http://127.0.0.1:8766/design-system/prototypes/textbooks/
- Обзор экранов и снимки Android: http://127.0.0.1:8766/design-system/05-screens/catalog/review/
- Остальные модули: http://127.0.0.1:8766/design-system/prototypes/web/

Сервер обслуживает всю `doc/`, чтобы работали ссылки на снимки и проверки. Открытие через `file://` не поддерживается: макет загружает реестр статусов и KanjiVG через fetch.

Доступны две темы, ширины 360/411/480, масштаб текста 100/130/160%, ru/en и русский fallback. Согласование фиксируется только после явного решения пользователя в реестре; браузер не записывает согласование в исходные файлы.

## Устройство и обновление

- `app.js`: реальные данные, поиск, фильтры, навигация и просмотр статусов.
- `screens.js`: текущие композиции и HTML-компоненты.
- `styles.css`, `components.css`, `tokens.css`: каркас, компоненты и токены.
- `assets/catalog.js`: экспорт каталога, подготовленных переводов и Android-ресурсов.
- `../../review_catalog.py`: генерация реестра экранов в Markdown и обзорной страницы. Статус самовольно не меняет.

Обновить данные и документацию:

```sh
python3 doc/design-system/prototypes/textbooks/export_catalog.py
python3 doc/design-system/review_catalog.py
node doc/design-system/prototypes/textbooks/test_content.cjs
```

Внутренний ключ рендерера `wip` сохранён для CSS. Он не является статусом согласования. Недоступные варианты старого рендера удалены. Общий прототип `web/` продолжает обслуживать главную, практику и личный словарь.

## Границы

Данные экспортируются из read-only seed и подготовленного `data/catalog/content`. Изменения не меняют БД приложения. Загрузка/ошибка переключаются вручную. HTML не воспроизводит системную клавиатуру, TalkBack, уничтожение процесса и физику Compose. Масштаб HTML не заменяет нативную проверку.

Текущее устройство Android: [контракт интерфейса](../../../implementation/catalog-ui.md), [архитектура presentation](../../../decisions/catalog-presentation.md). Прежние снимки в `approved/` — исходная редакция для сравнения, не согласование текущего макета.
