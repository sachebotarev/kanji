# Основной дизайн-макет

Все экранные варианты **не согласованы**. Общая Material 3 тема применяется к главной, тренировке, словарю, конструктору, настройкам и связанным диалогам. Android-код не менялся.

## Открыть

Публичный вход — [единый просмотрщик](../index.html#home): http://127.0.0.1:8767/design-system/prototypes/ . Страница показывает первый экран приложения и переходы к фичам. [Запуск и устройство](../README.md). Старые ссылки этого модуля перенаправляются в общую оболочку. `?standalone=1` используется только для тестирования рендерера.

## Содержание

Главная, практика, список/карточка/создание/редактирование личного слова; список конструктора с 10 рецептами и редактором; настройки приложения с состоянием японской модели и отдельный экран параметров проверки. Каталог открывается в другом разделе того же просмотрщика и использует ту же тему. Две схемы, три ширины, увеличенный текст и ru/en.

Работают поиск словаря, валидация и CRUD в памяти страницы, подтверждения удаления/выхода, несколько переводов по `language_tag`. Перевод разрешается с русским fallback. Слова, выражения и предложения сохраняют полное содержание.

Конструктор поддерживает несколько источников, фильтры, объединение без повторов в наборе, число заданий независимо от его объёма, режимы повторения и время на слово. Карточки одинакового размера; выбрана одна с лапкой; создание — закреплённая FAB. Полное название доступно в подробностях. [Контракт](../../05-screens/training-builder.md).

Практика принимает штрихи и показывает переключаемые демонстрационные результаты. Реальная проверка почерка, очередь сессии и таймер не выполняются. Настройки меняются только в памяти макета и не влияют на Android. Модель не скачивается: состояние задаётся в панели просмотра.

Цвета на всех экранах меняются через «Тема приложения». Согласование читается из отдельного `screens.json`; статус показывается вне телефона. Старый переключатель согласованного рендера не используется.

## Источники ресурсов

- Кот и иллюстрированные иконки — существующие PNG из `feature/dashboard` и `core/designsystem`, скопированы без изменения.
- Roboto — `/system/fonts/Roboto-Regular.ttf` запущенного Android-эмулятора; приложена лицензия Roboto из googlefonts/roboto.
- Эталоны — KanjiVG из assets проекта, Ulrich Apel; лицензия CC BY-SA 3.0 и исходное уведомление сохранены в `assets/KanjiVG-*`. https://kanjivg.tagaini.net/
- `assets/catalog-data.js` — статический фрагмент каталога приложения: полные главы и кандзи, первые восемь слов главы. Сохранено уведомление `assets/Catalog-NOTICE.txt`. Модель переводов использует `language_tag`.
- Начальный личный словарь и статистика — демонстрационные данные, не результаты пользователя.
