# HTML-прототип экранов v1

Локальный дизайн-артефакт для обсуждения. Направление главной согласовано; остальные экраны — предварительные варианты, не утверждённые спецификации Compose. HTML не заменяет действующую реализацию Android.

## Открыть

Из корня проекта:

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory doc
```

- Интерактивные экраны: http://127.0.0.1:8766/design-system/prototypes/web/
- Каталог для повторного согласования: http://127.0.0.1:8766/design-system/prototypes/textbooks/
- Снимки эмулятора: http://127.0.0.1:8766/design-system/01-audit/captures/2026-11-01/

`index.html` также можно открыть локальным файлом: прототип не использует CDN, сборщик или backend.

## Содержание

Пять экранных композиций этой страницы: главная, тренировка, список личного словаря, карточка записи и редактор. Учебники открываются в [отдельном модуле](../textbooks/index.html), чтобы не смешивать текущую компоновку с прежней визуальной заготовкой. Работают переходы, две темы, три ширины, увеличенный текст, длинное название тренировки и русский/английский интерфейс. Панель настройки макета находится вне экрана приложения.

Словарь: поиск, создание, изменение, подтверждение удаления, подтверждение выхода с изменениями, несколько переводов по `language_tag`, валидация обязательных полей, повторных языков и дубликатов. Перевод разрешается по выбранному языку с русским fallback. Записи допускают слова, выражения и предложения. Изменения хранятся только в памяти страницы, перезагрузка их сбрасывает.

Каталог перенесён в [отдельный HTML-модуль](../textbooks/index.html), восстановленный по текущему Compose-коду и полной базе проекта. Переходы «Каталог», «Учебник» и «Глава» ведут туда. [Состав и ограничения](../textbooks/README.md).

Тренировка: поле принимает штрихи мышью/указателем, можно сменить ячейку, отменить штрих, очистить и включить эталон KanjiVG соответствующего знака. Реальной проверки почерка нет. Внешний переключатель задаёт демонстрационные состояния. «Все знаки верны» показывает завершённое задание, а не разрешает переход после одного верного знака. Изображение принятого знака в этом состоянии — эталон, а не результат распознавания. Полноценная сессия, таймер, настройки чекеров, системная клавиатура и жизненный цикл Android не моделируются.

## Источники ресурсов

- Кот и иллюстрированные иконки — существующие PNG из `feature/dashboard` и `core/designsystem`, скопированы без изменения.
- Roboto — `/system/fonts/Roboto-Regular.ttf` запущенного Android-эмулятора; приложена лицензия Roboto из googlefonts/roboto.
- Эталоны — KanjiVG из assets проекта, Ulrich Apel; лицензия CC BY-SA 3.0 и исходное уведомление сохранены в `assets/KanjiVG-*`. https://kanjivg.tagaini.net/
- `assets/catalog-data.js` — статический фрагмент каталога приложения: полные главы и кандзи, первые восемь слов главы. Сохранено уведомление `assets/Catalog-NOTICE.txt`. Модель переводов использует `language_tag`.
- Начальный личный словарь и статистика — демонстрационные данные, не результаты пользователя.

## Проверки

Компоновка и сценарии проверяются Chrome/Playwright; актуальный объём проверки указан в `validation.json`. Для учебников есть отдельный отчёт в соответствующем модуле. Проверены поиск словаря, создание ru/en записи, отмена изменений, английский перевод, штрих на canvas, доступность завершения по выбранному состоянию и переходы каталога. Результаты в `validation.json`; изображения `*-light.png` и `*-dark.png` — снимки HTML, а не Android.

Эта проверка не подтверждает доступность нативного приложения, контраст всех состояний, масштабирование Android, переносы и японские шрифты на разных устройствах. CSS px используются для моделирования логической геометрии; они не эквивалентны физическим пикселям скриншота эмулятора.

## Варианты экранов

Каждый экран имеет переключатель «Текущий · как в приложении» / «Согласованный» / «В работе». Текущая реализация показана датированным снимком Android, интерактивный HTML находится в рабочем варианте. Отсутствие снимка состояния или согласованного эталона обозначается в панели просмотра без подмены другим дизайном. Выбор хранится отдельно для каждого экрана. [Правила и ограничения](../shared/README.md).
