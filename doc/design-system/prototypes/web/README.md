# Основной дизайн-макет

Экраны этого модуля согласованы 2026-11-07, **кроме** настроек (`SETTINGS` / `SETTINGS.01`). Канонические статусы — `../../theme/screens.json`. [Проверки конструктора](../../../releases/1.0.0.md), [контракт переноса](../../../implementation/approved-ui-handoff.md). Общая Material 3 тема применяется ко всем экранам модуля.

## Открыть

Публичный вход — [единый просмотрщик](../index.html#home): http://127.0.0.1:8767/design-system/prototypes/ . Страница показывает первый экран приложения и переходы к фичам. [Запуск и устройство](../README.md). Старые ссылки этого модуля перенаправляются в общую оболочку. `?standalone=1` используется только для тестирования рендерера.

## Содержание

Главная, практика, список/карточка/создание/редактирование личного слова; список конструктора с 11 рецептами и редактором; настройки приложения с состоянием японской модели и отдельный экран параметров проверки. Каталог открывается в другом разделе того же просмотрщика и использует ту же тему. Две схемы, три ширины, увеличенный текст и ru/en.

Работают поиск словаря, поиск рецептов по названию и источникам, валидация и CRUD в памяти страницы, подтверждения удаления/выхода, несколько переводов по `language_tag`. Поиск рецептов открывается лупой в шапке и использует общее поле каталога, очистку и состояние без совпадений. Перевод разрешается с русским fallback. Слова, выражения и предложения сохраняют полное содержание.

Конструктор поддерживает несколько источников, фильтры, объединение без повторов в наборе, число заданий независимо от его объёма, режимы повторения и время на слово. Список использует нейтральные карточки без обводки с высотой по содержимому; выбрана одна с заполненным круглым переключателем. Рецепт выбирается только круглым переключателем слева от названия, без диалога и выхода из конструктора; порядок карточек и позиция прокрутки сохраняются. Тап по телу карточки открывает просмотр рецепты и не меняет выбор. «Ещё N» раскрывает состав и тоже не меняет выбор. Подсветка нажатия применяется только к элементам управления, не ко всей карточке. Overflow-меню на карточке нет: изменение и удаление — с экрана просмотра. Hover-состояния не используются; обратная связь показывается при нажатии. Запрос поиска сохраняется. Перенос начинается удержанием тела карточки 450 мс и продолжается перетаскиванием мышью или пальцем. Меню экрана, отдельного режима, ручек, «Готово», инструкций и видимых сообщений о позициях нет. Движение до срабатывания удержания оставляет обычную прокрутку, отпускание применяет порядок, отмена жеста и Escape возвращают исходный. В HTML есть визуально скрытые действия перемещения для экранного диктора и клавиатуры (видимы при фокусе); результат озвучивается невидимым live region. Нативные действия TalkBack в Android ещё не реализованы. Выбор рецепты не меняется. Перетаскивание работает при пустом поисковом запросе. Доступные действия перемещения меняют соседние позиции полного списка. Порядок хранится до перезагрузки страницы. Создание — закреплённая FAB. Названия переносятся без обрезки. Метки состава строятся из существующих полей источников: конкретный учебник, главы, JLPT кандзи, знак или учебная запись. Источники сохраняют собственные группы; в карточке видны максимум два тега и «Ещё N», остальное раскрывается внутри неё. «Большое повторение» содержит десять реальных непустых источников. Название рецепта не определяет метки. [Контракт](../../05-screens/recipe-builder.md).

Практика принимает штрихи и показывает переключаемые демонстрационные результаты. Реальная проверка почерка, очередь тренировки и таймер не выполняются. Настройки меняются только в памяти макета и не влияют на Android. Модель не скачивается: состояние задаётся в панели просмотра.

Цвета на всех экранах меняются через «Тема приложения». Согласование читается из отдельного `screens.json`; статус показывается вне телефона. Старый переключатель согласованного рендера не используется.

## Источники ресурсов

- Кот и иллюстрированные иконки — существующие PNG из `feature/dashboard` и `core/designsystem`, скопированы без изменения.
- Roboto — `/system/fonts/Roboto-Regular.ttf` запущенного Android-эмулятора; приложена лицензия Roboto из googlefonts/roboto.
- Эталоны — KanjiVG из assets проекта, Ulrich Apel; лицензия CC BY-SA 3.0 и исходное уведомление сохранены в `assets/KanjiVG-*`. https://kanjivg.tagaini.net/
- `assets/catalog-data.js` — статический фрагмент каталога приложения: полные главы и кандзи, первые восемь слов главы. Сохранено уведомление `assets/Catalog-NOTICE.txt`. Модель переводов использует `language_tag`.
- Начальный личный словарь и статистика — демонстрационные данные, не результаты пользователя.
