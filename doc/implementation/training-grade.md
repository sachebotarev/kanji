# Оценка завершённой тренировки

Статус: алгоритм и макет PRACTICE.01 предложены; Android-экран использует тот же расчёт. Согласование HTML — отдельно.

Балл слова считается по числу подсказок на кандзи и раскрытию чтения — [hint-scoring.md](hint-scoring.md).

## Назначение

После успешного прохождения всех заданий показать краткую статистику и одну из трёх оценок с соответствующим маскотом. Оценка мотивирует, а не ранжирует пользователя публично.

## Вход

Терминальные задания завершённой тренировки (`correct` / `assisted` / `skipped` / `timed_out`) плюс поля подсказок:

- `training_task_symbols.hint_request_count` на practice-символах;
- `training_tasks.reading_hint_used`;
- лимит `H` = `training.maxNextStrokeHints` (сохраняется в агрегате `Training` из `RecognitionSettings.maxNextStrokeHints` при старте, по умолчанию 3). По умолчанию `Training.summarize()` использует этот сохранённый лимит, обеспечивая воспроизводимость оценки как сразу после прохождения, так и при открытии из истории тренировок.

Незавершённые (`pending` / `in_progress`) на экране итога не ожидаются.

## Баллы за задание

Непрерывные `wordPoints` — см. [hint-scoring.md](hint-scoring.md). Кратко:

| Статус задания | Балл | Смысл |
| --- | --- | --- |
| `correct` | 1.0 | Слово закрыто без учтённой помощи |
| `assisted` | `avg(1 − k/H) × (0.85 если чтение)` | Закрыто с подсказками; шкала по `k` |
| `timed_out` | 0.25 | Время истекло; была попытка |
| `skipped` | 0.0 | Пропуск / incorrect cells |

Проценты:

```text
percent = round(100 × Σ wordPoints / N)
```

`N` — число заданий в тренировке (`N ≥ 1`). Округление — до ближайшего целого.

## Три уровня

| Уровень | Условие | Подпись (RU) | Маскот |
| --- | --- | --- | --- |
| `excellent` | `percent ≥ 85` | Отлично | `mascot_sticker_completed_sheet` |
| `steady` | `55 ≤ percent < 85` | Хорошо | `mascot_sticker_encourage` |
| `keep_going` | `percent < 55` | Ещё потренируемся | `mascot_sticker_jp_shodo_retry` |

Пороги фиксированы в коде и макете; смена требует обновления обоих.

## Краткая статистика на экране

- Название рецепта (снимок; RU fallback).
- Процент и текстовая оценка.
- Числа: верно / с подсказкой / пропуск / по времени.
- Суммарное время заданий (`Σ elapsed_ms`).
- Одно действие: «На главную».

Без списка слов, без вердиктов по знакам и без сравнения с прошлыми тренировками на этом экране.
