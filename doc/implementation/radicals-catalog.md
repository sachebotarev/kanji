# Каталог иероглифических ключей

Дата: 20 октября 2026 года.

Данные: [`data/catalog/radicals.csv`](../../data/catalog/radicals.csv).

## Формат

UTF-8 без BOM, разделитель — запятая, окончания строк LF. Четыре столбца:

- `Номер` — традиционный словарный номер ключа Канси (1–214).

- `Ключ` — один символ полной традиционной формы ключа.
- `Название` — русское смысловое название.
- `Количество черт` — целое число черт полной формы, указанной в первом столбце.

214 записей следуют традиционному порядку ключей Канси. Номер определяется соответствием ключу в системе Канси, а не текущей позицией строки. Используются обычные иероглифы, соответствующие NFKC-нормализации блока Kangxi Radicals U+2F00…U+2FD5.

Сокращённые и позиционные варианты (亻, 氵, 忄, 艹, 辶 и другие) отдельными записями не добавлены. Число черт полной формы нельзя применять к её сокращённому варианту. Традиционные 戶, 靑, 黃, 黑 и другие не заменяются современными японскими формами без отдельного учёта вариантов. Это справочник ключей, а не готовый список современных японских начертаний для тренировки.

Файл хранится в каталоге `data/catalog/`, без отдельного Gradle-модуля. Каталог подключён к `main.assets` приложения; в APK файл доступен как `assets/radicals.csv`. Копии CSV в других каталогах не поддерживаются. См. [учебный каталог кандзи](kanji-catalog.md).

## Названия и источники

Статус русских названий: **предварительные смысловые названия; полная академическая сверка не завершена**. Восстановлена версия до изменений по разделу специальных названий Фельдман-Конрад.

### Локальный справочный материал

Пользовательский скан Фельдман-Конрад (2-е издание, 1977), OCR печатных страниц 14–17 и таблица специальных названий сохранены в игнорируемом каталоге `doc/dictionaries/local/feldman-konrad/`. Раздел содержит пояснения и названия вариантов, которые нельзя автоматически принимать за единый перечень русских названий 214 ключей. Изменения 28 названий по этому разделу отменены; материал не подтверждает текущий столбец `Название`.

Для ручного изучения доступна [локальная таблица со сканами](../dictionaries/local/feldman-konrad/keys-reader.html). Исходный PDF не изменён. Полный OCR всех 682 страниц не выполнялся.

Материалы, найденные при подготовке:

- [Н. И. Фельдман-Конрад. Японско-русский учебный словарь иероглифов, 2007](https://ru.djvu.online/file/1ueB5hburJVhO), ISBN 978-5-8033-0391-6 — академический ориентир для последующей сверки. Поисковая выдача подтвердила наличие таблицы ключей, но полный текст получить не удалось; построчная сверка названий по этому изданию не заявляется.
- [Н. Д. Неверова и др. Краткий японско-русский словарь иероглифов, 1990](https://ru.djvu.online/file/i9MBHUGi5UVGI), ISBN 5-200-01102-7 — дополнительный словарный ориентир; полного доступа к таблице также не было.
- [Таблица иероглифических ключей Japlang](https://www.japlang.ru/hieroglyphs/_keys.html) — доступный учебный справочный материал; не доказательство академической стандартизации всех названий.
- [Список ключей Канси](https://ru.wikipedia.org/wiki/Список_ключей_Канси) — вспомогательная справка по традиционной системе.

Полная академическая сверка всех 214 русских названий остаётся задачей дальнейшей редакции.

## Проверка данных

Проверено стандартным CSV-парсером Python: ровно четыре столбца, 214 непустых уникальных ключей, соответствие порядка NFKC-нормализации блока Unicode Kangxi Radicals, положительные целые количества черт и традиционное число ключей в каждой группе от 1 до 17 черт. Это структурная проверка, она не подтверждает академическую терминологию и индивидуальную технику написания.

Номера всех 214 ключей сверены с блоком [Unicode Kangxi Radicals](https://www.unicode.org/charts/PDF/U2F00.pdf): номер равен смещению символа ключа от U+2F00 плюс 1; полная форма в CSV проверяется через NFKC. Дополнительно связи всех 3000 кандзи проверяются по полю `rad_type="classical"` KANJIDIC2. Это номера ключей, а не номера статей конкретного словаря.
