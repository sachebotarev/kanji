# HOME.W02 — Следы тренировок за день

Кольцо на главной показывает завершённые задания **текущего локального дня**.

## Сегменты

| Цвет | Статус задания | Подпись |
|---|---|---|
| Зелёный (`primary`) | `correct` | Верно |
| Жёлтый `#E4B94F` | `assisted` | С подсказкой |
| Красный (`error`) | `skipped` или `timed_out` | Пропуск или таймаут |

Число в центре — сумма трёх сегментов за сегодня (слова, не кандзи и не «задания»). Подпись карточки: «слова дня» / «today's words». Размер карточки совпадает с `HOME.W03` (заголовок + подпись + область 116 dp).

Источник: `TrainingsRepository.observeCompletedTasks()` → `wordStatisticsForDay`. Тап по виджету открывает `HOME.02` с периодом «Сегодня».
