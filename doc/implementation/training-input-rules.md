# Правила ввода на тренировке

Канонический список бизнес-правил, которые решают, **нужен ли рукописный ввод** по позиции в слове, и смежные ограничения запуска. Код: `TrainingInputRules` в `:domain:catalog`. Host PRACTICE только вызывает эти функции — не дублирует условия.

Смежные, но отдельные темы: [таймер слова](practice-screen.md#время), [подсказки](hints.md), [оценка](hint-scoring.md), [таймаут ячеек](practice-screen.md) (`HandwritingTraining.settleTimedOut` в `:domain:practice`).

## Режим ячейки: `User` или `Prefilled`

По каждому непробельному символу написания независимые ограничения объединяются по **И**:

**`User` (нужна рукопись)** только если одновременно:

1. символ **есть** в каталоге кандзи;
2. **и** проходит ограничение по учебникам и главам (или оно выключено);
3. **и** проходит ограничение по JLPT (или оно выключено).

Иначе ячейка **`Prefilled`** (глиф показан, ввода нет). Любое невыполненное условие достаточно для `Prefilled`; несколько активных ограничений не «перекрывают» друг друга через ИЛИ для права писать.

Пробелы в написании в ряд ячеек **не** попадают (отбрасываются до правил).

| Ограничение | Когда активно | Когда **не** проходит → `Prefilled` |
| --- | --- | --- |
| Каталог | всегда | символ не кандзи каталога (кана, пунктуация, прочее) |
| Учебники / Главы | в рецепте есть хотя бы один материал `book` | знак не привязан к выбранному учебнику ИЛИ его глава в учебнике строго больше max выбранных |
| JLPT | материал `kanji` с точными уровнями `1…5` в `jlptLevels` | JLPT знака **сложнее** потолка (меньшее число: N1 сложнее N5); без JLPT в каталоге = N1 |

## Запуск слова

| # | Правило |
| --- | --- |
| 4 | Слово без **ни одной** `User`-ячейки в очередь тренировки **не** попадает |
| 5 | Пул слов — `recipeWords` / `shuffledCycles`; отбор writable — после конъюнкции выше |
| 6 | Лимит времени слова: `seconds_per_symbol ×` число `User`-ячеек (код `wordTimeLimitMs`, экран — [practice-screen.md](practice-screen.md)) |

## Учебники и главы

- Ограничение активно, если в рецепте есть хотя бы один материал типа `book` (`sourceId != null`). Если материалов `book` нет — ограничение по учебникам выключено.
- Для каждого выбранного учебника (`sourceId`):
  - если заданы главы (`chapters` не пуст) — вычисляется **максимальная выбранная глава** (объединяются все book-материалы этого учебника);
  - если ограничение по главам не задано (`chapters` пуст) — ограничение по главам для этого учебника не накладывается (весь учебник).
- Символ помечается как **`User`** (активная ячейка, заполняется пользователем), если кандзи привязан к выбранному учебнику и вводится в нём **до (включительно) максимальной выбранной главы** (`chapter <= maxChapter`, либо главы не ограничены).
- Если кандзи **не привязан к выбранному учебнику** — он отмечается как **`Prefilled`**.
- Если ограничение по главам не задано, но кандзи **не привязан к выбранному учебнику** — он также отмечается как **`Prefilled`**.

## JLPT

- Считается только материал типа `kanji` с непустым `jlptLevels` (точные уровни 1…5; значение `-1` — «нет данных JLPT» в фильтре набора, **не** задаёт потолок сложности).
- Потолок — **самый сложный** среди выбранных точных уровней: минимальное число (`N5=5`…`N1=1`). Несколько kanji-материалов объединяются.
- Знак с `jlpt_level` **строго меньше** потолка (сложнее) → ограничение **не** пройдено.
- У знака нет JLPT в каталоге → как **N1** (самый сложный).
- Пустой `jlptLevels` → ограничение выключено.

## Как менять

1. Обновить этот файл (сохранить формулировку **И** между ограничениями).
2. Править только `TrainingInputRules` (+ тесты `TrainingInputRulesTest`).
3. Host (`TrainingLaunch`) не добавлять новых `if` по главам/JLPT/каталогу — только вызов `requiresHandwriting` / `hasWritableCell`.
