# Согласованный UI: контракт передачи в Android

Дата согласования: **2026-11-07** (обновление к 2026-11-04). Канонические статусы: [screens.json](../design-system/theme/screens.json).

Согласованы экраны разделов `home`, `catalog`, `references`, `dictionary`, `recipe-builder`, `practice`, `shared`. **Не согласованы только `SETTINGS` и `SETTINGS.01`.** Общие экраны переиспользуются по контексту. Согласование макета не означает готовую Android-реализацию.

## Область реализации

Реализовать навигацию, каталог/справочники, личный словарь с переводами и тегами, создание/редактирование/выбор/перестановку рецептов, главную с разделением запуска и рецептов тренировок, выбор рецепта (`HOME.01`) и общие селекторы.

**Не реализовывать сейчас** полноценное исполнение тренировок по рецепту, генератор заданий, результаты и хранилище статистики — макет PRACTICE/PRACTICE.01 согласован, но продуктовый этап исполнения остаётся отдельным. Числа статистики на главной остаются демонстрационными.

**Настройки** (`SETTINGS` / `SETTINGS.01`) — вне текущего согласования; не считать макет эталоном для переноса без нового решения.

## Навигация и общие компоненты

На главной: «Учебники», «Справочники», «Мой словарь», «Рецепты тренировок», запуск тренировки. [Проверки разделов](../verification/library-sections-android.md), [корни BOOKS/REFS/DICT](../verification/roots-html-parity.md).

1. Одна карточка/строка слова для каталога, словаря, выбора и предпросмотра.
2. Общие селекторы кандзи/глав/ключей/JLPT/черт/слов/тегов; Apply подтверждает, Back отменяет.
3. Контекст карточки кандзи зависит от корня (учебник / личный / глобальный).
4. Не переносить `sessionStorage`, JS sentinel и viewer hash как контракты Android.

## Словарь и черновики

Написание/чтение допускают выражения и предложения. Основной перевод — текущий язык; RU — fallback. Теги — стабильные ID и семь цветовых ролей. [Теги](../verification/dictionary-tags-android.md), [переводы](../verification/dictionary-translations-android.md).

## Рецепты

Радиокнопка постоянного выбора убрана. Выбор для тренировки — на `HOME.01`. Long-press + drag меняют порядок. Материал: учебник, словарь, кандзи, точные слова. Параметры количества и секунд хранятся, но не запускают исполнение без отдельного этапа PRACTICE.

Пустой `HOME.01` ведёт в создание первого рецепта (`RECIPE.01`), не только в список.

## Данные и последовательность

Действующая схема — Room v7: каталог, теги, рецепты и хранение тренировок. Модели: [личный словарь](../database/personal-dictionary.md), [рецепты](../database/recipes.md), [тренировки](../database/trainings.md).

Приложение не выпущено. По решению пользователя от 2026-11-04 **миграции не реализуются**: при несовместимой версии Room пересоздаёт базу (`fallbackToDestructiveMigration(dropAllTables = true)`).

Подключённые срезы (словарь, каталог, конструктор, главная с разделением запуска) описаны в соответствующих verification-отчётах; полный TalkBack и визуальная матрица всего приложения остаются незавершёнными.

## Приёмка реализации

- Светлая/тёмная темы; 360/412/480 dp; font scale 1/1.3/1.6; RU/EN; без горизонтального переполнения.
- TalkBack, цели ≥48 dp, системный Back и отмена черновиков.
- Unit/DAO и навигационные/UI-тесты общих компонентов.
- Изменение согласованного дизайна требует нового согласования. Текущие статусы **не** распространяются на SETTINGS/SETTINGS.01.
