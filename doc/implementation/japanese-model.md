# Загрузка японской языковой модели

20 октября 2026.

`KanjiApplication.onCreate` запускает проверку наличия японской модели ML Kit и скачивает её при отсутствии. Загрузка принадлежит application scope, не блокирует интерфейс, не зависит от включения чекера читаемости и не отменяется при навигации или пересоздании Activity. Уже загруженная модель повторно не скачивается; параллельные запросы объединяются текущим состоянием загрузки.

Подтверждение скачивания и диалог прогресса удалены. Только ошибка показывает закрываемое сообщение: модель можно повторно загрузить в настройках. Без модели читаемость выключена и её включение недоступно с пояснением «Нет японской языковой модели. Сначала загрузите её в настройках» в обоих входах в настройки проверки. При ошибке загрузки выключенное состояние сохраняется; после успешной повторной загрузки читаемость можно включить вручную. Ошибка хранится в StateFlow до подтверждения пользователем или новой попытки.

На общем экране настроек кнопка отображает статус: «Не загружена · Скачать», «Загружается…», «Загружена». Нажатие доступно только при отсутствии модели. После успешной загрузки открытая практика перепроверяет результаты. Пока модель недоступна, проверка читаемости использует существующий результат Unavailable.

JVM-тесты проверяют отсутствие повторного скачивания, ошибку/повторную попытку и защиту от одновременных запросов. Проверка навигации больше не ожидает прежний диалог отключения читаемости.
