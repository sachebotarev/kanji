# Оценка задания с подсказками

Статус: подключено к `TrainingTask.wordPoints`, `Training.summarize`, диалогу помощи PRACTICE и итогу PRACTICE.01.

## Лимит и стоимость помощи

Пользователь задаёт лимит `H` через `RecognitionSettings.maxNextStrokeHints`. Он определяет число доступных подсказок на знак. Значение сохраняется в `Training`; 0 отключает вызов помощи. Лимит не определяет стоимость подсказки.

Число засчитанных показов `k` хранится в `training_task_symbols.hint_request_count`. Каждый показ уменьшает оставшийся балл на 20%. Выключение подсказки и бесплатный просмотр эталона уже принятого знака не увеличивают `k`.

## Балл знака

```text
correct: cell = 0.8^k × shapeFactor
shapeFactor = 0.8 при shape_verdict = accepted_with_penalty, иначе 1.0
incorrect / empty / editing: cell = 0
```

Предзаполненные знаки не входят в средний балл. Тип подсказки (полный знак или следующая черта) не меняет стоимость.

| Засчитано подсказок | Балл при верном ответе | Округлённый процент |
| --- | --- | --- |
| 0 | 1.0 | 100% |
| 1 | 0.8 | 80% |
| 2 | 0.64 | 64% |
| 3 | 0.512 | 51% |
| 5 | 0.32768 | 33% |
| 12 | 0.068719476736 | 7% |

Первая подсказка оставляет 80% при любом пользовательском лимите. При расходовании всего лимита помощь отключается, но самостоятельное письмо продолжается. Правильно завершённый знак сохраняет ненулевой балл для всех поддерживаемых лимитов 0–12. Округление применяется только при отображении, промежуточные значения остаются `Double`.

## Балл задания

```text
kanjiAvg = среднее(cell) по practice-символам
           (если practice-символов нет — 1.0)
readingFactor = 0.85, если чтение раскрыто как подсказка, иначе 1.0
translationFactor = 0.85, если перевод раскрыт как подсказка, иначе 1.0
wordPoints = kanjiAvg × readingFactor × translationFactor
```

| Пример для двух требуемых знаков | Чтение | Балл задания |
| --- | --- | --- |
| Оба верно, без помощи | скрыто | 1.00 |
| Оба верно, без помощи | открыто как подсказка | 0.85 |
| Оба верно, одна подсказка на первый знак | скрыто | 0.90 |
| Оба верно, по одной подсказке | открыто как подсказка | 0.68 |
| Оба верно, по две подсказки | скрыто | 0.64 |
| Один верно с одной подсказкой, второй неверно | скрыто | 0.40 |

В режиме «Без подсказок» перевод и чтение открыты сразу, соответствующие штрафы не применяются. Пропуск и таймаут сохраняют баллы за правильно решённые знаки. Таймаут сам не устанавливает флаги текстовых подсказок.

## Статус и итог тренировки

- Все требуемые знаки приняты без учтённой помощи — `correct`.
- Все приняты с учтённой помощью или мягким принятием формы — `assisted`.
- Пропуск или окончательно неверный знак — `skipped`.
- Истёк срок — `timed_out`.

Статусы определяют счётчики, а не фиксированный балл. Итог: `round(100 × Σ wordPoints / число заданий)`. Пороги оценки: 85 / 55, см. [training-grade.md](training-grade.md).

## Отображение PRACTICE

Помощь показывает использованные обращения `0/3…3/3`: до ввода без помощи нейтральна, после принятия без помощи зелёная, при частичном расходе жёлтая, при полном красная. Лимит 0 отображается как `0/0` и не считается расходом. Миниатюра знака с помощью или мягко принятой формой жёлтая, ошибка написания красная. «Далее» учитывает все знаки: полный успех без помощи зелёный; помощь, чтение/перевод или мягкая форма жёлтые; полный расход помощи хотя бы на одном знаке, ошибка или таймаут красные. Красный расход помощи не меняет формулу балла. В диалогах доступны точный балл и причина штрафа.

Мягкое принятие формы: недобор строго меньше настроенного допуска (по умолчанию 10 п.п.) до настроенного порога, если нет иных ошибок. Штраф применяется один раз и не расходует подсказки. Одна подсказка и мягкая форма дают `0.8 × 0.8 = 0.64`. [Решение](../decisions/shape-soft-acceptance.md).

## Хранение и совместимость

Счётчики подсказок сохраняют своё значение. Мягкая форма хранится отдельно в существующем `shape_verdict`; исходная схема 1 содержит допустимые значения. Итоги вычисляются по сохранённым результатам и числу подсказок при вызове `summarize`, поэтому просмотр существующей истории также использует новую формулу. Историческая версия формулы в БД не хранится. Параметр `maxHints` в API расчёта сохранён для совместимости вызовов и проверки корректности лимита; вес подсказки от него не зависит.

Реализация: `HintScoring.kt`, стандартный `kotlin.math.pow`, доступный с Kotlin 1.2 и совместимый с Kotlin 2.2.10 проекта. Context7 недоступен в этой сессии; проверена [официальная документация Kotlin](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin.math/pow.html). Новые зависимости и experimental API не вводятся.
