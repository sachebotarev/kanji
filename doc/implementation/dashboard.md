# Реализация главной панели (Dashboard)

Модуль `:feature:dashboard` реализует домашний экран приложения. С него пользователь видит общую статистику обучения, отслеживает регулярность занятий, выбирает и настраивает тренировочные наборы и переходит в остальные разделы приложения.

## Архитектурные границы

Модуль спроектирован по принципам Clean Architecture и атомарного Compose UI:

- **Изоляция:** `:feature:dashboard` не зависит от других функциональных модулей (`:feature:catalog`, `:feature:practice`, `:feature:dictionary`, `:feature:settings`).
- **Контракт событий:** вся навигация и запуск действий вынесены в колбэки верхнеуровневого экрана `DashboardScreen`.
- **Сборка графа:** класс `MainActivity` (в модуле `:app`) связывает экран с потоками данных (`StateFlow`) и передаёт лямбды навигации.

## Модели состояния

Модели экрана определены в файлах `DashboardState.kt` и `TrainingOverview.kt`:

### `DashboardState`

Снимок состояния главного экрана объединяет три блока:

1. **`WordStatistics`** — статистика изученных слов:
   - `learned: Int` — слова, написанные безошибочно и без подсказок;
   - `assisted: Int` — слова, написанные с использованием подсказки;
   - `errors: Int` — слова, при вводе которых были допущены ошибки;
   - `total: Int` — общее число пройденных слов (`learned + assisted + errors`).
2. **`ActivityOverview`** — интенсивность занятий:
   - `dailyCounts: List<Int>` — количество выполненных заданий по дням за последние недели (используется для сетки активности);
   - `streakDays: Int` — число дней непрерывных занятий (серия / streak).
3. **`VocabularyOverview`** — состояние учебных материалов:
   - `textbookCount` и `activeTextbooks` — общее и подключенное число курсов/учебников;
   - `personalTotal: Int?` — количество слов в личном словаре пользователя (если `null`, отображается состояние загрузки/подсказка);
   - `personalLearned`, `personalErrors`, `personalAssisted` — статус освоения слов личного словаря.

### `TrainingOverview`

Описывает сохранённую конфигурацию тренировки (пресет):

- `id: String` — идентификатор набора;
- `name: String` — название тренировки (например, «Смешанный набор» или название учебника);
- `wordsPerSession: Int` — целевое количество слов на одну сессию (по умолчанию 10);
- `secondsPerWord: Int` — лимит времени на написание одного знака/слова (по умолчанию 60 с);
- `completedSessionCount: Int` — общее число завершённых сессий по данному пресету.

## Состав компонентов и виджетов

Экран `DashboardScreen` собирается из независимых компонентов пакета `ru.mobui.kanji.feature.dashboard.widgets`:

| Компонент | Назначение | Поведение и диалоги |
|---|---|---|
| **`WordStatisticsWidget`** | Краткая сводка освоения слов (цветовые индикаторы) | По клику открывает диалог `WordStatisticsDialog` с детальной разбивкой по статусам |
| **`ActivityWidget`** | Счётчик дней непрерывных занятий (streak) и мини-график активности | По клику открывает `ActivityDetailsDialog` с развёрнутой сеткой активности по неделям |
| **`CurrentTrainingWidget`** | Карточка текущего выбранного тренировочного пресета | Кнопка «Начать» сразу запускает тренировку; диалог `TrainingPicker` позволяет переключить набор, создать новый (`TrainingEditor`) или открыть историю (`TrainingHistory`) |
| **`VocabularyWidget`** | Блок навигации по словарному запасу | Содержит две секции: переход в каталог учебников (`onOpenCatalog`) и в личный словарь (`onOpenDictionary`) с живым счётчиком слов |
| **`DashboardCard`** | Базовая карточка Material 3 с фоном, скруглением и отступами | Обеспечивает единый визуальный стиль всех виджетов |
| **`IllustratedIcon`** | Иконки виджетов с поддержкой векторных и растровых иллюстраций | Использует адаптивные ресурсы и контурные пиктограммы приложения |

## Интеграция с источниками данных

- **Личный словарь:** количество пользовательских слов `personalTotal` реактивно поступает из Room через `PersonalDictionaryRepository.count` в виде `StateFlow<Int>`. При добавлении или удалении слов на экране словаря счётчик на главной панели обновляется немедленно.
- **Тренировочные пресеты:** список пресетов и активный идентификатор управляются в `TrainingSelectionModel` и сохраняются в состоянии сессии.
- **Статистика и активность:** в текущей версии данные активности инициализируются объектом `DashboardDemo`. С развитием подсистемы истории тренировок демонстрационный источник будет заменён на локальный Room DAO сессий.

## Локализация

Все пользовательские тексты, метки кнопок, заголовки карточек и описания в диалогах вынесены в строковые ресурсы:
- Основная локализация: `res/values/strings.xml` (русский язык);
- Английская локализация: `res/values-en/strings.xml`.

Идентификаторы строк начинаются с префикса `dashboard_` (`dashboard_home`, `dashboard_settings`, `dashboard_words_title`, `dashboard_streak_days` и др.).
