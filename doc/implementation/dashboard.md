# Реализация главной панели

Главная показывает выбранный **рецепт**, счётчик личных слов и отдельные входы «Учебники», «Справочники», «Мой словарь». [Глоссарий](../glossary.md) различает сохранённый рецепт и тренировку — выполнение по нему.

## Архитектура

`:feature:dashboard` не зависит от других feature-модулей. `DashboardScreen` получает состояние и callbacks через конструкторный граф приложения; `:app` связывает переходы с каталогом, словарём, настройками и существующим рукописным прототипом. Общие атомарные селекторы и строки слов находятся в `:core:wordui`.

Запуск тренировки идёт через `HOME.01` (`TrainingPickScreen`); постоянный выбор радиокнопкой в списке RECIPE отсутствует. `RecipeHomeSummary` ещё может читать `is_active` для сводки/fallback. Порядок рецептов хранится в Room. `RecipeBuilderRoute` предоставляет отдельного владельца состояния каждому редактору; предварительный просмотр и управление тегами возвращают в тот же черновик. Копия публикуется только после Save. Успешное создание из книги рецептов (RECIPE.01) возвращает на список RECIPE; успешное редактирование (RECIPE.01.01) — на RECIPE.02. Создание первого рецепта с `HOME.01` (`launchAfterCreate`) после Save сразу открывает PRACTICE.

## Состояние

`DashboardState` объединяет `WordStatistics`, `ActivityOverview` и `VocabularyOverview`. Количество личных слов поступает из `PersonalDictionaryRepository`. `HOME.W02` и `HOME.W03` строятся из `TrainingsRepository.observeCompletedTasks()` — [активность](home-activity.md), [день](home-word-stats.md).

`RecipeOverview` — представление конфигурации, не запущенная тренировка:

- `id`, `name` — ID и локализованное название рецепта;
- `wordsPerTraining` — число слов на тренировку;
- `secondsPerSymbol` — секунды на один practice-символ; лимит слова = секунды × число символов для письма; 0 в представлении означает отсутствие таймера;
- `completedTrainingCount` — существующее поле демонстрационного отображения, не реализованная статистика исполнителя рецептов.

## Компоненты

| Компонент | Назначение |
|---|---|
| `CurrentRecipeWidget` | Выбранный рецепт; «Выбрать» открывает настоящий список рецептов. «Начать» пока использует существующий тренировочный прототип, не исполнитель рецепта |
| `VocabularyWidget` | Три независимых перехода: учебники, справочники, личный словарь |
| `WordStatisticsWidget` | Дневное кольцо `HOME.W02` → `HOME.02` (сегодня) |
| `ActivityWidget` | Сетка активности `HOME.W03` → `HOME.02` (все) |
| `TrainingHistoryRoute` | Следы тренировок `HOME.02` / `HOME.02.01` |
| `DashboardCard`, `IllustratedIcon` | Общие карточки и иллюстрации; настройка не меняется при замене иллюстраций материалов |

`RecipePicker` и `LegacyRecipeEditor` сохраняются для legacy/preview-композиций. Это не второе постоянное хранилище рецептов.

## Локализация и границы

Пользовательские тексты находятся в `res/values` и `res/values-en`; названия рецептов и материалов независимы от UI-строк, переводы используют `language_tag` и русский fallback. [Терминология и проверка схемы](../verification/recipe-terminology.md), [разделение корней](../verification/library-sections-android.md).
