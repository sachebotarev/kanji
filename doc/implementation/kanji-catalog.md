# Учебный каталог кандзи

Дата подготовки: 20 октября 2026 года.

Данные: [`kanji.csv`](../../data/catalog/kanji.csv) и [`radicals.csv`](../../data/catalog/radicals.csv).
Для изучения и проверки: [локальный указатель статей ЯРКСИ](../dictionaries/yarxi-index.html).

## Состав

Дополнение от 20 октября 2026 года: добавлен знак повтора `々`, `id = 12293` (`U+3005`). Теперь в CSV 3001 запись: 3000 кандзи и один учебный знак. У `々` три черты; ключ и оба поля чтений пустые, признаки списков — `false`. При импорте пустой ключ означает `NULL`. Собственных онъёми/кунъёми нет. [Источник сведений о знаке и числе черт](https://www.tanoshiijapanese.com/dictionary/kanji_details.cfm?character_id=12293&k=%E3%80%85). Исторический отчёт словарной сверки охватывает исходные 3000 кандзи и не приписывается новому знаку.

В исходном наборе `kanji.csv` 3 000 уникальных кандзи: 2 136 дзёё-кандзи и 864 дополнительных именных знака. 1 026 кёику-кандзи входят в дзёё, поэтому у них одновременно выставлены два признака. Число строк — размер объединения, а не сумма размеров трёх пересекающихся списков: `1026 + 2136 + 864 − 1026 = 3000`. Проверено по CSV: кёику вне дзёё — 0, пересечение дзёё и дополнительного именного списка — 0. Более широкий набор японских кандзи включает хёгайдзи, не входящие в запрошенные списки; они не добавляются автоматически. Последний столбец обозначает дополнительный перечень 人名用漢字, а не все знаки, допустимые в именах. Сохранено название столбца «Синмэйё», использованное в запросе; распространённое русское название — дзиммэйё-кандзи.

В учёт добавлен 勒: изменение именного перечня от 26 июня 2026 года ещё не отражено в поле `grade` загруженного KANJIDIC2. Основание — действующая редакция [戸籍法施行規則](https://laws.e-gov.go.jp/law/322M40000010094), приложение с именными знаками (в загруженной редакции — 別表第三), и [сообщение о внесении изменения](https://www.kobe-np.co.jp/news/zenkoku/compact/202606/0020519824.shtml). Прочие признаки берутся из `grade` KANJIDIC2: 1–6, 8, 9–10 соответственно.

Традиционные, современные и совместимые формы, отдельно включённые в перечни, сохраняются отдельными строками. NFKC-нормализацию всего столбца применять нельзя: она может объединить разные записи. Например, 神 и 神 должны сохранять свои исходные кодовые точки. 𠮟 — один знак за пределами BMP; потребитель не должен считать каждый UTF-16 `Char` самостоятельным кандзи.

## Формат

UTF-8 без BOM, LF, стандартный CSV с разделителем `,` и кавычками `"` по правилам RFC 4180. В одной ячейке независимые значения разделены `|` без пробелов вокруг разделителя. Литерал `|` внутри отдельного значения запрещён. Сначала нужен CSV-парсер, затем `split('|')` только для многозначных столбцов.

| Столбец | Содержание |
| --- | --- |
| id | Кодовая точка Unicode десятичным целым, например `26085` для 日; будущий первичный ключ |
| Кандзи | Один знак Unicode, включая отдельные вариантные формы |
| Названия на русском | Краткое значение или описание употребления; несколько значений через `|` |
| Верхнее чтение | Онъёми из KANJIDIC2, обычно катаканой; несколько через `|` |
| Нижнее чтение | Кунъёми из KANJIDIC2, обычно хираганой; несколько через `|` |
| Количество черт | Первое, нормативное `stroke_count` KANJIDIC2; положительное целое |
| Ключ | Традиционный номер ключа Канси (1–214); внешний ключ на столбец `Номер` в `radicals.csv` |
| Входит в Кёику кандзи | `true` или `false` |
| Входит в Дзёё кандзи | `true` или `false` |
| Входит в Синмэйё кандзи | `true` или `false` |

Идентификатор `id` вычисляется из исходной кодовой точки без нормализации. В будущей таблице — `INTEGER PRIMARY KEY` без автогенерации, в Kotlin — `Int`. Например, 日 имеет `id = 26085`; отображаемое `U+65E5` вычисляется из этого числа. Использовать Unicode code point, а не UTF-16 `Char`. Столбец `Ключ` импортируется как числовой `radicalId` со ссылкой на номер ключа Канси. Отдельные совместимые формы имеют разные идентификаторы. Текущая модель хранит один символ; последовательности с селектором варианта потребуют отдельной модели идентификатора.

Пустая ячейка чтения означает отсутствие соответствующего класса чтений в источнике, а не ошибку CSV. Точка в кунъёми отделяет окуригану, дефис обозначает связанное употребление; эти символы сохранены. Нанори, то есть специальные именные чтения, в эти два столбца не подмешиваются. Чтения словарные, включая редкие; принадлежность к дзёё не означает, что каждое приведённое чтение входит в официальный школьный минимум.

Для 歷, 欄, 廊 и 類 в KANJIDIC2 нет собственных японских чтений: использованы чтения явно связанных вариантов 歴, 欄, 廊 и 類. Эти случаи отдельно отражены в отчёте. При сверке русского значения также допускается статья связанного варианта; исходный знак, число черт, ключ и признаки принадлежности при этом не заменяются.

Русская колонка не является полным толковым словарём. Для знаков, используемых главным образом фонетически, в именах или топонимах, описание может обозначать именно это употребление. Оно не выдаётся за самостоятельный перевод кандзи. Названия географических объектов и лиц сохраняют прописную букву.

## Источники и сверка

- [KANJIDIC2, EDRDG / Jim Breen](https://www.edrdg.org/wiki/KANJIDIC_Project.html): японские чтения, нормативное число черт, номер классического ключа, категории и связи вариантов. Снимок `2026-293`, дата `2026-10-20`, версия формата 4.
- [Русская таблица дзёё-кандзи, участники Википедии](https://ru.wikipedia.org/wiki/Список_дзёё-кандзи): вспомогательная исходная редакция части русских значений. Её нельзя считать словарной проверкой: при сопоставлении обнаружены и исправлены неверные значения 低, 呈, 域, 謁 и другие.
- [ЯРКСИ, Вадим Смоленский; онлайн-версия — Сева Алексеев](https://yarxi.ru/online/): построчное сопоставление русских значений с доступными статьями. Проводились поиск термина в значениях, разбор расхождений и проверка связанных вариантов. Простой поиск совпадения сам по себе не является лингвистической экспертизой.
- [WARODAI](https://www.warodai.ru/about/), сборка TXT от 1 июля 2026 года: дополнительная проверка по статьям с однознаковым заглавным написанием. Это словарь слов; наличие кандзи внутри многознакового слова не принималось за его самостоятельное значение.

По каждому кандзи сохранены ссылка на ЯРКСИ, способ сопоставления, использованный вариант и идентификаторы подходящих статей WARODAI, если они есть: [отчёт сверки](../dictionaries/kanji-verification.json). Доступность статьи связанного варианта отмечается отдельно от отдельной статьи исходного знака. Полноту покрытия и оставшиеся ограничения нужно оценивать по этому отчёту, а не по наличию непустой русской ячейки.

Сверка значений 3 000 кандзи с электронными источниками не означает постраничной проверки всех статей по печатному словарю. Пользовательский скан Фельдман-Конрад и OCR сохранены отдельно для ручного изучения. Изменения названий ключей по его пояснениям отменены. Полная академическая редакция 214 названий ключей не завершена: см. [каталог ключей](radicals-catalog.md).

## Assets

`app/build.gradle.kts` добавляет `data/catalog/` в `main.assets` через `assets.directories`. Это единственное место хранения исходных CSV; копии в `app/src/main/assets/` не создаются. В APK доступны `radicals.csv`, `kanji.csv` и `NOTICE.txt`. Например: `context.assets.open("kanji.csv")`.

Подключение assets не добавляет загрузчик, базу данных или экран обучения. Будущий потребитель должен учитывать правила парсинга и атрибуции.

## Лицензии и воспроизводимость

Каталог `kanji.csv` производный от KANJIDIC2 и русскоязычной Википедии, распространяется по CC BY-SA 4.0. Уведомление и ссылки на условия включены в assets в `NOTICE.txt`. ЯРКСИ и WARODAI использовались для сверки; их полные статьи и базы не включены в assets или версионируемую документацию.

Исходные данные KANJIDIC2 (XML), WARODAI (TXT) и ЯРКСИ (оригинальный двоичный файл `yarxice.db`) хранятся в `doc/dictionaries/local/` для подготовки контента и проверки. Установщик ЯРКСИ удалён. Каталог исключён из Git правилом `/doc/dictionaries/local/` и не входит в Android assets. Версионируется только [описание источников, форматов и условий использования](../dictionaries/local-reference-materials.md). Готового парсера базы ЯРКСИ в проекте нет; приложение её не загружает. Публичный HTML-указатель содержит данные проекта и ссылки, а не тексты статей ЯРКСИ.

[Манифест источников](../dictionaries/catalog-sources.json) фиксирует версии и SHA-256 входных материалов и итоговых CSV. Указатель содержит данные проекта и ссылки на оригинальные статьи, работает локально без запросов к словарям до перехода по ссылке.

Проверка структуры, полноты наборов, внешних ключей и упаковки:

```sh
python3 doc/dictionaries/validate_catalog.py
python3 doc/dictionaries/validate_catalog.py --kanjidic /path/to/kanjidic2.xml.gz --apk app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:assembleDebug :app:lintDebug --offline
```

При обновлении KANJIDIC2 необходимо повторять сверку изменённых значений и вариантов, а также проверять актуальный официальный именной перечень. Фиксированные численности в проверке относятся к состоянию на 20 октября 2026 года.
