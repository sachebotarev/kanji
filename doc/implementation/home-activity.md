# HOME.W03 — Активность

Календарь активности на главной строится из завершённых заданий тренировок (`training_tasks`), не из демо-фиксттуры.

## Метрика

- Учитываются статусы `correct`, `assisted`, `skipped`, `timed_out` с непустым `ended_at`.
- День — локальный календарный день `ended_at`.
- Яркость клетки: `count / 10`, ограничено `[0, 1]` (порог 10 ≈ типичный размер тренировки).

## Сетка

Шесть недель понедельник→воскресенье; последняя колонка — неделя с «сегодня». Дни после сегодня в текущей неделе остаются пустыми (0).

## Streak и фраза

Streak — подряд идущие дни с `count > 0`. Если сегодня уже есть задания — считаем от сегодня; иначе — от вчера (серия ещё жива); иначе 0.

| Ситуация | Условие | RU | EN |
|---|---|---|---|
| Start | нет завершённых заданий в истории | Начни сегодня | Start today |
| Rebuild | была активность, streak = 0 | Вернись к серии | Rebuild your streak |
| KeepGoing | streak > 0, сегодня 0 | Не пропусти сегодня | Don't skip today |
| KeepItUp | streak > 0, сегодня > 0 | Так держать | Keep it up |

Источник: `TrainingsRepository.observeCompletedTasks()` → `activityOverviewFromEndedAt` в `:feature:dashboard`. Тап по виджету открывает `HOME.02` без фильтра периода.
