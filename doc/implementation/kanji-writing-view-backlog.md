# Развитие просмотра написания кандзи

## Приоритет и статус

Отложено до завершения основного функционала приложения. Эти задачи не входят в текущий этап и не означают готовую Android-реализацию. Возвращаться к реализации отдельным этапом.

Текущий HTML-макет использует квадратную ячейку с границей и центральными пунктирными направляющими. Исходные координаты KanjiVG сохраняются без обрезки по контуру знака.

## Отложенные задачи

- Увеличение ячейки по нажатию для просмотра сложных знаков и номеров черт.
- Пошаговый показ черт: предыдущая, следующая, воспроизведение последовательности.
- Переключение видимости номеров черт для изучения порядка и просмотра чистой формы.
- Проверка единого масштаба знаков во всех режимах: сохранять исходную систему координат, пропорции и свободное место; не растягивать отдельные элементы до заполнения ячейки.

Предпочтительный первый шаг будущего этапа — увеличение ячейки и переключение номеров, без усложнения основного экрана. Значения и чтения оставлять вне ячейки.

Все новые подписи, управляющие элементы и описания доступности должны поддерживать локализацию с русским основным и резервным языком. Конкретные API и библиотеки пока не выбраны; применение experimental API отдельно не согласовано.
