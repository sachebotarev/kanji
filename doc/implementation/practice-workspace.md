# Реализация рабочего экрана v9

19 октября 2026. По согласованному [макету](../design/practice-workspace-v9.md). Это дополнение заменяет прежнюю компоновку карточек, инструментов и временных статусов; бизнес-правила тренировки не меняются.

## Компоновка

Светлый общий фон без отдельной полосы/рамки/тени хедера. После оценки реального экрана палитра полностью возвращена к исходной дизайн-системе: прежние светлая/тёмная темы, зелёный успех, голубое выделение и прежний цвет «Пропустить». См. [коррекцию](../reviews/practice-ui-correction-2026-10-19.md).

Русское слово занимает всю ширину и переносится. Ряд миниатюр — отдельно, горизонтально прокручивается и показывает исходный ввод/разрешённые подставленные ячейки, не раскрывает ответы. Рамки ячеек восстановлены по обратной связи пользователя. Выбранная клетка выделена рамкой и подчёркиванием, состояния кодируются прежними рамками/заливками; текстовых подписей под ячейками нет. Над ними краткая инструкция выбора. Accessibility-состояния также сохранены. При активном жесте миниатюра продолжает показывать текущий штрих.

Три компактных нажимаемых результата находятся над полем: распознанный знак, процент формы, количество завершённых черт. После них отступ20dp. Каждый открывает отдельный прокручиваемый диалог без слова «Отчёт». Диалог закрывается при редактировании/смене ячейки. Невыполненные подпроверки не обозначаются пройденными. Причины ошибок берутся из результата своего провайдера через IndividualCheckResult.failures, а не из смешанного списка общей проверки. Данные отсутствующего эталона не выдумываются.

Диалог читаемости показывает предсказанный знак и состояние. Целевой знак доступен только после уже использованной подсказки или для разрешённой подставленной ячейки: открытие деталей само по себе не должно раскрыть ответ без учёта помощи. Для формы — процент и ошибки её правил. Для черт — фактическое/эталонное количество, состояние порядка/направления и их нарушения. Если количество не позволяет выполнить сопоставление, порядок/направление обозначены «Не проверено».

Под холстом единая тональная панель с иконками и короткими подписями «Подсказка», «Отменить», «Очистить». Сохранены состояния активности/доступности и вибрация включения подсказки. Отладочное сравнение перенесено в верхнюю панель debug-сборки; детальный debug-диалог сохранён. Внизу — тихий пропуск и основное «Далее» с прежними условиями доступности.

## Сохранённые возможности

Сам KanjiWritingPad не менялся: горизонтальная/вертикальная и диагональные направляющие, нормализованные исходные точки, история, отмена жеста, подсказка с номерами черт, красная отладочная геометрия, ограничения ввода и превью активного штриха остаются прежними. Таймер и typed-результаты тренировки сохраняются. Верхняя область прокручивается отдельно на достаточно высоких экранах; короткое окно использует общую прокрутку без уменьшения поля. Бизнес-состояние и сценарии ViewModel не переносятся в виджеты.

Обновление20 октября: [таймер в верхнем баре](task-timer.md). Кнопки перенесены из бара в подробности проверок; инструкция над клетками убрана, место оставлено пустым. При отсутствии лимита время считается прямо, при лимите — обратно с порогами цвета80%/90%.
