# Глоссарий

Канонические термины для кода, интерфейса, макета и действующих спецификаций. Русский — основной язык; английские переводы не меняют смысл сущностей.

| Русский | English / код | Значение |
|---|---|---|
| Рецепт | Recipe | Сохранённое описание материалов, правил выбора и параметров. Редактируется, копируется, удаляется и может быть выбран для запуска. Не является выполнением и не содержит результатов. |
| Материал рецепта | RecipeMaterial | Источник и сохранённые ограничения отбора слов внутри рецепта. |
| Тренировка | Training | Конкретное выполнение по рецепту: ход выполнения, задания, время и результаты. Один рецепт может использоваться во многих тренировках. |
| Задание | Task | Одна учебная задача в тренировке. |
| Выбранный рецепт | Selected recipe | В черновике 2026-11-07 постоянный выбор убран: рецепт выбирается при запуске тренировки (`HOME.01`). Термин может встречаться в Android/исторических спецификациях до переноса. |

## Правила использования

- «Конструктор рецептов», «создать рецепт», «изменить рецепт», «список рецептов», но «начать тренировку», «история тренировок» / «следы тренировок» (Training footprints), «заданий за тренировку». Не называть рецепт тренировкой и не называть тренировку рецептом; не подменять «тренировку» «занятием» или «учёбой» в продуктовых текстах.
- Модель хранения выполнения — [database/trainings.md](database/trainings.md); Room v7 и host PRACTICE пишут прогресс тренировки. Экран PRACTICE остаётся экраном одного задания; очередь и персистентность принадлежат host.
- Технические API платформы (`sessionStorage`, сеанс drag-and-drop, временный выбор) не являются бизнес-сущностью тренировки.
- Пользовательские имена рецептов и переводы учебного контента не переписываются механически.
- Действующая схема Room v7 использует `recipes` / `recipe_materials_*` и исполнение `trainings` / `training_tasks` / `training_task_symbols` (см. [trainings.md](database/trainings.md)). Представления и алиасы прежних таблиц не создаются. Миграций нет: приложение устанавливается заново, прежняя локальная база несовместима с новой схемой.
- Канонические адресные ID конструктора — `RECIPE…` (не `TRAIN…`). Это идентификаторы карты, а не имя бизнес-сущности. Действующие маршруты, ресурсы и ключи конфигураций используют `recipe`. Прежние `TRAIN…` сохранены как алиасы; см. [миграцию](screen-id-migration.md).
- Исторические отчёты, снимки и экспортированные схемы описывают проверенную тогда версию и не переписываются задним числом.
