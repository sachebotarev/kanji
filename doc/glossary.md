# Глоссарий

Канонические термины для кода, интерфейса, макета и действующих спецификаций. Русский — основной язык; английские переводы не меняют смысл сущностей.

| Русский | English / код | Значение |
|---|---|---|
| Рецепт | Recipe | Сохранённое описание материалов, правил выбора и параметров. Редактируется, копируется, удаляется и может быть выбран для запуска. Не является выполнением и не содержит результатов. |
| Материал рецепта | RecipeMaterial | Источник и сохранённые ограничения отбора слов внутри рецепта. |
| Тренировка | Training | Конкретное выполнение по рецепту: ход выполнения, задания, время и результаты. Один рецепт может использоваться во многих тренировках. |
| Задание | Task | Одна учебная задача в тренировке. |
| Выбранный рецепт | Selected recipe | Рецепт для следующего запуска; выбор не означает, что тренировка уже началась. |

## Правила использования

- Прежнее название сохранённой конфигурации «тренировка» заменено на **«рецепт»**. Прежнее продуктовое название выполнения «сессия» заменено на **«тренировка»**.
- «Конструктор рецептов», «создать рецепт», «изменить рецепт», «список рецептов», но «начать тренировку», «история тренировок», «заданий за тренировку».
- Изменение терминов не реализует отсутствующий исполнитель рецептов или новое хранение результатов. Существующий рукописный экран остаётся существующей реализацией, а не полноценным исполнителем рецепта.
- Слово session допустимо для технических понятий платформы: `sessionStorage`, сеанс drag-and-drop, состояние временного выбора. Это не доменная сущность тренировки.
- Пользовательские имена рецептов и переводы учебного контента не переписываются механически.
- Действующая схема Room v6 использует только `recipes`, `recipes_translations`, `recipe_materials` и дочерние `recipe_materials_*`; внешние ключи — `recipe_id` и `material_id`. Представления и алиасы прежних таблиц не создаются. Миграций нет: приложение устанавливается заново, прежняя локальная база несовместима с новой схемой.
- Стабильные адресные ID экранов `TRAIN…` не переиспользуются и не перенумеровываются. Это идентификаторы карты, а не имя бизнес-сущности. Действующие маршруты, ресурсы и ключи конфигураций используют `recipe`.
- Исторические отчёты, снимки и экспортированные схемы описывают проверенную тогда версию и не переписываются задним числом.
