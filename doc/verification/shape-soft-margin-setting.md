# Настраиваемый допуск мягкого принятия

Дата: 2026-11-11. Виджет: `SETTINGS.01.W04.W01`.

В группе сходства формы после порога добавлен существующий `ParameterSlider`:
`shapeSoftMarginPoints`, 0…100 п.п., шаг 1, по умолчанию 10. Ноль отключает
мягкое принятие. Штраф остаётся 20%, граница остаётся строгой: недобор должен
быть меньше выбранного допуска. Знак и Черты не смягчаются.

`CombinedKanjiChecker` читает значение из текущего снимка настроек. DataStore
сохраняет отдельный float-ключ; отсутствие ключа у старого хранилища даёт 10.
SavedStateHandle использует отдельный ключ, прежний массив параметров не меняется.
Сброс возвращает 10. База результатов и сохранённые штрафы не меняются.
Пояснение результата формы больше не содержит жёстко заданного допуска 10.
