# Теги личного словаря: Android

## Реализованная часть

- Список показывает до двух тегов записи и количество остальных; карточка — все теги. Назначения и таксономия наблюдаются из Room через репозитории.
- Фильтр тегов использует общий `SelectionFilterChip`, который также подключён к каталогу. Выбор тегов объединяется по ИЛИ и пересекается с поиском слов.
- Селектор держит временный выбор: подтверждение передаёт результат, возврат не применяет изменения. Поиск и просмотр выбранных не снимают скрытые назначения.
- Управление тегами доступно из overflow: создание, переименование, семь цветовых ролей и удаление с подтверждением. Это явные общие операции, не откатываемые возвратом из селектора.
- Новые теги из редактора остаются в `WordDraft.pendingTags` и сохраняются атомарно с записью. Состояние редактора и селектора записывается в `SavedStateHandle`.
- Проверка дубликатов временных тегов использует NFKC и Unicode case folding, как хранилище. Удалённые глобально теги исключаются из выбора и перед сохранением записи.
- Сохранение новой записи возвращает к списку. Главная команда редактора — плавающая кнопка.

## Выполненные проверки

На подключённом Pixel 10 Pro, Android 17:

```sh
./gradlew :feature:dictionary:connectedDebugAndroidTest
./gradlew :app:assembleDebug :feature:dictionary:lintDebug :core:wordui:lintDebug
```

Результат: 8 инструментальных тестов, 0 ошибок; сборка и lint успешны.

Три теста проверяют локализацию карточки, русский fallback и доступность действий только для личных записей. Пять новых тестов проверяют временные изменения/отмену, восстановление значений SavedStateHandle, Unicode-дубликаты и удаление выбранного тега, Apply и сохранение скрытого выбора при поиске. В тестах селектора используется поддельный репозиторий; реальные транзакции Room проверены отдельно в [отчёте хранилища](learning-recipes-storage.md).

## Границы

Это не завершение переноса всех согласованных экранов. Отдельный экран других переводов подключён и проверен [отдельно](dictionary-translations-android.md). Единые селекторы кандзи/слов для всех контекстов, Compose-конструктор рецептов и полный визуальный прогон RU/EN × темы × размеры шрифта остаются следующими частями реализации. Проверка восстановления моделирует повторное создание ViewModel из сохранённых значений, а не уничтожение процесса системой. Полноценная проверка TalkBack и визуального соответствия всего приложения не заявляется. Сессии и статистика не добавлялись; миграций Room нет.
