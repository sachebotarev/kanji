# Нативная визуальная матрица конструктора тренировок

## Результат

Проверена финальная debug-сборка на отдельном AVD `Medium_Phone_API_37.0`, Android 17, 1080×2400, density 420. Физический телефон с пользовательским черновиком не использовался.

Матрица: RU/EN × светлая/тёмная тема × системный масштаб шрифта 1,0/1,5 — **8 конфигураций, 48 кадров**. В каждой конфигурации сохранены список тренировок, верх и низ редактора, форма материала, общий выбор кандзи и вложенный JLPT.

[Манифест](recipe-visual-matrix/manifest.json); актуальные PNG и платформенные XML-иерархии находятся в `recipe-visual-matrix/<язык>-<тема>-<масштаб>/`. Например: [EN dark 150% — материал](recipe-visual-matrix/en-dark-1.5/material.png), [RU light 150% — низ редактора](recipe-visual-matrix/ru-light-1.5/editor-bottom.png), [EN dark 150% — JLPT](recipe-visual-matrix/en-dark-1.5/jlpt.png).

## Проверки и исправление

- Длинные названия, переносы подписей, читаемость светлой/тёмной темы; доступны нижние параметры редактора над плавающей кнопкой.
- В JLPT присутствуют N5…N1 и отдельное «Нет данных»; справка расположена собственной строкой над вариантами.
- Русское поле названия пусто для рецепта только с английским переводом: fallback не копируется в редактируемый текст. Русские значения учебных данных в EN при отсутствии перевода — предусмотренный fallback.
- При EN 150% выявлена разная высота соседних кнопок типов материала. Использованы стабильные `Row.height(IntrinsicSize.Min)` и `fillMaxHeight()` дочерних кнопок: высота определяется содержимым, фиксированной высоты/обрезания текста нет. Зависимости и experimental opt-in не менялись. Платформенные возможности intrinsic measurements сверены через Context7 с официальной документацией Compose.
- Регрессионный тест `MaterialEditorTest.largeEnglishTypeLabelsHaveEqualHeightWithoutFixedTextClipping` проверяет английские подписи при 150% и ширине 320 dp, равенство высоты/верхней границы и радио-выбор. Все **7 тестов MaterialEditorTest** прошли на AVD (12,838 с). Сборка приложения, test APK и dashboard lint успешны. Полный dashboard-набор повторно в этом срезе не запускался.

Все 48 сохранённых кадров пересняты **после** исправления. Предварительные снимки в отчёт не включены. Две визуальные проверочные записи созданы и архивированы через интерфейс; список после очистки пуст. Системные настройки эмулятора возвращены к font 1,0, светлой теме и отсутствию app-locales override; эмулятор остановлен. База не редактировалась SQL-командами.

## Воспроизведение и границы

[Сценарий захвата](recipe-visual-matrix.py) использует штатные `cmd locale`, `cmd uimode`, системный `font_scale`, UIAutomator, `input` и `screencap`. Запускать только на отдельном эмуляторе с двумя явно проверочными рецептами и текущим APK, установленным **после загрузки AVD**: сохранённый snapshot может содержать старую версию приложения. Сценарий восстанавливает исходные настройки в `finally`; рецепты удаляются отдельно через UI. `--resume` предназначен только для продолжения захвата той же сборки.

Это визуальная проверка перечисленных шести представлений, а не полная матрица всех экранов приложения/четырёх типов материалов, автоматическое доказательство контрастности или проверка TalkBack. Обрезанные viewport-ом нижние строки XML не трактовались как полный размер touch target. Полный проход TalkBack, другие размеры/ориентации, масштаб выше 150%, вложенные селекторы/диалоги при process death и общий detekt остаются отдельными задачами. Сессии, выполнение рецептов, статистика и миграции не добавлялись.
