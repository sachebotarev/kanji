# Конструктор: сверка Android с утверждённым HTML

Дата: 2026-11-05. Область этого среза — список рецептов и основной редактор рецепта. Формы материалов и остальные согласованные экраны требуют отдельной сверки; весь перенос не объявляется визуально завершённым.

## Эталон и метод

Эталон — действующий [HTML-прототип](../design-system/prototypes/web/index.html#recipes), [спецификация конструктора](../design-system/05-screens/recipe-builder.md) и итоговый CSS с учётом каскада `material-components.css`. Значения проверены через computed styles в Chrome: нельзя брать отменённое значение из одного CSS-файла.

Android: установленное приложение на Pixel 10 Pro, Android 17, 1080×2410, плотность 420 dpi, русский, тёмная тема, масштаб шрифта 100%. HTML: тёмная тема, русский, viewport телефона 412×892 CSS px. Данные и системные панели отличаются, поэтому это сравнение структуры и компонентов, не pixel-diff одинаковой сцены. Существующий рецепт не переименовывался, не удалялся и не сохранялся для получения снимков.

## Исправлено

- Список: стрелка заголовка, 20 dp боковых полей, иллюстрация 96 dp, высота вводного блока и промежутки; размеры/вес заголовков, счётчиков и чипов.
- Карточка: итоговый радиус 12 dp, две колонки параметров с иконками, встроенное раскрытие условий, меню без лишнего ряда. При крупном шрифте параметры переходят в вертикальную компоновку.
- Радио: видимый размер 28 dp внутри независимой выбираемой области 48 dp; тело карточки по-прежнему не выбирает рецепт. Меню также 48 dp.
- FAB списка: итоговые primaryContainer/onPrimaryContainer, радиус 16 dp, векторный плюс вместо текстового символа.
- Редактор: отдельные заголовки создания/изменения, общая стрелка; материал как единая карточка с настоящим названием источника, обложкой, условиями и доступным количеством слов, удалением справа. Обложки перемещены в core:designsystem и используются каталогом и конструктором без копий.
- Добавление материала — полноширинная тональная кнопка; просмотр общего набора — компактный вариант общей строки навигации. Убраны дублирующие отдельные строки счётчиков.
- Количество и время — штатные стабильные Material 3 SegmentedButton вместо вертикальных радиорядов. Подписи числовых полей вынесены над полями. Сохранены валидация, фокус, прокрутка к ошибке и тестовые идентификаторы.
- FAB сохранения — векторная иконка и согласованная форма. Область списка явно ограничена viewport через clipToBounds: прокручиваемые карточки не закрашивают неподвижный заголовок.

Новых зависимостей, версий, experimental opt-in, изменений Room и правил сохранения нет. Подтверждение источника, временный выбор, radio-only, поиск и штатный Android Drag and Drop сохранены.

## Проверки и границы

- Сборка приложения/test APK и lint dashboard/core:wordui успешны.
- Полный пакет builder: **64 теста**, 220.042 с, физический Android 17 — после основных визуальных изменений.
- После окончательной компактной строки, подписей числовых полей и ограничения viewport: **13 тестов** RecipeEditorTest/RecipeAccessibilityTest, 23.234 с, без ошибок.
- Включены две проверки геометрии параметров при обычном/крупном шрифте и сохранения 48 dp целей радио/меню. Полный пакет также включает реальный платформенный перенос и сохранение/восстановление черновиков.
- LSP по-прежнему не разрешает сгенерированные R и часть межмодульных ссылок; Gradle компилирует эти файлы успешно.

Успешные функциональные тесты и прежняя матрица тем/шрифтов не доказывают сходство с HTML. В этом срезе отдельно проверены два основных экрана на телефоне; формы материалов, полная повторная RU/EN-матрица окончательного оформления и ручной проход TalkBack остаются открытыми. Данные снимков не являются новыми эталонными макетами.
