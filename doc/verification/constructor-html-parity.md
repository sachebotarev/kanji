# Конструктор: вложенные экраны и диалоги

## Статус и границы

Сверка относится к текущей итерации конструктора, а не ко всему приложению. Новая функциональность вне этой итерации не добавлялась. Успешные тесты не считаются доказательством визуального соответствия.

Проверены компоновка общих селекторов слов, глав, кандзи, черт, ключей и JLPT, четыре формы материалов, подтверждения выхода/удаления и управление тегами. Сохранены RU/EN × светлая/тёмная тема × шрифт 100%/150%: **224 нативных кадра с XML и 80 HTML-эталонов**. Осмотрены сводки всех восьми конфигураций и полноразмерные кадры критических состояний. Это не автоматическое попиксельное сравнение и не подтверждение каждого возможного сочетания данных, ошибок и открытых диалогов.

Ограниченная матрица не является полной приёмкой всей итерации. Текущий приоритет — завершение оставшихся функциональных доработок, затем окончательная визуальная доводка; незакрытая визуальная приёмка не блокирует функциональную работу. Остальные согласованные разделы приложения, ручной TalkBack и восстановление каждого вложенного состояния после завершения процесса этой проверкой не закрываются.

## Исправления

- В выборе слов «Выбрано / ← Все» и «Снять выбор» находятся в одной строке, а не образуют отдельные вкладки и лишнюю строку. Отступы фильтра, сводки и списка сверены с вычисленным CSS. Сохранены 48 dp, скрытый выбор, поиск и локальный Apply.
- Фильтр подписан «Кандзи / Kanji»; общий значок поиска больше не объявляет поиск кандзи на экране слов или глав.
- Подтверждение выхода совпадает со словарём: заголовок о сбросе правок, «Отмена» и деструктивное «Выйти»; сохранение только через FAB.
- Подтверждение удаления рецепта содержит его название и объясняет, что материалы остаются. Отрицательное действие — «Отмена».
- В управлении тегами отображаются цвет, название, количество уникальных слов, редактирование и отдельная кнопка удаления 48 dp. Удаление больше не спрятано внутри редактирования; его подтверждение не накладывается поверх другого диалога.
- Тот же счётчик используется в выборе тегов словаря и материала. Данные наблюдаются через репозиторий; временные теги имеют нулевое число опубликованных связей.
- Диалог тега содержит заголовок «Цвет тега» и семь локализованных вариантов. Новое действие называется «Создать тег». При редактировании отсутствующий EN-перевод не заполняется русским fallback; остальные переводы сохраняются.
- Фон селектора тегов рисуется **до** safeDrawingPadding: самостоятельный маршрут управления не оставляет белые системные поля с белыми значками в тёмной теме.
- Дублирование открывает частную копию в новом редакторе, без записи из меню списка; [проверено отдельно](recipe-copy-parity.md).
- Ошибки полей рецепта и четырёх форм материалов используют общий supporting text с декоративным значком Error и единым доступным текстом.

Использованы существующие стабильные Compose/Material3 компоненты, включая AlertDialog и его штатные слоты. Версии зависимостей, opt-in и схема Room не менялись. Возможности проверены через Context7 и [официальное описание диалогов](https://developer.android.com/develop/ui/compose/components/dialog).

Наборы слов и источники берутся из настоящего каталога, а не подменяются демонстрационными данными ради совпадения картинки. Для 150% установлен `--scale: 1.5` и штатный класс large-text: стандартный флажок прототипа использует 1.35. Android использует системный font_scale, включая платформенное нелинейное масштабирование. Различия системных полей и переносов из-за размеров экрана не скрываются.

### Явное исключение эталона

Текущая функция `renderMaterialReference` в HTML выводит JLPT N1→N5 и не содержит общей справки. Более конкретное согласованное требование задаёт N5→N1, отдельное отсутствие данных и справку непосредственно над списком. Android сохраняет это требование. HTML не переписан под реализацию, а это расхождение не выдано за буквальное совпадение.

Штатные Android-диалоги и радио сохраняют области 48 dp. Цветовые варианты при необходимости переносятся, а не уменьшаются до маленьких HTML-целей.

## Воспроизведение и изоляция

[constructor-parity-matrix.py](constructor-parity-matrix.py) использует adb/UIAutomator и отдельный эмулятор. Нужен сохранённый через интерфейс тестовый рецепт `PARITY_MATRIX_20261105` с учебником. Основной режим не сохраняет черновики. `--tags-only` пересоздаёт только тестовый `PARITY_TAG_20261105`, чтобы снять пустые и непустые состояния. Оба фикстурных объекта удаляются через интерфейс после проверки; SQL-записей, очистки данных и миграций нет. Язык приложения, тема и масштаб восстанавливаются в finally; отменённые промежуточные запуски не публикуются.

[constructor-html-reference.cjs](constructor-html-reference.cjs) использует уже установленный Playwright/Chrome и локальный HTTP-сервер с корнем `doc`, порт 8767. Ничего не устанавливает и не меняет HTML.

```bash
python3 doc/verification/constructor-parity-matrix.py --serial emulator-5554 --output /tmp/constructor-check
python3 doc/verification/constructor-parity-matrix.py --serial emulator-5554 --output /tmp/constructor-tags --tags-only
# NODE_PATH задаётся только при необходимости найти существующий Playwright.
node doc/verification/constructor-html-reference.cjs /tmp/constructor-html
```
