# Релизная страница приложения

Изменены SHARED.04.W02, SHARED.04.W02.W01 и SHARED.04.W06: приложение опубликовано в Google Play, главный баннер сочетает реальный скриншот светлой карточки 山 и существующий маскот. Кнопки установки используют URL `https://play.google.com/store/apps/details?id=ru.mobui.kanji` из общей конфигурации.

## Источник скриншотов

`doc/legal/assets/kanji-light-ru.png` и `kanji-light-en.png` сняты командой ADB `screencap` с физического Pixel 10 Pro, в исходном разрешении 1080 × 2410. Перерисовка и обрезка не применялись. Для русского и английского интерфейсов сохранены отдельные кадры; отсутствующие английские переводы учебного контента используют русский fallback приложения. После съёмки восстановлены исходная тёмная тема, локали приложения `[]`, `sysui_demo_allowed=0` и обычные статусные значки. Разрешение устройства не менялось.

## Проверка исходников

- Google Play URL возвращает HTTP 200 при HTTP-запросе; встроенный веб-поиск не смог открыть страницу, поэтому использована прямая проверка адреса, предоставленного владельцем приложения.
- `check-project-map.py`, `check-input-shapes.py`, разбор YAML и проверка одинаковых ключей RU/EN проходят.
- Изображение имеет `height:auto`, без `object-fit:cover` и фиксированной высоты: кадр целиком сохраняет исходное соотношение сторон. Ссылка на оригинал открывается в новой вкладке с локализованным описанием.
- Старые отчёты и кадры первой версии сайта сохранены; относятся к указанной в них версии.
