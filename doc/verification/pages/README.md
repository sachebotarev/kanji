## Выполненные проверки

- Обе страницы приложения и политики доступны по HTTPS без авторизации. Все внутренние ссылки и изображения, извлечённые из этих страниц, возвращают HTTP 200. В опубликованном HTML нет необработанных Liquid-вставок.
- Русская и английская локали используют одинаковые ключи, по три возможности и три шага обучения; HTML `lang`, заголовки и выделение выбранного языка соответствуют локали. Ссылка RU из английской версии открывает русскую страницу.
- В браузере Orca проверена русская страница при ширине 320, 390, 768 и 1440 CSS px: горизонтального переполнения нет, оба изображения загружены. Английская версия проверена при 320 и 390 px; переполнения нет. Мобильная область ссылки-бренда — не менее 44 px.
- Просмотрены сохранённые кадры desktop RU и mobile RU/EN. На мобильном кадре учебного примера видны знак, чтение и перевод; маскот уменьшен до 220 px. Кадры представляют отдельные области страницы, не полную проверку всех состояний.
- Основные сочетания текста/фона имеют расчётный контраст от 5.33:1 до 11.55:1; белый текст кнопки на зелёном — 6.52:1. Есть видимый `focus-visible`, ссылка пропуска к содержимому, семантические секции и отключение плавной прокрутки при `prefers-reduced-motion`.
- `python3 doc/verification/check-project-map.py` — успешно: 44 зарегистрированных экрана, 2 выведенных, 673 виджета.
- `python3 doc/verification/check-input-shapes.py` — успешно; текстовые поля не добавлены.
- `node --check doc/design-system/prototypes/viewer.js`, чтение YAML и `git diff --check` — успешно. Просмотрщик поддерживает отдельный тип публичной страницы, не выдавая его за экран Android.
