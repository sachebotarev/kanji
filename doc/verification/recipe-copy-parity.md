# Дублирование: несохранённая копия в редакторе

## Контракт

[Макет конструктора](../design-system/05-screens/recipe-builder.md) и `recipes.js` задают открытие копии в редакторе. Отдельного диалога дублирования нет. Нажатие пункта меню не должно создавать запись в БД.

- Типизированный маршрут передаёт только ID исходного рецепта. Использованы существующие Navigation Compose 2.10.2 и SavedStateHandle, без обновления зависимостей и opt-in. Возможности проверены через Context7 по официальным [типобезопасным маршрутам](https://developer.android.com/guide/navigation/design/type-safety).
- Редактор создаёт новые UUID рецепта и каждого материала, revision 1, неактивное состояние. Настройки и выбор материалов сохраняются; все строки переводов названия остаются отдельными, к каждой добавляется локализованное ` (копия)` / ` (copy)` с ограничением 120 символов, как в HTML.
- Это частный черновик. Запись выполняется только штатным Save; Back без правок отбрасывает копию. Правки используют обычное подтверждение выхода и валидацию. Исходный рецепт и активный выбор не изменяются.
- UUID и первоначальный снимок копии сохраняются в SavedStateHandle через тот же Bundle-кодек, что черновик формы. Восстановление не создаёт новые ID и не подхватывает изменённую исходную revision. Отсутствующий исходник показывает ошибку, а не пустой новый рецепт.
- Заголовок копии — «Новая тренировка», даже если название уже заполнено. Штатные компоненты редактора и диалог выхода не дублируются.

## Проверки

`RecipeLibraryTest`: **12 тестов**, 69,223 с, Pixel 10 Pro / Android 17. В том числе:

1. Открытие копии не вызывает запись; UUID независимы, настройки и переводы сохранены.
2. Восстановление SavedStateHandle сохраняет снимок и ID, даже если исходное название обновилось.
3. Отсутствующий исходник не публикует пустой рецепт.
4. Ошибка Save удерживает черновик; повторное нажатие во время записи игнорируется, успешный retry создаёт одну копию.
5. Настоящий RecipeBuilderRoute: пункт меню открывает заполненный новый редактор; Back возвращает в неизменённый список; повторное открытие и явный Save добавляют только одну неактивную запись, оригинал не изменяется.

Финальный прогон dashboard: **67 тестов**, 230,633 с, без ошибок, включая общие декоративные значки ошибок полей. Сборка приложения, test APK и dashboard lint успешны. APK установлен на телефон через `install -r`, без очистки данных. Отдельный ручной снимок пути копирования не получен: во время проверки телефон использовался вручную, автоматизация прекращена, чтобы не перехватывать действия пользователя. Это проверка маршрута и жизненного цикла черновика, а не доказательство визуального совпадения во всех конфигурациях. Восьмиконфигурационная [матрица общих компонентов](constructor-html-parity.md) снята до локальной правки пути дублирования; её APK SHA не заменён на новый задним числом.
