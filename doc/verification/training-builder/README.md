# Проверка конструктора тренировок

Дата: 2026-11-02. Статус дизайна: **черновик для согласования**. [Модель](../../database/trainings.md), [UX-контракт](../../design-system/05-screens/training-builder.md).

## Объём и результаты проверки

1. **Интерактивный макет — 17 групп проверок прошли**:
   - Chrome / Playwright, мастерская 1440×1180, ширина телефона 360/375/412/480 CSS px, ru/en, обе темы, увеличенный текст. Дополнительно проверен горизонтальный preview 740 × 480 с reduced motion. Ошибок JavaScript и HTTP нет. [Машинный отчёт](validation.json).
   - 10 начальных рецептов разрешаются в непустые выборки. Карточки имеют одинаковую высоту и ширину при одном масштабе текста, включая выбранную и карточку с длинным названием.
   - Закреплённая Extended FAB видна, доступна нажатию и открывает создание после прокрутки к концу. Последняя карточка полностью поднимается выше FAB за счёт нижнего отступа.
   - Подписанные типы подборок, крупная лапка и явное состояние «Выбрана»; загружена отдельная иллюстрация кота-мастера. Длинное название доступно целиком в «Подробнее».
   - Контраст текста названия, материала, типа и времени не менее 4.5:1 в обеих темах, измерен по вычисленным CSS-цветам. Это проверка затронутых текстовых пар, а не аудит всех деталей интерфейса.
   - Создание, изменение, дублирование, выбор, удаление с подтверждением, отмена удаления и выход с несохранёнными правками.
   - Объединение пересекающихся источников, 4000 заданий при наборе из 2491 слова, независимые настройки числа/времени/порядка, ошибки лимитов и главы без учебника. Английский интерфейс использует русский fallback каталожных переводов.
   - Меню: стрелки, Home/End, Escape с возвратом фокуса, закрытие снаружи. Длинный список, карточки и меню не выходят за горизонтальные границы узкого телефона. Пустое состояние сохраняет FAB.
   - Снимки визуально просмотрены. Кот-мастер сгенерирован с reference из каталога, его RGBA-файл содержит прозрачность. Пользовательское исследование понятности и отдельная проверка всех сочетаний фильтров не проводились.

2. **Проверка схемы БД в SQLite in-memory (`validate_schema.py`)**:
   - Применена схема каталога и расширение тренировок: таблицы `trainings`, `trainings_translations`, `training_sources`, а также таблицы сессий `training_sessions` и `training_session_items`.
   - Проверены:
     - Nullable-лимиты и отклонение нулевых/отрицательных значений;
     - Проверка допустимых значений `selection_mode` и статусов сессий;
     - Невозможность указать диапазон глав без `source_id`;
     - Валидность порядка глав `chapter_from <= chapter_to`;
     - Индексы по внешним ключам `training_id`, `source_id`, `word_id`, `kanji_id`, `session_id`;
     - Единообразное мягкое удаление через `is_archived IN (0,1)` и `archived_at`;
     - Каскадное удаление элементов сессии при удалении `training_sessions`.

## Воспроизведение

Из корня репозитория запустить веб-сервер для макета:
```sh
python3 -m http.server 8767 --directory doc
```

Запуск верификационных тестов:
```sh
# Проверка SQL-схемы, ограничений целостности и каскадов:
python3 doc/verification/training-builder/validate_schema.py

# Интерактивное E2E-тестирование веб-прототипа (при наличии Playwright):
node doc/design-system/prototypes/web/test_training.cjs
```
