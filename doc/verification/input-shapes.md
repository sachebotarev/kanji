# Единое скругление полей ввода

## Источник и применение

Единственный параметр: `component_shape.text_field` в [theme-source.json](../design-system/theme/theme-source.json), текущее значение **16**. Изменение применяется ко всем полям Android и HTML командой:

```sh
npm run build --prefix doc/design-system/theme
```

Генератор обновляет CSS-переменную `--app-input-corner-radius`, экспорт темы и `core/designsystem/src/main/res/values/input-shape.xml`. Генерируемые значения вручную не редактируются. В Android все 17 вызовов текстового поля используют `MaterialTheme.inputShape` из `core:designsystem`: поиск, обычные/многострочные поля, числовые параметры, диалоги и старые тренировочные формы. Общая форма записи также получает этот радиус. Радиусы карточек, кнопок, чекбоксов, радиокнопок и слайдеров не меняются.

[Инструкция темы](../design-system/theme/README.md), [карта влияния UI-INPUT-SHAPE](../project-map.md). Ранее сохранённые снимки DICT.02 с радиусом 4 отражают предыдущее состояние; они не переписывались.

## Проверки

- `python3 doc/verification/check-input-shapes.py`: 17 нативных вызовов используют тему; Android dimension, CSS и JSON синхронизированы.
- Сборка приложения и тестовых APK, lint `core:designsystem`, `core:wordui`, каталога, словаря и dashboard прошли.
- На отдельном эмуляторе Android 17 прошли **33 теста словаря** за 98.537 с, включая новый `InputShapeTest`: все четыре угла используют генерируемый ресурс. **21 тест редактора и списка рецептов** прошёл за 86.112 с.
- `input-shapes.cjs`: **48 HTML-состояний** (RU/EN, обе темы, 100%/150%; редактор слова, рецепт, тег, поиск, параметры и поиск каталога). Проверены вычисленные радиусы всех четырёх углов. Временное изменение CSS-токена на 23 px распространяется на текстовые поля, textarea и select, но не меняет чекбоксы, радиокнопки и слайдеры.

[HTML-манифест](input-shapes/html/manifest.json) и кадры сохранены вместе с восемью нативными кадрами общей формы в `input-shapes/native/`. Это проверка радиуса и регрессий, не попиксельная приёмка всех экранов. Нативные кадры получены в тестовом хосте с черновиками в памяти; пользовательские записи не изменялись. Схема БД, зависимости и experimental opt-in не менялись.
