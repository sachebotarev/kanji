# Android-хранилище тегов и рецептов

## Реализовано

- `domain/catalog/.../Recipes.kt`: локализованные теги, семь идентификаторов цветов, четыре типа материалов, рецепты и контракт репозитория. Валидация языков, имён и совместимости ограничений.
- `data/catalogdb/.../RecipeEntities.kt`, `RecipesDao.kt`: десять новых таблиц Room; переводы отдельными строками с `language_tag`, связи с FK и каскадами.
- `RoomRecipesRepository.kt`: наблюдение Flow, tag CRUD/назначение, транзакционное сохранение агрегата рецепта, оптимистическая проверка revision, единственный активный рецепт, точная перестановка полного списка и архивирование активного со сбросом выбора без автоматического выбора другого.
- `WordDraft.pendingTags` и `RoomCatalogRepository.saveWord`: слово, переводы, новые теги и назначения сохраняются одним commit. Ошибка имени тега откатывает также слово. Обычные клиенты редактора без tagIds сохраняют прежние назначения.
- Ключ имени тега — NFKC + Unicode case folding (`android.icu.lang.UCharacter`, API 24+). Цвет не зависит от языка, неизвестные языки не требуют новых столбцов.
- исторически Room v5; актуальная схема — Room v6, экспорт `data/catalogdb/schemas/ru.mobui.kanji.data.catalog.CatalogDatabase/5.json`. Дополнительные SQL-ограничения и частичный unique-index активного рецепта устанавливаются при каждом открытии (`RecipeChecks.kt`). Каталожные guards также устанавливаются после замены базы.
- Пользователь разрешил замену невыпущенной базы: миграции не созданы. `fallbackToDestructiveMigration(dropAllTables = true)` удаляет прежнюю базу логически, включая неуправляемые таблицы; установщик повторно загружает каталог. Старые локальные данные не сохраняются.

## Выполненные проверки

2026-11-04, подключённый Pixel 10 Pro, Android 17:

```sh
./gradlew :domain:catalog:test :data:catalogdb:connectedDebugAndroidTest
./gradlew :app:assembleDebug :data:catalogdb:lintDebug :domain:catalog:test
```

Оба запуска успешны. 25 JVM-тестов домена (включая 4 новых), 8 инструментальных тестов хранилища (включая 5 новых), 0 падений/ошибок. Lint слоя данных и сборка APK успешны.

Новые инструментальные сценарии проверяют:

1. Unicode-дубликаты `Straße`/`STRASSE`, откат слова и промежуточного нового тега, сохранение назначений при обычном редактировании, удаление тега без удаления слова.
2. Сохранение/чтение рецептов, активность, перестановку, запрет частичного списка и устаревшей revision, сброс выбора при архивировании активного без выбора другого.
3. Настоящий личный source ID, пересечение тегов/кандзи, OR по нескольким тегам, пустой результат и неправильный источник.
4. SQL-guards цветов/происхождения/параметров и отсутствие таблиц сессий.
5. Создание старой базы из фактического экспорта v4, её замену без миграции, отсутствие старой неуправляемой таблицы, установку каталога и guards после повторного открытия.

## Границы

Этап хранения завершён; актуальный UI конструктора и тегов описан в project-map и verification/recipe-*. Репозиторий доступен через `RoomCatalogRepository.recipesRepository`. Сессии, исполнение тренировок, таймер и статистика не добавлялись. SQL-тест документации остаётся отдельной проверкой модельного DDL и не заменяет Room-тесты.
