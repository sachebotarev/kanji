# Проверки каталога

Текущие статусы — в [едином реестре](../../design-system/theme/screens.json). 18 каталожных и общих экранов согласованы 2026-11-04; [контракт переноса](../../implementation/approved-ui-handoff.md) отделяет целевой HTML от существующей Android-реализации.

## Действующие проверки

- `node doc/design-system/prototypes/textbooks/test_content.cjs`: реальные данные, локализация, количества и единый реестр 18 экранов.
- `test_browser.cjs`: браузерная матрица маршрутов/состояний/тем/ширин/масштабов.
- [Множественные фильтры](../catalog-multiselect-filters.md), [общие экраны](../shared-screens.md), [унификация](../design-unification.md).
- [Результаты нативной проверки существующей версии](refactor-2026-11-02/README.md): JVM/инструментальные тесты, сборка и lint. Отчёт относится к проверенной Android-редакции, не подтверждает перенос целевых изменений HTML.
- [Ревизия кода](code-review-2026-11-02.md): технические исправления и границы проверки действующей реализации.

`capture_native.py` снимает debug-only точки входа и фиксирует hash реестра. Он не выполняет обычную навигацию, TalkBack или импорт и не подтверждает согласование/полноту реализации. Снимки временных браузерных прогонов направлять в `/tmp`; спецификации не генерируются из старых галерей.
