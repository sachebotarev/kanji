# Перенос Material-макетов каталога в Android

## Область реализации

Перенесены текущие компоненты всех 17 экранов каталога. Это не означает пиксельного совпадения HTML и Android и не меняет статусы пользовательской приёмки в реестре дизайна. Отложенные функции просмотра написания и новые сцены маскота в этот этап не входят.

| Экраны | Реализация |
| --- | --- |
| CAT-01 | Иллюстрированные входы в учебники и справочники, умеренный акцент учебников из общей Material-схемы. |
| CAT-02 | Обычный список глав с полным превью сохранён. |
| CAT-03, CAT-05 | Фильтры Tertiary, счётчик на отдельной постоянной строке, доступная кнопка помощи по нумерации рядом. |
| CAT-04, CAT-06, CAT-15 | Общий вертикальный виджет слова: написание, чтение, перевод. Контекст и разные чтения одного написания сохраняются. У единственной главы количество не повторяется; декоративный конец списка главы убран. |
| CAT-07 | Написание, чтение и перевод без общей тяжёлой подложки; примечания и составляющие кандзи сохранены. |
| CAT-08 | Квадратная ячейка с направляющими и исходными координатами, без обрезки рисунка; краткие заголовки чтений; метки классификации по размеру текста; пустые чтения не выводятся. |
| CAT-09 | Карточка ключа и связанные кандзи; помощь по учебным номерам рядом со счётчиком. |
| CAT-10 | Компактные строки выбора главы с приглушённым однострочным превью и многоточием, без декоративной галочки. Если единственный доступный вариант уже выбран, название фильтра не открывает выбор; сброс независим. |
| CAT-11 | Плитки выбора кандзи без инструкций, номеров и числа черт; контекст главы/учебника сохранён. |
| CAT-12, CAT-14 | Непрерывная сетка ключей без заголовков групп, четыре повторяющихся оттенка по числу черт, полные названия; короткое имя «Второй» локализовано. |
| CAT-13 | Общий справочник с пересекающимися фасетами, поиском и счётчиком. |
| CAT-16, CAT-17 | Единые компактные двухстрочные варианты; пояснение JLPT открывается кнопкой рядом со сбросом. |

Тема и компоненты используют семантические роли Material 3, ресурсы ru/en и русский fallback. Новые experimental API, зависимости, языковые флаги и исключения анализаторов не добавлены. Baseline detekt не расширялся.

## Производительность Compose

Проведён целевой осмотр реализации, не измерение FPS:

- Ленивые списки/сетки сохраняют стабильные ключи ID и существующие владельцы состояния/прокрутки.
- В `KanjiDrawing` обнаружена повторная сборка `Path` из точек и копирование коллекций `ReferenceDrawing` на каждой перерисовке.
- Нормализованные пути и снимок номеров теперь подготавливаются через `remember(drawing)`; при отрисовке применяется масштаб ячейки. Геометрия исходного квадрата не меняется.
- Никаких массовых `remember` для модификаторов/лямбд, новых `Stable`/`Immutable` или изменений рукописного ввода не вводилось.
- Release/profileable frame timing не измерялся; результаты debug-тестов не выдаются за замеры производительности.

## Регрессии, выявленные общим прогоном

- Восстановленный поиск повторно запрашивал фокус и открывал IME, из-за чего Back мог закрыть клавиатуру вместо возврата. Факт первоначального запроса фокуса сохраняется через `rememberSaveable`; действие IME Search снимает фокус, сохраняя запрос.
- `PracticeViewModel` обнулял временную отметку при уходе в фон и терял фоновый интервал. Отметка сохраняется, интервал учитывается при возобновлении в соответствии с существующим контрактом. Повторные события активности не запускают второй ticker. Существующие проверки фонового времени и таймаута сохранены.
- UI-тесты прокручивают элемент только при необходимости: полностью помещающиеся страницы намеренно не имеют scroll action. Для проверки пустого поиска используется гарантированно отсутствующий номер, а не существующий ключ 85.
- Отправка Back в тестах диалогов явно выбирает Espresso-root `isDialog()` и ожидает закрытия. Перед возвратом из выбора тренировки тест ожидает исчезновения редактора. Проверки навигации и данных сохранены.
- На Pixel обнаружен дополнительный случай: при переходе из редактора тренировки в выбор оставшаяся IME могла перехватить Back. `TrainingEditor` снимает фокус и скрывает клавиатуру перед передачей валидной формы в `onSubmit`. Проблемный сценарий проверяется на физическом устройстве.
- Проверки HTML обновлены под согласованный контракт коротких заголовков, скрываемой помощи и единственного счётчика; проверки результата сохранены.
- В общем HTML-просмотрщике устранён цикл синхронизации темы между вкладками: входящие `storage`-события и перерисовка больше не записывают тему обратно. Запись выполняется только при явном выборе темы; устаревшие события читают актуальное значение хранилища. Добавлена регрессионная проверка отсутствия обратной записи при перерисовке.
