# Допроверка замечаний второго агента и варианты решений

2 ноября 2026 года. Реальный Pixel 10 Pro, установленное приложение 1.0. Эта допроверка использует обычную навигацию приложения, не `CatalogReviewActivity`. Код, БД и настройки устройства не изменялись. Проводились действия просмотра, поиска и выбора фильтров.

Связанные материалы: [первоначальный экспертный отчёт](../README.md), [проверенные числа из seed](data-check.json). Персона остаётся экспертным предположением: русскоязычный подросток 14 лет с полугодом изучения японского. Реальных пользовательских интервью не проводилось.

## Главный результат: воспроизведён дефект скрытого фильтра

Утверждение «выбор главы со вкладки слов показывает одну главу 3, один кандзи и 118 слов при полном списке из 1554» подтвердилось. Найдена воспроизводимая последовательность:

1. Открыть «Каталог → Tobira → Кандзи».
2. Выбрать «Все черты → 1 черта». Видна только 一: [снимок](one-stroke-kanji.png).
3. Переключиться на «Слова». Видны все 1554 слова, фильтр черт не отображается: [снимок](words-after-kanji-filter.png).
4. Открыть «Все главы». Виден один вариант «Глава 3», подпись «1 кандзи · 118 слов», превью 一: [снимок](chapter-picker-after-kanji-filter.png).
5. Вернуться на «Кандзи», сбросить одну черту, снова открыть выбор главы из слов. Доступны все 18 глав: [исходный список без ограничения](chapter-picker-unfiltered.png).

**Причина, подтверждённая чтением кода:** `CatalogRoute.kt:73` передаёт `state.strokes` и `state.jlpt` при открытии фильтра главы независимо от вкладки. Фильтр ключа при переходе из слов уже обнуляется. Число черт продолжает ограничивать допустимые кандзи в `CatalogSnapshot.availableChapters()`. При этом `CatalogSnapshot.words()` не применяет черты и JLPT. Поэтому превью/количество кандзи и количество слов рассчитываются по разным правилам.

Это ошибка передачи контекста, а не потеря содержимого БД. В Tobira ровно один однострочный знак — 一, размещённый в главе 3. Поэтому скрытая «1 черта» воспроизводит именно замечание агента.

### Предлагаемое исправление

**P1 — первым отдельным исправлением.** Формировать эффективные условия по назначению вкладки. Для слов действуют глава и выбранный кандзи. Черты, ключ и JLPT не должны попадать из вкладки кандзи в выбор главы для слов. При этом выбор «1 черта» сохраняется при возвращении на вкладку кандзи.

Минимальное исправление маршрута: при открытии выбора главы из слов передавать нейтральные `strokes` и `jlpt` вместе с уже нейтральным `radical`. Более устойчивое решение: явно передавать назначение выбора и нормализовать условия перед расчётом фасет. Сам экран выбора не должен угадывать назначение по наличию чисел.

Отдельно определить смысл количества в варианте главы. Возможны полные объёмы главы с отдельным количеством совпадений либо только объёмы отобранного материала с явной подписью. Не смешивать частичный набор кандзи с полным количеством слов под общей неуточнённой подписью.

**Приёмка:** повторить последовательность выше. Во вкладке слов без активного отбора должны остаться 1554 слова и 18 вариантов глав. Глава 3 должна показывать полные 14 кандзи и 118 слов. При возврате на вкладку кандзи сохраняется «1 черта». Дополнительно проверить выбор главы при активном отборе слов по 一: тогда ограничение по этому кандзи законно и должно быть видимым. Нужны проверка маршрута/состояния и один тест сценария на устройстве.

## Проверка остальных утверждений

| Замечание | Результат проверки | Предлагаемое решение |
| --- | --- | --- |
| Результат поиска главы находится под клавиатурой | **Не воспроизведено в проверенных условиях.** Поиск `12` в обычных главах и в выборе главы показывает всю карточку над цифровой клавиатурой | Не записывать как подтверждённый баг. Допроверить исходный сценарий при прокрутке, крупном тексте и другой высоте IME. Если воспроизведётся — обеспечить доступность первого результата в области над IME и правильную позицию списка после изменения запроса |
| Карточка главы почти на экран, видно только две главы | **Частично.** Превью действительно содержит весь набор знаков. В обычном списке при текущем масштабе видны три полные карточки и часть четвёртой. С клавиатурой карточек меньше | В списке глав ограничить превью двумя строками с подписью «ещё N». Все знаки оставить внутри главы. В выборе главы использовать более компактный вариант. Не обрезать данные в domain или БД |
| Все карточки имеют одинаковую зелёную заливку | **Частично.** Учебники используют отдельный `surfaceContainerHighest`, остальные переходы — `surfaceContainerHigh`, просмотр — `surfaceContainerLow`. Цветовые роли реализованы, но близки визуально | Сначала улучшить иерархию компоновкой, размерами, иконками и шевронами. Не назначать отдельный цвет каждой сущности. Если различие учебника и справочника всё ещё не читается, проверить усиление существующих токенов в обеих темах |
| Короткая карточка слова оставляет пустую нижнюю половину | **Подтверждено для 一.** [Снимок](short-word.png). Принудительная прокрутка не нужна | Не растягивать блоки и не добавлять декор ради заполнения. Полезное продолжение — пример, проверенное примечание или учебное действие. До появления таких данных свободное место допустимо |
| Выбор кандзи похож на обычную сетку | **Подтверждено визуально**, это также действующий контракт переиспользования виджета | Кратко объяснить результат нажатия: «Выберите кандзи, чтобы отфильтровать слова». Сохранить выбранность и возврат. Отдельная палитра или полностью новый вид плитки не обязательны |
| Длинное имя ключа обрезается | **Подтверждено**, совпадает с D1 первого отчёта | В справочнике допустимо краткое превью с полной карточкой. В выборе дать полное название до применения условия: дополнительные строки либо компактный список со знаком и названием |
| Два счётчика «13 слов» и «Глава 3 · 13 из 13» | **Подтверждено.** [Снимок](related-13.png). У знаменателя нет явного пояснения, счётчики дублируются | Общий объём назвать «13 слов в Tobira». У группы оставить «Глава 3 · 13 слов». При поиске отдельно показать число найденных. Не имитировать долей учебный прогресс |
| Связанные 13 слов — тот же список, что вся глава | **Не подтверждено в буквальном смысле.** В главе 3 всего 118 слов, по связи с 一 — 13. Начало списков совпадает | Явно назвать область и основание отбора. Не объединять разные подборки и не удалять полезные связи ради устранения похожести |
| 1554 слова учебника не показывают главу, карточка говорит лишь «Слово · Tobira» | **Подтверждено**, соответствует текущему дизайну | Сохранить плоский список, но дать учебные размещения в подробностях или раскрываемой строке. Если источник входа был главой, сохранять контекст возврата. Для записей с несколькими размещениями показывать все подходящие связи |
| В «Все кандзи» нет своего места в учебнике | **Подтверждено как свойство общего справочника**, не дефект фильтра | Подписать «Общий справочник». Для поиска по своему материалу использовать вход из учебника. Если нужен переход между областями, сделать явный выбор учебника, а не наследовать скрытый фильтр. Показать учебные размещения кандзи в подробностях |
| Карточка кандзи логично собрана, метки 常用 и 教育 присутствуют | **Подтверждено.** Структура понятна; присутствие меток не гарантирует понимания их значения начинающим | Структуру сохранить. Добавить русские расшифровки или раскрываемую справку и уточнить, что школьный год относится к Японии |

Снимки поиска: [главы учебника, запрос 12](chapter-search-12.png), [выбор главы, запрос 12](picker-search-12.png). В обоих случаях нижний край содержимого карточки расположен выше верхнего края IME. Проверка относится к этому устройству, обычному масштабу и цифровой клавиатуре. Все размеры и клавиатуры ею не покрыты.

## Что показывают сами данные

| Область | Проверенное количество |
| --- | --- |
| Tobira | 329 размещений кандзи, 1554 уникальных слова, 18 глав с номерами 3–20 |
| Tobira, глава 3 | 14 кандзи, 118 уникальных связанных слов |
| Tobira, учебные связи с 一 | 13 уникальных слов |
| Basic Kanji Book | 500 размещений кандзи, 1716 уникальных слов, 45 глав с номерами 1–45 |
| Seed кандзи | 3001 запись, из них у 3000 задан ключ; обычный общий список без запроса показывает 3000 |

Главы Tobira начинаются с 3 в поставляемом наборе. Это не повод перенумеровывать источник. При необходимости следует пояснить границы поставляемого материала.

Учебная принадлежность слова определяется `source_words → source_kanji`, а не просто наличием знака в написании. У одного слова возможны несколько связей и учебных размещений. Поэтому для показа главы нельзя добавлять единственное обязательное поле `chapter` в сущность слова или определять главу по первому видимому кандзи.

## Решения по моим первоначальным замечаниям

| Замечания первого отчёта | Конкретный путь решения | Очерёдность |
| --- | --- | --- |
| D1, U2, U3: выбор ключа, кандзи, числа черт | Полное название ключа до выбора, инструкция результата нажатия, компактные варианты чисел и глав при сохранении доступных областей нажатия | После исправления скрытого фильтра |
| D2, D4: чтения в списке и номера размещений | Проверить увеличение каны, добавить легенду «глава — номер кандзи». Системное увеличение текста сохранять | Следующий UI-проход |
| U1: непонятен выбор учебника | Краткое описание назначения и ожидаемой подготовки на русском. Использовать проверенное содержание источника, не угадывать уровень по названию | Высокая продуктовая ценность |
| U5: область связанных слов и счётчики | Указать учебник/область в подписи, убрать неоднозначное «из N», отделить число результатов от объёма и прогресса | Следующий UI-проход |
| B2, B6: чтения, классификации, значения частей | Расшифровки терминов и дефисов, реальные примеры чтений в словах, пояснение школьной классификации и роли ключа. Не представлять значение знака как перевод части выражения | Высокая учебная ценность |
| B5: повторяющиеся написания с разными чтениями | Пояснить варианты чтения, связывать записи для просмотра. Не сливать ID и не удалять допустимые формы | По мере проверки контента |
| D3, B1: пустая карточка и отсутствие следующего шага | Определить одно основное действие: сохранить для повторения или начать упражнение. Связать с существующим личным словарём через явное правило владения | Отдельное продуктово-архитектурное решение |
| B3: звук и употребление | Проверенные примеры с чтением/переводом и явный тип озвучки. Не заполнять пробел автоматически выдуманными сведениями | Развитие контента |
| U4, B4: общий поиск и материал по силам | Общий поиск и объяснённый выбор начального материала. Точный фильтр JLPT сохранить; накопительный учебный режим вводить отдельно и явно | Следующий этап продукта |

**Приоритеты:** сначала воспроизводимый дефект передачи фильтра. Затем понятные количества, область материала и компактность выбора. После этого — согласованные учебные действия и расширение контента.

Изменения состава карточек, навигации и учебного сценария потребуют актуализации действующих спецификаций, где часть таких функций исключена намеренно. Этот документ предлагает решения, но не объявляет новый дизайн утверждённым и не утверждает, что функции уже реализованы.

Любые новые подписи и пояснения локализуются. Переводимое содержимое хранится отдельно с `language_tag`, русский остаётся основным и резервным языком. Фильтры и идентичность объектов не зависят от текста подписи.
