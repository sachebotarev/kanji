# Android: перенос карточки кандзи CAT-08

## Выполненный участок

Продолжен частичный перенос текущих HTML-макетов. Существующие изменения других компонентов сохранены. Полное соответствие всех экранов каталога не заявляется.

- `KanjiDrawing`: фиксированная квадратная ячейка 188 dp (либо доступная ширина, если она меньше), граница и центральные пунктирные направляющие.
- Отменена подгонка высоты и смещение рисунка по границам черт. Сохранены нормализованные координаты эталона. Текстовый fallback имеет ту же квадратную ячейку.
- В `KanjiDetail` убрана общая подложка знака/значения и классификации; классификация оформлена неинтерактивными метками по ширине текста.
- Удалены постоянная подсказка о чтениях и пустое сообщение о чтениях; заголовки сокращены до «Онъёми»/«Кунъёми».
- Русские и английские ресурсы школьной метки сокращены синхронно.

## Проверки

Успешно выполнены:

- `:feature:catalog:compileDebugKotlin`;
- `:feature:catalog:testDebugUnitTest`;
- `:feature:catalog:compileDebugAndroidTestKotlin`;
- `:feature:catalog:lintDebug`;
- `:feature:catalog:connectedDebugAndroidTest` с ограничением на `KanjiDrawingCellTest`, подключённый Pixel 10 Pro / Android 17.

Новые Compose-тесты проверяют одинаковую квадратную область горизонтального штриха и fallback, а также сохранение квадрата при доступной ширине 140 dp. Полный набор инструментальных тестов не запускался; визуальное совпадение всего приложения со всеми HTML-экранами не проверялось.

Для команд использованы JBR Android Studio через `JAVA_HOME` и локальный SDK через `ANDROID_HOME`; конфигурационные файлы окружения проекта не изменялись.
