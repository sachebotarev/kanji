# Проверка обновлённого макета каталога — 2 ноября 2026

Редакция `2026-11-02-native-sync` синхронизирует HTML-макет с текущей Android-реализацией. Все 17 экранов ожидают явного согласования пользователя: у 13 обновлены основные композиции, подписи или варианты содержимого; у остальных четырёх — общие состояния загрузки и ошибки.

[Интерактивный макет](../../../design-system/prototypes/textbooks/index.html) · [Обзор экранов](../../../design-system/05-screens/catalog/review/index.html) · [Реестр статусов](../../../design-system/05-screens/catalog/review-status.json) · [Снимок макета](overview.png).

## Изменения

Обновлены контекстные количества при выборе главы, независимость фильтров слов от фильтров кандзи, легенды списков, чтения слов, полные названия ключей, подписи классификаций и связанные слова. Повторное название учебника не добавляется там, где контекст уже виден. Данные и локализованные строки выгружены из текущих источников проекта.

Статус отображается вне телефона и в списке экранов. Есть фильтр несогласованных экранов. Единственный источник статусов — `review-status.json`; генератор документации не согласовывает экраны автоматически. Предыдущие снимки в `approved/` сохранены и явно обозначены как архив.

## Очистка

Удалены недоступные старые варианты рендеринга каталога, повторные переопределения подписей, неиспользуемые функции и тексты. Удалён неиспользуемый `prototypes/textbooks/assets/book.png`. Сохранены используемые макеты других разделов, общие ресурсы, лицензии, данные и свидетельства прежних проверок.

Актуализированы README, спецификации экранов, описание реализации, правила согласования и указатели на проверки. Статусы в спецификациях и обзоре генерируются из одного реестра. Повторный запуск генератора не меняет результат.

## Проверка

Проверки содержимого и браузерный сценарий прошли. Использованы Chrome 156.0.8078.80 и Playwright 1.49.1. Открыты все 17 экранов, проверены ширины 360 / 411,43 / 480, масштабы 1 / 1,3 / 1,6, русский и английский интерфейс, русский fallback для неподдерживаемого языка, состояния загрузки, ошибки и пустого поиска. Проверен переход к выбору главы из слов при активном фильтре черт кандзи. Ошибок JavaScript и загрузки ресурсов нет.

[Результат браузерной проверки](validation.json) · [Контрольные суммы исходников](sources.json).

Команды из корня проекта:

```sh
node doc/design-system/prototypes/textbooks/test_content.cjs
NODE_PATH=/tmp/node_modules node doc/design-system/prototypes/textbooks/test_browser.cjs http://127.0.0.1:8766/design-system/prototypes/textbooks/ doc/verification/catalog/prototype-review-2026-11-02
python3 doc/design-system/review_catalog.py
```

Для браузерной проверки нужны установленный Playwright и Chrome; путь `NODE_PATH` относится к окружению этой проверки. Сервер запускается командой `python3 -m http.server 8766 --bind 127.0.0.1 --directory doc`.

Проверка HTML не подтверждает работу Android-клавиатуры, системной кнопки «Назад» или TalkBack. Нативный код в рамках обновления макета не изменялся; его проверки и снимки находятся в [отчёте рефакторинга](../refactor-2026-11-02/README.md). Техническая проверка не заменяет согласование дизайна.
