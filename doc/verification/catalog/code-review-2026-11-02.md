# Ревизия кода каталога

Дата: 2 ноября 2026 года. Область: текущий код `:feature:catalog`, доменные выборки `:domain:catalog`, изменённый `WordEntryCard`, связанные адаптеры загрузки и инструкции проекта. Это ревизия каталога и последних изменений, не всего приложения.

## Исправленные замечания

### 1. Группировка слова могла использовать размещение вне выбранной главы

**Существенность: средняя.** `CatalogSnapshot.wordGroups()` ограничивал первое размещение выбранным кандзи, но не главой и ключом. Если слово связано с кандзи в главах 3 и 4, при выборе главы 4 оно могло оставаться в группе 3. Это также могло менять порядок плоского списка.

Первое размещение теперь выбирается только среди размещений, соответствующих выбранной главе и ключу. Добавлены два доменных регрессионных теста. ID, связи и сами учебные данные не изменялись.

### 2. Тип и значение числового фильтра передавались независимо

**Существенность: средняя, риск рассогласования состояния.** Навигация записывала `resultIsJlpt` и `resultNumeric`, а принимающая сторона наблюдала их отдельными коллекторами и применяла результат по изменению числа. Такая конструкция связывает корректность применения с порядком доставки двух состояний. Факт ошибочного применения на телефоне не заявляется как воспроизведённый.

Для числа черт и JLPT теперь используются независимые ключи результата: каждое изменение несёт однозначный смысл без дополнительного флага. Инструментальный тест проверяет последовательный выбор JLPT и черт, независимый сброс и доступность правильных результатов.

### 3. Выбранная глава отмечалась только оттенком

**Существенность: средняя, доступность.** В `ChapterList` была `selected`-семантика и другая заливка, но отсутствовала видимая отметка.

Добавлена галочка, исключённая из озвучивания. Семантическая выбранность сохранена. Спецификация компонента уточнена.

### 4. TalkBack получал полный набор знаков из превью главы

**Существенность: средняя, доступность.** Превью явно задавало весь набор кандзи как семантический текст. При открытии списка это противоречило контракту карточки, который предусматривает название и объёмы без длинного перечисления знаков.

Превью исключено из семантики. Полный состав остаётся визуально в карточке и доступен отдельными элементами на странице главы. Инструментальный тест проверяет выбранность карточки и отсутствие полного превью в её доступном тексте. Это проверка Compose semantics, не полноценное ручное исследование TalkBack.

### 5. У слова без кандзи оставался пустой раздел состава

**Существенность: низкая.** Подробности слова всегда создавали заголовок «Кандзи в написании», даже если `literalKanji()` возвращал пустой список.

Раздел создаётся только при наличии элементов. Добавлен инструментальный тест для слова, записанного каной.

## Experimental API

Пользователь подтвердил существующее разрешение на experimental-механизм скрываемой панели каталога. Это не считается дефектом и не удалялось.

В `AGENTS.md` и `doc/architecture.md` зафиксировано: каждое новое применение experimental/preview API и соответствующего opt-in требует предварительного явного разрешения пользователя на конкретный API и область. Существующее разрешение перечислено в [реестре](../../decisions/experimental-api.md). Другие experimental API, нестабильные версии библиотек и экспериментальные флаги языка этим разрешением не охватываются.

## Решение по объёмам в выборе главы

`availableChapters()` при фильтрации кандзи показывает число и превью отобранных знаков, но количество слов рассчитывает по отдельной выборке. В результате сочетание «1 кандзи · 118 слов» может смешивать частичный и полный объём.

Предложены два варианта:

1. Полный объём главы, а число совпадений — отдельной подписью. Это рекомендуемый вариант: пользователь видит реальный размер главы и результат текущего отбора.
2. Только отобранные кандзи и связанные с ними слова, с явно обозначенным смыслом этих количеств.

Пользователь выбрал более простое решение: в выборе главы из вкладки «Кандзи» количество слов скрывается. Карточка показывает только число подходящих кандзи и их превью. В обычном списке глав и выборе для слов оба количества сохраняются. Назначение выбора передаётся явным параметром маршрута. Регрессионный тест навигации проверяет оба контекста. Ранее исправленная передача скрытого фильтра черт из вкладки слов сохранена. Описанные выше два варианта изменения объёмов не вводились.

## Проверки

- `:domain:catalog:test`: 21 тест, без ошибок и пропусков.
- `:feature:catalog:testDebugUnitTest`: 4 теста, без ошибок и пропусков.
- `:feature:catalog:connectedDebugAndroidTest`: 8 тестов на Pixel 10 Pro, без ошибок и пропусков. Включены новые проверки числовых фильтров, пустого состава слова и семантики главы.
- `:app:assembleDebug`: успешно.
- `:feature:catalog:lintDebug` и `:core:wordui:lintDebug`: успешно. В каталоге остаются предупреждения lint о `VisibleForTests`, `PluralsCandidate` и `UnusedQuantity`; ошибок нет.
- `git diff --check` по затронутым файлам: без замечаний.
- Обновлённая debug-сборка установлена поверх существующей, данные приложения не очищались.

Полная проверка сохранения процесса, всех комбинаций фильтров, всех экранов других модулей и ручная проверка TalkBack в эту ревизию не входят. Новые пользовательские строки не добавлялись; существующая русская и английская локализация сохранена.
