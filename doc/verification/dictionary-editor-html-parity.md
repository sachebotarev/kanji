# DICT.02 — сверка редактора с утверждённым макетом

## Область

Экран создания записи **DICT.02** приведён к структуре действующего HTML `web/#editor`. Общая форма также используется в **DICT.02.01**; сохранение, черновики и модель переводов не изменены. [Карта компонентов](../project-map.md), [спецификация словаря](../design-system/05-screens/dictionary/README.md).

## Реализация

- Заголовок 60 dp, стрелка назад в области 48 dp, размер текста 22 sp.
- Порядок: написание, чтение, текущий перевод, другие переводы, теги. Отступы формы 18 dp по горизонтали, 12 dp сверху, расстояние между элементами 19 dp, резерв снизу 112 dp.
- Общий `WordEditorTextField`: внешняя подпись, промежуток 8 dp, тонкая рамка, радиус 4 dp и фон экрана. Нативный многострочный `OutlinedTextField` растёт для выражений и полных предложений. Минимум первых полей — стандартные 56 dp; у текущего перевода — 94 dp. HTML-поле написания имеет минимум 54 px; ради этого двухпиксельного отличия нативный ввод не заменён собственной реализацией.
- Строки других переводов и тегов прозрачные, высотой от 64 dp, с шевроном. При отсутствии тегов показано «Пока без тегов» / «No tags yet».
- FAB высотой от 56 dp, радиусом 18 dp, в цветах `primaryContainer/onPrimaryContainer`: плюс и «Добавить в словарь» при создании, галочка и «Сохранить» при изменении.
- Значение текущего перевода по-прежнему не копирует русский fallback. Остальные переводы, включая старые языки, остаются в черновике.

Использованы стабильные API существующего Material3 1.4.0. Возможности `OutlinedTextField`, `OutlinedTextFieldDefaults.colors` проверены через Context7 по официальной документации Android. Версии зависимостей, opt-in и схема БД не менялись.

## Проверки

```sh
./gradlew :app:assembleDebug :feature:dictionary:assembleDebugAndroidTest \
  :core:wordui:lintDebug :feature:dictionary:lintDebug
```

Сборка и lint прошли. Все **32** инструментальных теста словаря прошли на отдельном эмуляторе Android 17 за **92.923 с**. Два новых теста проверяют:

1. Порядок и минимальные размеры элементов в RU/EN, обеих темах, при шрифте 100%/150%.
2. Рост поля для многострочного предложения, сохранение введённого текста и отсутствие подстановки русского перевода в английский ввод.

Существующие проверки тегов, дополнительных переводов, временного выбора и восстановления продолжают проходить. Состояния ошибок и сохранение записей не получили новых бизнес-правил.

## Кадры

[Манифест и SHA-256](dictionary-editor-html-parity/manifest.json):

- `native/create-*.png` — восемь кадров реальной Compose-формы в тестовом хосте, с пустым черновиком в памяти;
- `html/create-*.png` — восемь кадров исходного HTML, без изменения макета;
- [действующее приложение, RU / тёмная / 100%](dictionary-editor-html-parity/native/actual-create-ru-dark-1.0.png) и [UI-дерево](dictionary-editor-html-parity/native/actual-create-ru-dark-1.0.xml).

Проверены полные кадры RU dark 100% и EN light 150%, порядок полей, доступность FAB и навигационных строк. Нативные кадры — 1080×2400; HTML — 412×892. Это сравнение компоновки, а не попиксельный тест: системные панели, нативный ввод, placeholder и масштабирование шрифта платформы могут отличаться. В HTML для 150% задан `--scale: 1.5`; стандартный переключатель прототипа использует 1.35.

Новая матрица ограничена DICT.02. Редактирование DICT.02.01 проверено существующими тестами общей формы и новым многострочным сценарием, но отдельной полной матрицей кадров не объявляется. Это не приёмка остальных экранов словаря, клавиатур всех производителей или ручной работы TalkBack.

Для фактического кадра открыта пустая форма через приложение на эмуляторе; записи не создавались и не сохранялись. База не очищалась. После проверки форма закрыта, временные настройки эмулятора восстановлены. Установка на физический телефон выполняется через `adb install -r`, без удаления пользовательских данных.
