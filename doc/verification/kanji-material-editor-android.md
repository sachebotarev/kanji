# Android: форма материала «По кандзи»

## Реализовано

`feature:dashboard/builder/KanjiMaterialEditorScreen.kt` — композиция формы материала, без репозитория и без пользовательского маршрута конструктора.

- Владелец передаёт полный пул слов каталога и личного словаря, глобальные знаки и связи фактического написания слов с кандзи. Форма не ограничивает результат учебником или личным источником.
- Нейтральная строка с шевроном открывает настоящий `SymbolPickerScreen` с общими поиском, сеткой и переданными фасетами. Apply меняет локальный черновик; Back отменяет черновик селектора.
- Выбранные кандзи объединяются по OR. Пустой выбор означает все слова, включая записи без кандзи. Результат уникален по ID слов; отрицательные ID личных записей поддерживаются.
- Предпросмотр показывает только текущий результат через общий `WordList`; открытие карточки делегируется владельцу. Возврат сохраняет черновик.
- Окончательное подтверждение возвращает материал с прежним ID и выбранными `kanjiIds`, без записи в БД. Нулевой результат блокируется ошибкой у строки выбора. Ошибка имеет Error-обводку и семантику; строка предпросмотра скрыта при пустом результате.
- Back формы не публикует изменения. Состояние формы и открытого селектора сохраняется через `rememberSaveable`.
- RU/EN-ресурсы, русский fallback; превью первых трёх знаков и «Ещё N». Объявлены Compose-превью EN dark и RU с крупным шрифтом.

Форма «Набор слов» использует тот же заголовок, нейтральные строки с шевронами и inset-aware предпросмотр. Расширение `WordNavigationRow` в `core:wordui` добавляет необязательные цвет контейнера и trailing-slot; поведение остальных клиентов по умолчанию сохранено.

## Проверки

Pixel 10 Pro, Android 17, прямой запуск AndroidJUnitRunner:

- `KanjiMaterialEditorTest`: 6 успешных тестов — весь пул и дедупликация, OR/отложенная публикация, отмена двух уровней, пустой результат/пустое ограничение, восстановление двух уровней, callback карточки личного слова.
- `WordMaterialEditorTest`: 5 успешных регрессионных тестов.
- Словарь: 24 теста; каталог: 33 теста, все успешны.
- Успешны сборка приложения и тестовых APK, lint `core:wordui`, `feature:dashboard`, `feature:dictionary`, `feature:catalog`.

## Границы

Формы «По кандзи» и «Набор слов» не подключены к пользовательской навигации. Сборка полного пула из репозитория и реальные маршруты карточек остаются задачей владельца конструктора; тесты используют переданные фикстуры. Также подготовлена [форма учебника](book-material-editor-android.md), без пользовательского маршрута. Подготовлена и [форма личного словаря](dictionary-material-editor-android.md), также без пользовательского маршрута. Переключение типов и список/редактор рецептов ещё не готовы. Визуальная матрица, TalkBack и убийство процесса не проверялись; объявленные превью и StateRestorationTester их не заменяют. БД, миграции Room, исполнение тренировок и статистика не изменялись.
