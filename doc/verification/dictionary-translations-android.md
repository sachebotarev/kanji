# Другие переводы: Android

## Текущее поведение

Основной редактор показывает только явный перевод текущего языка интерфейса (RU/EN) и строку «Другие переводы · N». Fallback используется при просмотре, но не копируется в сохраняемое поле. Число дополнительных языков не увеличивает основной редактор.

Отдельный экран показывает дополнительные переводы общими навигационными строками. Диалог позволяет добавить, изменить или удалить перевод; отмена не меняет черновик. Новые языки пока RU/EN, без ввода кодов; текущий и уже добавленные исключены. Существующие переводы других языков доступны для редактирования и не теряются. Если языки исчерпаны, FAB скрыт. Пустой список использует согласованный маскот с коробкой.

Возврат оставляет изменения в общем `WordDraft`/`SavedStateHandle`. Только сохранение основной записи публикует их в репозитории; выход из изменённого редактора использует существующее подтверждение сохранения/отмены. Поля допускают полные предложения. Команда редактирования личной карточки перенесена в FAB; прокрутка общей карточки резервирует 112 dp под него.

## Проверено

```sh
./gradlew :app:assembleDebug :feature:dictionary:connectedDebugAndroidTest \
  :feature:dictionary:lintDebug :core:wordui:lintDebug
```

Успешно на Pixel 10 Pro / Android 17: 11 инструментальных тестов словаря, 0 ошибок; сборка и lint успешны. Три новых теста: добавление только по подтверждению и скрытие исчерпанного FAB; редактирование/удаление старого языка и отмена диалога; отсутствие копирования fallback и компактный основной редактор с девятью дополнительными языками. Регрессия включает пять тестов тегов и три проверки локализации карточки. Для повторного открытия диалога тест вызывает семантическое действие, чтобы не зависеть от анимации закрытия IME.

Не заявляется полный визуальный прогон всех тем/размеров шрифта, проверка TalkBack или системное уничтожение процесса. Конструктор рецептов и остальные общие селекторы остаются следующими частями Android-реализации. Тренировки/статистика и миграции Room не добавлялись.
