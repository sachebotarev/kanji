## Выполнено

- Все 28 вариантов открыты в обеих темах: 56 снимков. Роли фона и Primary совпадают с общей конфигурацией в обоих просмотрщиках.
- Изменение Primary на экране темы обновляет главную и каталог в других вкладках и сохраняется после перезагрузки. Сброс возвращает текущую исходную палитру.
- Некорректный HEX отклоняется, слабый контраст показывается предупреждением, конфигурация выгружается как JSON. Статусы не меняются.
- Проверены настройки: ошибка японской модели и повтор, переключатель проверки и ввод числового параметра.
- Узкая ширина 360, увеличенный текст, английский интерфейс и русский fallback каталога не дают горизонтального переполнения в проверенных состояниях.
- Регрессионные сценарии конструктора и всех 17 экранов каталога выполняются отдельно; отчёты сохранены рядом. Пустые/ошибочные/загрузочные состояния и переводы каталога входят в регрессионную проверку.

## Воспроизведение

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory doc
npm ci --prefix doc/design-system/theme --ignore-scripts
npm run build --prefix doc/design-system/theme
node doc/design-system/theme/test_viewer.cjs
node doc/design-system/theme/test_shell.cjs
```

Нужны Playwright и Chrome; если пакет установлен вне проекта, указать `NODE_PATH`. Чистая проверка содержимого каталога: `node doc/design-system/prototypes/textbooks/test_content.cjs`.

Снимки просмотрены визуально для главной, конструктора, каталога, карточек и настроек. Автоматический обход всех маршрутов не является пользовательским согласованием или полным аудитом доступности. Нативные IME, TalkBack, системный Back и lifecycle не проверялись; они относятся к этапу Android-реализации.
