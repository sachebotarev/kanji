# Android: форма материала «Из личного словаря»

## Реализовано

`feature:dashboard/builder/DictionaryMaterialEditorScreen.kt` — локальная форма материала `Dictionary`. Принимает `CatalogSnapshot`, общие теги и назначения тегов словам, язык и callbacks. Не обращается к репозиторию и не сохраняет рецепт.

- Личный источник разрешается по фактическому `sourceType = personal`; выбора другого словаря нет. При отсутствии единственного личного источника подтверждение блокируется. Учебные слова не заимствуются по совпадению написания или тегов. `CatalogSnapshot` из `RoomCatalogRepository.readSnapshot` включает активный personal-источник и его `source_words`: иначе форма материала всегда видит «Личный словарь недоступен», даже когда в «Мой словарь» есть слова.
- `TagPickerScreen` и `TagPickerHeader` вынесены в `core:wordui` из интерфейса словаря. Их использует и существующий `DictionaryTagsRoute`, и новая форма. В словаре сохранены собственные ViewModel, CRUD и модальные редакторы: зависимости feature → feature не добавлены.
- Общий выбор тегов поддерживает поиск названия с NFKC/регистром и русским fallback, скрытые отметки, просмотр выбранных, снятие выбора, Apply/Back. Меню управления общими тегами передаёт событие владельцу формы. Вложенный Apply изменяет только локальный набор ID, не фильтр списка словаря.
- Теги объединяются по OR. Кандзи — OR, а с тегами пересекаются по AND. Пустые наборы не ограничивают слова, включая записи без кандзи. Повторы ID исключает доменный запрос.
- Пул настоящего `SymbolPickerScreen` состоит из буквальных кандзи личных слов, прошедших теги, а не из учебных связей или глобального справочника. Доступны общие поиск и фасеты. Применение тегов исключает несовместимые выбранные кандзи.
- Общий предпросмотр `WordList` учитывает оба ограничения; открытие карточки слова делегируется владельцу. Возврат сохраняет черновик. Нулевой результат блокируется ошибкой, Error-обводкой и доступной семантикой; пустой предпросмотр скрыт.
- Окончательное подтверждение возвращает материал с прежним ID, фактическим `sourceId`, `tagIds`, `kanjiIds`. Названия тегов не сохраняются в условиях. Back формы ничего не публикует. Удалённые общие теги исключаются из возвращаемых ID.
- Состояние формы и открытого выбора сохраняется через `rememberSaveable`. Пользовательские строки RU/EN вынесены в ресурсы; объявлены превью RU с крупным шрифтом и EN dark.

## Проверки

Pixel 10 Pro, Android 17, прямой AndroidJUnitRunner:

- **26 тестов форм**: 8 новых `DictionaryMaterialEditorTest` и 18 регрессий учебника/кандзи/слов;
- **24 теста словаря**, включая существующие сценарии временных тегов, приватных черновиков, переводов и общих селекторов после выделения общего UI;
- **33 теста каталога**.

Новые проверки: личный источник без заимствований; дедупликация, записи без кандзи и callback карточки; OR тегов/кандзи и AND между ними без учебных связей; ограничение символов тегами и очистка несовместимого выбора; отмена селекторов/формы; NFKC-поиск с сохранением скрытого выбора и восстановлением; событие управления тегами без публикации материала; блокировка пустого диапазона и очистка; удаление общих тегов без висячих ID; отсутствие личного источника.

Успешны `:app:assembleDebug`, сборки test APK и lint модулей `core:wordui`, `feature:dashboard`, `feature:dictionary`. LSP не видит часть сгенерированных ресурсов/проектных зависимостей рабочего пространства; фактическая Gradle-компиляция успешна.

## Границы

Все четыре формы материала подготовлены, но не подключены к пользовательской навигации конструктора. Владелец должен загрузить и наблюдать snapshot/теги/назначения, подключить глобальное управление тегами, маршрут карточки слова и публикацию материала в черновик рецепта. Сейчас проверено событие управления, а не переход в реальный экран управления из конструктора. Переключение типов, список и редактор рецептов остаются незавершёнными. Наличие отдельных форм не означает готовый конструктор.

Превью не подтверждают полную визуальную матрицу; TalkBack и убийство процесса не проверялись. Схема БД, миграции Room, исполнение тренировок и статистика не изменялись.
