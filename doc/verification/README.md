# Техническая верификация

В этом разделе собраны отчёты, тестовые прогоны и артефакты верификации ключевых подсистем приложения. Материалы сохраняются для контроля регрессий и воспроизводимости результатов.

## Проверка рукописного ввода

- [Алгоритм проверки формы](handwriting/shape-checker.md) — базовые принципы и этапы валидации штрихов.
- [Алгоритм Procrustes](handwriting/procrustes.md) — нормализация, оценка геометрического подобия и бюджет трансформаций.
- [Профиль параметров распознавания](handwriting/settings.md) — фиксация рабочих порогов (73% / 5% / 27%) и точности ползунков.
- [Контекст распознавания (Readability)](handwriting/readability.md) — проверка читаемости через ML Kit Digital Ink.
- [Объединение трёх проверок](handwriting/three-checkers.md) — итоговый консенсус: форма, читаемость и словарные правила.

Сырые числовые данные, тестовые скрипты и таблицы прогонов находятся в разделе [Калибровка](../calibration/README.md).
