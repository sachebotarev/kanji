# SCR-KANJI-PRACTICE — Практика кандзи

Актуальная компоновка: [рабочий экран v9](../implementation/practice-workspace.md). Статусы ячеек и все направляющие поля сохранены; подробности чекеров открываются нажатием на индикаторы над полем.

Версия 1.1. Визуальное направление и поведение экрана. Экран одного слова реализован; подключён локальный анализатор общей формы. Контракты и технические границы: [реализация](../implementation/practice-screen.md). Постоянная ссылка для других экранов: [SCR-KANJI-PRACTICE](kanji-practice.md).

<a id="purpose"></a>
## Назначение и вход

Пользователь видит русское значение одного слова и записывает требуемые японские знаки. Часть знаков может быть подставлена заранее. Экран принимает `PracticeTask` и выдаёт `PracticeResult`; состав полей описан в [контракте](../implementation/practice-screen.md). Лимит на всё слово опционален, по умолчанию отсутствует.

Управление группой из N слов, прогрессом и переходами принадлежит вызывающему компоненту. Повторяющиеся знаки имеют отдельные идентификаторы позиций. Новая попытка начинается с первой требующей ввода ячейки, пустой историей и нулевым временем. ViewModel сохраняет состояние при смене конфигурации; постоянное восстановление после закрытия/уничтожения процесса — отдельная будущая задача.

<a id="input"></a>
## Ввод и проверка

Нажатие на доступную ячейку выбирает её и восстанавливает её штрихи в поле. Автоматического переключения после правильного знака пока нет: пользователь выбирает следующий сам. Предзаполненные ячейки не нажимаются. Прокрутка ряда не меняет выбор.

Каждый завершённый жест добавляет штрих. Изменение содержимого сбрасывает старый результат проверки; пустая ячейка становится пустой, непустая — редактируемой. Проверка присваивает «Верно» или «Неверно» текущей версии штрихов. Устаревший ответ проверки после редактирования игнорируется. Во время ввода отдельный индикатор проверки не появляется, геометрия строки постоянна.

**Текущая реализация:** автоматическая локальная проверка после паузы 350 мс. Требуется точное количество штрихов и достаточное совпадение общей формы; порядок штрихов не учитывается.

<a id="tools"></a>
## Подсказка и история

Алгоритм подсказки передаётся отдельно. Текущая стратегия — включаемый кнопкой бледный фон для обводки под пользовательскими штрихами. Кнопка является переключателем: повторное нажатие скрывает фон; активная заливка обозначает включённый режим. Рисование, отмена, очистка и проверка доступны. Переход к другой ячейке скрывает фон, факт использования сохраняется. Подробности: [сменные алгоритмы](../implementation/hints.md).

Отмена откатывает штрих или очистку выбранной ячейки. Подсказка не добавляется в историю. Ни отмена, ни очистка не снимают факт её использования. Подсказка сама по себе не выполняет знак.

<a id="completion"></a>
## Завершение слова и переходы

Слово выполнено, когда каждая требующая ввода ячейка подтверждена анализатором; эталоны предзаполненных ячеек должны быть доступны. «Далее» выдаёт результат текущего задания. Повторное редактирование, нарушившее условие, снова отключает завершение. Пока слово не выполнено, «Далее» недоступна. Кнопки «Проверить» нет; ошибочные и правильные знаки отмечаются по результатам автоматической проверки. Сообщение о недоступности проверки закреплено над нижними кнопками вне прокрутки. Вводное объяснение вынесено в будущий туториал.

«Пропустить» выдаёт результат `Skipped` с текущими статусами и штрихами. При истечении заданного лимита выдаётся `TimedOut`. Самостоятельное выполнение (`Correct`) отличается от выполнения с подсказкой (`Assisted`). Результат фиксируется один раз; следующие слова и итоговый экран группы выбирает host. Демо-host показывает краткий итог одного слова.

<a id="progress-time"></a>
## Прогресс и время

Если host показывает группу: «Слово i из N» — позиция в группе. Осталось = N минус число выполненных или пропущенных слов; текущее незавершённое включено в остаток. Например, на четвёртом из десяти после трёх пройденных осталось 7; после выполнения четвёртого — 6.

Таймер измеряет время всего слова с момента показа, включая размышление и исправления. Он приостанавливается в фоне и при уходе с экрана, останавливается при выполнении или пропуске. Если выполненное слово снова изменено и стало незавершённым, таймер продолжается с сохранённого значения, завершённость пересчитывается. По умолчанию ограничения нет. При заданном лимите справа показано оставшееся время; истечение завершает задание. Время каждой ячейки суммируется, пока она выбрана, включая размышление и исправления; у предзаполненных знаков оно равно нулю. Назад возвращает управление host и не является пропуском; постоянное сохранение тренировки пока не подключено.

<a id="invariants"></a>
## Требования для реализации

- Поле ввода одинаково во всех состояниях на одном размере экрана.
- Каждая доступная кнопка имеет область нажатия не менее 48 × 48.
- Отдельные истории ячеек не теряются при переключении и прокрутке.
- Подсказка не выдаётся за самостоятельный правильный ответ.
- Цвет не является единственным способом узнать результат выбранного знака.
- Задание из одних предзаполненных знаков считается уже выполненным; генератор тренировок должен избегать таких заданий.
- Адаптация к очень длинному русскому тексту, маленькой высоте и крупному системному шрифту требует дополнительных макетов. Эталон не является готовым решением этих случаев.

## Уточнения после аудита

Верхняя часть уплотнена: блок слова минимум 64 dp, декоративный 漢 убран; короткий ряд ячеек выровнен слева с полем. Отступ перед строкой состояния сокращён. Строка состояния допускает рост по высоте, таймер виден только при лимите (учёт времени сохраняется). После правильного знака появляется стрелка «Следующий знак», выбирающая следующую незавершённую ячейку с возвратом к началу ряда при необходимости; самопроизвольного переключения нет.

Пока штрихов меньше эталона, анализатор возвращает `Incomplete`: в строке состояния «Ещё не закончен», без красной ошибки и дублирующего сообщения снизу. При превышении количества — `Incorrect`; принятие требует точного количества. Подсказка расположена слева от инструментов, отмена/очистка справа; очистка без тональной заливки. Диагонали сетки ослаблены, мару/бацу сохранены. Debug-панель в рамках этой итерации не переработана по решению пользователя. Изменения не уменьшают поле рисования.

Для проверки адаптации подключено демо «Электроэнцефалография» (脳波検査) с лимитом 5 минут. Блок рисования закреплён снизу; верхняя часть при нехватке места прокручивается независимо. В очень коротких окнах доступна прокрутка всего экрана. Debug-подробности перенесены из нижней панели в отдельное окно `{}`, которое в закрытом виде не влияет на компоновку.

## Настройка анализатора

Из верхней панели доступен [экран параметров проверки](checker-settings.md). Он регулирует все пределы и бюджет, включает отдельные компенсации, структурную проверку и независимые правила порядка/направления. Изменения повторно проверяют текущие рисунки без потери истории. Согласованные правила — [здесь](../decisions/handwriting-verification.md).
