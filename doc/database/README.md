# Структура базы данных и модели (Database)

В этой директории описаны схемы реляционных таблиц SQLite/Room, модели сущностей и правила связей между ними.

Действующая Android-база — Room 1: каталог, личные записи, теги, рецепты и исполнение тренировок имеют entities/DAO; репозитории рецептов и тренировок транзакционные. Compose-интерфейсы тегов и конструктора подключены к репозиторию рецептов; host PRACTICE пишет прогресс тренировки через `TrainingsRepository` (старт / граница задания / interrupt / complete, без записи на каждый штрих). Релиз 1.0.0 использует исходную схему 1. Последующие изменения требуют явных миграций с сохранением данных; разрушительная замена запрещена. [Контракт реализации](../implementation/approved-ui-handoff.md), [проверки Android-хранилища](../releases/1.0.0.md). Фактическая Room-схема проверяется инструментальными тестами хранилища.

- [Слова, выражения и предложения](words.md) — структура таблицы `words`, переводы `words_translations`, примечания `usage_note` и правила многоязычности.
- [Личный словарь («Мой словарь»)](personal-dictionary.md) — пользовательские слова, теги (`dictionary_tags`), их переводы (`dictionary_tags_translations`) и связи (`word_tags`).
- [Кандзи и чтения](kanji.md) — реестр иероглифов, онные/кунные чтения и группы значений.
- [Ключи (радикалы)](radicals.md) — 214 традиционных ключей Кангси, альтернативные формы и переводы.
- [Конструктор рецептов](recipes.md) — рецепты (`recipes`), локализованные названия (`recipes_translations`), материалы (`recipe_materials`), множественные фильтры глав/кандзи/слов/тегов. [SQL-схема](recipes.sql).
- [Тренировки](trainings.md) — исполнение: `trainings`, задания `training_tasks`, символы `training_task_symbols`, снимки переводов, возобновление и рукописный JSON. [SQL-схема](trainings.sql). Room 1 / `TrainingsRepository`.
