# Структура базы данных и модели (Database)

В этой директории описаны схемы реляционных таблиц SQLite/Room, модели сущностей и правила связей между ними.

Действующая Android-база — Room v7: каталог, личные записи, теги, рецепты и исполнение тренировок имеют entities/DAO; репозитории рецептов и тренировок транзакционные. Compose-интерфейсы тегов и конструктора подключены к репозиторию рецептов; host PRACTICE пишет прогресс тренировки через `TrainingsRepository` (старт / граница задания / interrupt / complete, без записи на каждый штрих). Миграций нет: по решению пользователя невыпущенная база пересоздаётся при несовместимой версии, каталог устанавливается повторно. Пользовательские данные старой базы не сохраняются. [Контракт реализации](../implementation/approved-ui-handoff.md), [проверки Android-хранилища](../verification/recipes-storage-android.md). `python3 doc/database/test_builder_schema.py` проверяет SQL-контракт рецептов на основе v4; фактическая Room-схема проверяется инструментальными тестами.

- [Слова, выражения и предложения](words.md) — структура таблицы `words`, переводы `words_translations`, примечания `usage_note` и правила многоязычности.
- [Личный словарь («Мой словарь»)](personal-dictionary.md) — пользовательские слова, теги (`dictionary_tags`), их переводы (`dictionary_tags_translations`) и связи (`word_tags`).
- [Кандзи и чтения](kanji.md) — реестр иероглифов, онные/кунные чтения и группы значений.

- [Конструктор рецептов](recipes.md) — рецепты (`recipes`), локализованные названия (`recipes_translations`), материалы (`recipe_materials`), множественные фильтры глав/кандзи/слов/тегов. [SQL-схема](recipes.sql).
