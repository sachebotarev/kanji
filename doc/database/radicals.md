# Таблицы `radicals` и `radicals_translations`

Статус: проект модели данных. Дата: 20 октября 2026 года.

Назначение: справочник 214 традиционных ключей Канси. Источник первоначального заполнения — [`radicals.csv`](../../data/catalog/radicals.csv). Одна строка соответствует одному ключу.

Названия таблицы и полей — на английском, в `snake_case`. Типы указаны для SQLite, используемой Room.

| Field | SQL type | Constraints | CSV column | Описание |
| --- | --- | --- | --- | --- |
| `id` | `INTEGER` | `PRIMARY KEY`, `NOT NULL`, `CHECK (id BETWEEN 1 AND 214)` | `Номер` | Традиционный номер ключа Канси; задаётся из CSV, без автоматической генерации. |
| `symbol` | `TEXT` | `NOT NULL`, `UNIQUE`, `CHECK (length(symbol) = 1)` | `Ключ` | Символ полной традиционной формы ключа. |
| `stroke_count` | `INTEGER` | `NOT NULL`, `CHECK (stroke_count BETWEEN 1 AND 17)` | `Количество черт` | Количество черт полной формы, хранящейся в `symbol`. |

**Первичный ключ: `id`.** Он совпадает с традиционным номером Канси и не зависит от порядка строк CSV. Будущие связи с таблицей кандзи должны ссылаться на `radicals.id`.

Пример записи:

| id | symbol | stroke_count |
| --- | --- | --- |
| 1 | 一 | 1 |

## Таблица `radicals_translations`

Название следует общему правилу: полное имя основной таблицы + `_translations`.

Хранит названия ключей на разных языках. Одна строка — название одного ключа на одном языке.

| Field | SQL type | Constraints | Описание |
| --- | --- | --- | --- |
| `radical_id` | `INTEGER` | `NOT NULL`, `FOREIGN KEY REFERENCES radicals(id)` | Номер ключа Канси. |
| `language_tag` | `TEXT` | `NOT NULL`, `CHECK (length(trim(language)) > 0)` | Языковой тег, например `ru`, `en`, `ja`; при необходимости — `pt-BR` или `zh-Hant`. |
| `name` | `TEXT` | `NOT NULL`, `CHECK (length(trim(name)) > 0)` | Название ключа на указанном языке. |

**Составной первичный ключ: (`radical_id`, `language_tag`).** Для одного ключа допускается одно название на каждом языке. Связь с `radicals` — многие к одному.

| radical_id | language_tag | name |
| --- | --- | --- |
| 1 | ru | Единица |
| 1 | en | One |

При импорте столбец CSV `Название` записывается в `name` с `language = 'ru'`, а `Номер` — в `radical_id`. Добавление языка не требует изменения схемы. Значения `language_tag` хранятся в едином согласованном формате; строки с вариантами регистра одного тега не должны создавать разные переводы.

## Правила данных

- Все поля обеих таблиц обязательны; отсутствующий перевод означает отсутствие строки для данного языка.
- При первоначальном заполнении импортируются все 214 записей с сохранением номеров из CSV.
- Сокращённые и позиционные варианты, например `亻` и `氵`, в эту таблицу отдельными записями не входят.
- Русские названия переносятся из CSV; их академическая сверка пока не завершена.
- Модель описывает будущую таблицу; создание БД и методы доступа выполняются отдельным этапом.
