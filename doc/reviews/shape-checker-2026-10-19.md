# Аудит проверки кандзи — 19 октября 2026 года

Основание: [согласованные требования](../decisions/handwriting-verification.md). Область: передача геометрии, ограничения и бюджет, смысловые детали, настройки и проверка соответствия практикам сопоставления форм.

## Проверенные принципы

- Компенсации готовят геометрию до оценивания; отдельные классы, constructor DI, чистый Kotlin/JVM.
- Растровая проверка симметрична: учитывает лишние и отсутствующие участки, не нормализует рисунки независимо после компенсаций.
- Пределы, бюджет, количество черт, структура и опциональные порядок/направление — независимые условия принятия.
- Принятый допустимый вариант имеет приоритет перед более похожим запрещённым вариантом.
- Выбранная геометрия возвращается для реального красного debug-слоя, а не вычисляется повторно в UI.

## Исправления по результатам аудита

1. Общий viewport всех перебираемых вариантов позволял крайнему отклоняемому варианту менять разрешение остальных сравнений. Теперь базовый эталон готовится один раз; при необходимости расширение viewport выполняется только для **текущей пары**. Линии по-прежнему сравниваются в общей системе координат, без скрытых независимых преобразований.
2. Общий процент мог скрывать различие небольших значимых выступов. Добавлена независимая проверка исходных отношений черт. По уточнению пользователя обязательные смысловые отношения перенесены в простой адресный словарь, а не применяются универсально ко всем знакам: пересечение/окончание для 牛/午, относительные длины для 未/末 и 土/士. Компенсации концов и дрожания не могут отменить исходную структурную ошибку.
3. Для независимых порядка/направления добавлено взаимно однозначное геометрическое сопоставление черт. По умолчанию эти правила выключены; ошибки выдаются отдельно.
4. Настройки читаются единым снимком на запрос. Изменение параметров инвалидирует старые результаты и ревизии, включая ранее принятые рисунки.

## Инженерная калибровка

`ShapeCalibrationTest` использует локальный KanjiVG через настоящий Android-загрузчик. Набор: точные эталоны, умеренные переносы, масштаб −5%, повороты ±3°, shear ±3°; отрицательные пары 土/士, 未/末, 日/曰, 人/入, 人/八, 大/丈, 牛/午, 木/不, 王/玉, 大/太, 口/囗, 刀/力 в обоих направлениях. Варианты за пределами поля не объявляются корректными и пропускаются. Проверяются допуски расстояния 2.5%, 3.5% и 4.5%; порог и бюджет анализируются совместно.

Результаты сохраняются построчно в test logcat для воспроизводимого анализа. Синтетические варианты не являются реальным почерком. Статистика этого набора не переносится на всех пользователей и знаки. Исходный профиль 80% допускал путаницу 未/末. По инженерному прогону выбран предварительный профиль 95% покрытия, 3.5% расстояния и бюджет 15%. Бюджет 10% оказался чрезмерно строгим для части умеренных глобальных искажений. Полный текущий результат и исходные записи находятся в [калибровке](../calibration/README.md).

## Исследовательские основания и границы

[Shape Contexts](https://people.eecs.berkeley.edu/~malik/papers/BMP-shape.pdf) сочетает соответствия, ошибку сопоставления и стоимость преобразования; [CPD](https://arxiv.org/abs/0905.2635) ограничивает деформации регуляризацией; [$P](https://depts.washington.edu/acelab/proj/dollar/pdollar.html) демонстрирует геометрическое сопоставление многотактных жестов. Применение этих принципов в проекте — инженерная адаптация, не воспроизведение перечисленных алгоритмов и не подтверждение точности для обучения кандзи.

Остаются ограничения: разрешение 128×128, приближённое поле расстояний, ограниченный поиск угла, эвристика shear, чувствительность к выбросам, нет полного графа каллиграфических отношений и размеченной выборки реального почерка. Соответствие исследовательским принципам не означает достаточности одного общего процента для любого знака.

## Крючки и отключение хвостов

Обнаружен принципиальный риск: маленький крючок может потеряться при очистке или остаться необязательным для общего процента. Сохранение неочищенного кандидата не гарантирует его обязательности. По этому результату хвосты выключены в стартовом профиле, пока не готовы отдельный обязательный признак и reference-aware защита удаления. Риск не объявляется устранённым; зафиксирован в [договорённостях](../decisions/handwriting-verification.md#обязательные-крючки-и-безопасность-хвостов).
