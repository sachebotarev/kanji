# Инженерный подбор параметров — 19 октября 2026 года

Цель: выбрать стартовые параметры и выявить явную путаницу похожих кандзи. Это **не оценка точности на реальном почерке** и не доказательство оптимальности порогов.

## Набор и воспроизведение

Используется `ShapeCalibrationTest` на Pixel 10 Pro (Android 17), настоящий `BundledKanjiReferenceSource` и локальные KanjiVG. Исходные SVG не копируются в новый набор. Тест берёт фактический стартовый профиль `RecognitionSettingsViewModel`, затем формирует детерминированные рисунки.

22 знака, 14 вариантов для каждого: исходный эталон, сдвиг (+1.5%, −1% поля), единый размер ±5%, независимые размеры X/Y ±5%, повороты ±3°, shear ±3°, дрожание амплитудой 0.25% размера, короткий хвост 1% размера. Синтетические точки за пределами поля не зажимаются: такой вариант пропускается и это должно отражаться в числе записей.

24 отрицательных примера — обе стороны пар 土/士, 未/末, 日/曰, 人/入, 人/八, 大/丈, 牛/午, 木/不, 王/玉, 大/太, 口/囗, 刀/力. Некоторые пары дополнительно различаются числом черт; это учитывается отдельным обязательным условием, а не выдаётся за успех одной геометрии.

Результаты: [машиночитаемый файл](synthetic-2026-10-19.json), одна запись на сравнение. В нём указаны профиль, целевой знак, класс/вид искажения, покрытие, бюджет, ошибки этапов/словаря, число черт и фактическое решение. `ShapeCalibrationSummary` в test logcat содержит ожидаемое число записей для проверки полноты выгрузки. Логирование идёт по мере расчёта, чтобы не терять большой пакет сообщений в конце.

Команда:

```sh
./gradlew :app:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=ru.mobui.kanji.ShapeCalibrationTest
```

## Выбранный стартовый профиль

| Параметр | Значение |
|---|---:|
| Минимальное двустороннее покрытие | 95% |
| Допуск расстояния | 3.5% большей стороны эталона |
| Общий бюджет | 15% геометрического вмешательства |
| Сдвиг | 10% поля по любой оси |
| Общий размер | 30% изменения |
| Растяжение X/Y | по 15% |
| Вращение | 7° |
| Shear | 5° |
| Дрожание | 0.5% размера |
| Хвосты | **выключены**, сохранённый допуск 2.5% |
| Словарь | включён |
| Соединение / значимый выступ / разница длин | 5% / 3% / 5% |
| Порядок / направление | выключены / выключены |

Обоснование: исходный порог 80% позволял принимать 未 вместо 末 и наоборот. Более строгий порог при допуске 3.5% отсекает эту путаницу в инженерном прогоне; дополнительно различие закреплено обязательными словарными правилами. Первоначальный бюджет 10% отклонял часть умеренных масштабирований/поворотов; 15% выбран как предварительный компромисс с сохранением индивидуальных пределов. Ограничение shear уточнено: использовать длинные почти прямые черты, не короткие участки диагоналей/кривых.

Отключение хвостов связано с отдельным риском обязательных крючков. Сохранённый допуск не означает, что этап включён. Проверка обязательности крючка и reference-aware защита его обрезки пока не реализованы.

## Результат

Окончательный прогон содержит **332 записи**, число совпадает с `ShapeCalibrationSummary`. Принято **307 из 308** допустимых синтетических вариантов. Принято неправильных пар: **0 из 24**. Все 22 точных эталона приняты.

Хвосты в этом прогоне выключены. Остался один известный ложный отказ: 囗, повёрнутый на −3°, расход бюджета около 20.8 при пределе 15. Предел не ослаблен ради одного примера; случай сохранён для дальнейшего улучшения оценки преобразований. Нулевая ошибка на отрицательных примерах не переносится на все кандзи и почерк людей.

## Ограничения

- Искажения детерминированны и получены из самого эталона, а не из независимых рисунков людей.
- Набор мал, не покрывает все знаки, формы крючков и стили письма.
- Нулевое число ложных принятий здесь не доказывает отсутствие ложных принятий в приложении.
- Порог и набор использовались для инженерного подбора; это не отдельная контрольная выборка.
- Для продуктивной калибровки нужны размеченные правильные/ошибочные рисунки разных людей и отдельные контрольные пользователи.
