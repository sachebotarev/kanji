# Калибровка проверки рукописного ввода

В этом разделе описаны рабочие параметры алгоритма проверки формы кандзи, методика калибровки и сохранённые наборы данных для воспроизводимости.

## Актуальный рабочий профиль

Для проверки геометрической формы кандзи используется алгоритм **Procrustes** с предварительной нормализацией и компенсацией искажений.

Текущие параметры калибровки зафиксированы в `RecognitionSettings`:

| Параметр | Значение | Шаг настройки | Назначение |
|---|---:|---:|---|
| **Минимальное сходство** | 73% | 1% | Порог геометрического подобия контуров черт |
| **Допуск расстояния** | 5% | 1% | Максимальное среднее расстояние между сопоставленными точками |
| **Суммарный бюджет** | 27% | 1% | Лимит на общее геометрическое вмешательство (0 = без общего лимита) |
| **Сдвиг (перенос)** | 12% | 1% | Допустимое смещение знака по горизонтали/вертикали |
| **Масштаб (размер)** | 30% | 1% | Допустимое общее изменение размера относительно эталона |
| **Растяжение по осям X / Y** | по 15% | 1% | Независимое неизотропное масштабирование по осям |
| **Вращение** | 8° | 1° | Допустимый угол наклона знака |
| **Скос (Shear)** | 8° | 1° | Допустимый перекос параллелограмма |
| **Дрожание руки** | 0.5% | 0.1% | Сглаживание микроколебаний штриха |
| **Словарные правила** | Включены | — | Проверка ключевых геометрических признаков (соединение 5%, выступ 3%, разница длин 5%) |
| **Валидация крючков** | Включена | — | Обязательная проверка наличия крючка по метаданным KanjiVG |
| **Порядок черт** | Игнорируется | — | Позволяет писать штрихи в произвольном порядке |
| **Направление черт** | Игнорируется | — | Не штрафует за проведение линии в обратную сторону |

> Указанный профиль обеспечивает принятие **83.33%** (4 753 из 5 704) корректных знаков в эталонном корпусе рукописных траекторий Tomoe при **0%** ложных принятий похожих знаков (土/士, 未/末, 日/曰, 人/入 и др.).

## Методика калибровки

Калибровка выполняется на трёх независимых источниках данных:

1. **Корпус Tomoe:** более 6 500 рукописных записей кандзи, записанных разными людьми. Используется для оценки процента распознавания живого рукописного ввода.
2. **Синтетические искажения:** детерминированные геометрические трансформации эталонных векторов KanjiVG (сдвиги, масштабирование, повороты, shear, добавление шума). Позволяет точно изолировать влияние каждого параметра.
3. **Реальные пользовательские образцы:** контрольные образцы написания на физических устройствах (Pixel 10 Pro) со сложными знаками и отрицательными примерами (сетки, случайные штрихи).

## Ограничения

- Корпус Tomoe отражает оцифрованные траектории планшетного ввода и служит регрессионным ориентиром; он не заменяет сбор статистики на живой аудитории мобильного приложения.
- Нулевой уровень ошибок на тестовых парах похожих знаков снижает риск путаницы, но не гарантирует полного отсутствия ложных срабатываний на редких или экзотических стилях написания.
- Дальнейшая тонкая настройка параметров опирается на пользовательские образцы в разделе [user-examples/](user-examples/).
