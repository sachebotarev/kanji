# Словарные источники для подготовки контента

Исходные словари хранятся в `doc/dictionaries/local/` для подготовки контента приложения и ручной сверки. Весь каталог исключён из Git и не входит в Android assets. Дистрибутив ЯРКСИ удалён; программа не устанавливалась и не запускалась.

| Источник | Файл относительно этой папки | Формат и версия | Назначение |
| --- | --- | --- | --- |
| KANJIDIC2 | `local/kanjidic2/kanjidic2.xml` | XML UTF-8, 2026-293, 20 октября 2026 года | Чтения, ключи, число черт, категории и варианты; русских значений в снимке нет |
| WARODAI | `local/warodai/warodai.txt` | Текст UTF-8 с разметкой статей и идентификаторами, 1 июля 2026 года | Русские значения слов и проверка употребления; не полный словарь значений отдельных кандзи |
| ЯРКСИ | `local/yarxi/yarxice.db` | Оригинальная двоичная база версии Mac/Linux 1.15, 1 ноября 2021 года | Сохранённые словарные данные; готового парсера в проекте нет |
| Фельдман-Конрад | `local/feldman-konrad/source.pdf` | Предоставленный пользователем скан 2-го издания, 1977, 682 страницы | Академический источник; раздел специальных названий ключей распознан и проверен отдельно |

`local/sources.json` фиксирует URL, версии, размеры и SHA-256. Исходные данные сохраняются отдельно от редактируемых CSV приложения.

## Распознанный раздел Фельдман-Конрад

[Локальный просмотрщик](local/feldman-konrad/keys-reader.html) объединяет проверенную таблицу 107 ключей, сканы печатных страниц 14–17 (PDF 16–19) и черновой OCR. Рядом сохранены `special-key-names.csv`, `keys-ocr.txt`, `ocr-quality.json` и `source-metadata.json`. OCR выполнен локальным Tesseract с русской и японской моделями, без отправки документа внешним сервисам. Полный текст всех 682 страниц пока не распознан.

В списке 84 русских пояснения. Они сохранены для ручного изучения и не используются как утверждённые названия ключей в приложении. Все 28 изменений `radicals.csv` по этому разделу отменены. Архив попытки сверки сохранён только локально: `local/feldman-konrad/rejected-radicals-verification.json`.

## Доступность данных ЯРКСИ

Из официального образа извлечён только словарный файл `yarxice.db`, без установки программы. Расширение `.db` не означает SQLite: стандартный SQLite-парсер не распознаёт этот формат. Файл нельзя считать готовым к SQL-запросам или импорту. Он также не является актуальным снимком онлайн-словаря. Для чтения доступны [онлайн-версия](https://yarxi.ru/online/) и [указатель кандзи проекта](yarxi-index.html).

## Условия использования

- **KANJIDIC2:** [EDRDG / Jim Breen](https://www.edrdg.org/wiki/KANJIDIC_Project.html), [CC BY-SA 4.0 и условия EDRDG](https://www.edrdg.org/edrdg/licence.html). Производные данные требуют атрибуции и соблюдения лицензии. Из этого источника получены справочные поля текущего CSV.
- **WARODAI:** [условия проекта](https://www.warodai.ru/about/) — CC BY-NC-ND 3.0. Не считать их общим разрешением включать переработанный корпус статей в распространяемый контент приложения. Пока используется для проверки значений.
- **ЯРКСИ:** [сайт автора](https://yarxi.ru/) и [источник локальной версии](https://yarxi.ru/mac_linux.html). Свободная лицензия на переработку и распространение базы не установлена. Массовый импорт и распространение базы с приложением не реализованы.

Для новых учебных записей следует фиксировать источник, собственную редакцию значения и состояние проверки. Условия исходных материалов учитываются до переноса их текста в распространяемый набор. Локальное хранение источника и его распространение с приложением — отдельные операции.

## Проверки хранения

```sh
git check-ignore -v doc/dictionaries/local/sources.json
git check-ignore -v doc/dictionaries/local/yarxi/yarxice.db
git ls-files doc/dictionaries/local
```

Последняя команда должна вернуть пустой список. Не использовать `git add -f` для этих материалов. Android assets подключены только к `data/catalog/`; исходные базы и установщики в APK отсутствуют.
