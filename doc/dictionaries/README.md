# Справочные материалы и словари (Dictionaries)

В этой директории собраны внешние и локальные справочные данные, индексы эталонов и утилиты валидации.

- [Локальные справочные материалы](local-reference-materials.md) — источники данных (KanjiVG, ЯРКСИ, EDICT/JMdict), правила локального хранения и лицензии.
- `catalog-sources.json` — реестр учебных источников и метаданных.
- `kanjivg-coverage.json` — карта покрытия кандзи векторными эталонами KanjiVG.
- `kanji-verification.json` — контрольные наборы данных для верификации иероглифов.
- `validate_catalog.py` — проверочный скрипт целостности данных каталога.
