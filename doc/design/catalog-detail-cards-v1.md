# Карточки каталога: слово, кандзи, ключ

20 октября 2026 года. Визуальный концепт для обсуждения: [три карточки](catalog-detail-cards-v1.png). Данные источника и привязки на макете иллюстративные.

- Слово: написание, полное чтение, локализованный перевод, уникальные известные кандзи, буквально входящие в написание, и отдельно учебные связи в источниках. Части чтения показывать только при наличии проверенных `word_reading_parts`. Слова, выражения и предложения переносятся на несколько строк; фиксированный размер гигантского заголовка из концепта не применяется к длинным записям.
- Кандзи: знак, значения, количество черт, принадлежность к спискам, онъёми/кунъёми, основной словарный ключ и переходы к связанным словам. Списки слов длинные: в карточке только предпросмотр и переход к отдельному списку с поиском. Учебная связь не доказывает буквального вхождения знака в слово.
- Ключ: символ, локализованное название, номер Канси, количество черт и прокручиваемая сетка кандзи, у которых он является основным словарным ключом. Поиск по знаку/чтению/значению. Варианты ключей отдельными сущностями не становятся.

Все экраны только для просмотра. Навигация между карточками не изменяет данные. Тексты — ресурсы/таблицы переводов, запрошенный язык с русским fallback. Системные подписи и интерфейс также переводятся на английский при реализации.

Содержимое длиннее экрана прокручивается; возвращение сохраняет позицию исходного списка. Для пустого списка и отсутствия русского перевода требуется явное локализованное состояние.
