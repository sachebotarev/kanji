# Стикеры кота-маскота — учёба и отдых

21 октября 2026. Третий набор: восемь отдельных PNG с прозрачным фоном, созданных встроенным `image_gen` в стиле первых двух наборов. По уточнению пользователя кисть есть только на одном стикере — с каллиграфией.

| Ресурс | Сюжет |
| --- | --- |
| `mascot_sticker_read_book` | Читает книгу |
| `mascot_sticker_library` | Выбирает книгу в библиотеке |
| `mascot_sticker_calligraphy` | Старательно пишет кандзи кистью |
| `mascot_sticker_magnify` | Рассматривает знак через лупу |
| `mascot_sticker_lightning` | Боится молнии |
| `mascot_sticker_gaming` | Играет на портативной консоли |
| `mascot_sticker_flashcards` | Повторяет учебные карточки |
| `mascot_sticker_sleep_book` | Засыпает над учебником |

В иллюстрациях сохранены светлый кот, зелёная ученическая шапка с красной полосой и золотой кокардой, тёмно-зелёный контур и общий стиль. Иллюстрации не содержат интерфейсных подписей. Учебные знаки 一, 三 и 山 не переводятся, это изображённый учебный материал. В консоли используются узнаваемые цвета контроллеров без логотипа и текста.

Все файлы доступны через `ru.mobui.kanji.core.designsystem.R.drawable.mascot_sticker_*` из `core/designsystem/src/main/res/drawable-nodpi/`. Исходники сохранены здесь. [Промпты](prompts.json), [технические сведения](manifest.json).

При использовании декоративные стикеры получают `contentDescription = null`, смысловые — локализованные описания; русский остаётся основным языком и fallback.
