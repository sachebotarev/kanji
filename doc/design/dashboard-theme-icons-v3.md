# Иконки для двух тем

20 октября 2026. Пользователь согласовал макет dashboard-theme-icons-v3.png и запуск реализации.

- Светлая шестерёнка сохранена.
- Ночные PNG используют единственный шалфейный контур вместо тёмного; внешняя светлая кайма не добавляется.
- Стрелки имеют прямой стержень и цельную заливку: зелёную днём, светлую ночью. Один PNG используется для старта и повёрнутого раскрытия.
- История — более вертикальный свиток с часами.
- Пламя — приглушённые терракота и золото.
- Размеры: настройки 30 dp, строки 34 dp, раскрытие 20 dp, старт 44 dp. Оптическая компенсация учитывает прозрачные поля исходников.
- Варианты подбираются Android через drawable-night-nodpi. Данные, навигация и контракты виджетов сохранены.

Исходники и промпты: dashboard-icons/theme-v2/.
