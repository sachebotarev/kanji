# Единое рабочее поле v7

19 октября 2026. Статус: предложение на рассмотрении. Код по этому макету не изменять до согласования.

Пользователь попросил кардинально изменить интерфейс без потери функций: верхние кандзи и нижние инструменты выглядели как множество одинаковых кнопок. Цвет должен остаться строгим, индикаторы — компактными, с подписью над значением; нажатие открывает подробности в диалоге с названием проверки, без слова «Отчёт».

Предложенная иерархия:

1. Компактная тёмная индиго-шапка: назад, практика, настройки и дополнительное меню (включая debug в соответствующей сборке).
2. Контекст задания: русское слово, опциональный таймер и свободный ряд выбора кандзи без карточек; активный знак подчёркнут. Для длинных слов/многих знаков потребуется адаптивная компоновка без уменьшения области ввода.
3. Главное рабочее поле: квадратный холст с общей пристыкованной панелью подсказки, отмены и очистки. Инструменты — элементы единой панели, а не разрозненные кнопки.
4. Компактная область результатов под холстом: общий блок «Проверки», три колонки без индивидуальных рамок/заливок, цветные значения. Каждая проверка нажимаема, подробности — в диалоге. «Подробнее» на макете — дополнительное указание доступности деталей, не замена выбора конкретного чекера; точное поведение уточняется при согласовании.
5. Нижняя область команд: тихое действие «Пропустить» и единственное основное «Далее»; отдельной стрелки следующего кандзи нет.

Зелёный/бордовый оставлены за результатами. Основная палитра — слоновая кость, тёмный индиго и приглушённая бирюза. На иллюстрации слово «Япония» и 日/本 — демонстрационное содержимое, не замена задания приложения. Показанный таймер не добавляет лимит заданию, у которого его нет. Подсказки, история, ревизии и алгоритмы проверок не меняются.

Изображение: practice-workspace-v7.png. Создано встроенным imagegen.

Промпт: радикально новый строгий русский Android UI изучения кандзи, два экрана — рабочее поле и диалог проверки черт. Светлый тёплый фон, индиго-шапка с навигацией и настройками. Компактный заголовок «Япония», свободные 日 本 с подчёркиванием выбранного, таймер. Один квадратный рукописный холст 日, общая присоединённая панель «Подсказка», «Отменить», «Очистить» с понятными иконками. Под ним единая зона «Проверки»: три компактные колонки «Читаемость»/«日», «Форма»/«92%», «Черты»/«4», без отдельных карточек и значков статуса. Зелёные успехи, бордовая ошибка. Внизу «Пропустить» текстом и основная «Далее», неактивная при ошибке. Справа диалог «Черты»: количество4из4, порядок нарушен, направление верное, пояснение о перестановке2и3, кнопка «Понятно». Никаких иллюстраций, градиентов, радуги или слова «Отчёт». Сохранить все функции в чёткой иерархии общего рабочего инструмента.
