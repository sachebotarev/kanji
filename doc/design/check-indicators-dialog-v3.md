# Нажимаемые индикаторы и отчёт v3

19 октября 2026. Статус: предложение для согласования, не реализация.

Пользователь предложил открывать подробный отчёт нажатием на индикатор и отклонил однострочное расположение подписи/значения. Возвращены две строки внутри компактного блока: подпись сверху, значение снизу. Планируемый размер блока около 48–52dp, отступ до поля около 20dp, touch target не менее 48dp. Подробные ошибки не выводятся под блоками: только в диалоге выбранной проверки.

На макете check-indicators-dialog-v3.png слева показан экран, справа диалог чекера черт: количество 4 из 4, порядок нарушен, направление верное; подробность — черты 2 и 3 написаны в обратном порядке. Для читаемости предполагается показывать заданный и распознанный знаки, для формы — соответствие и причины непринятия. Нельзя показывать «Верно» для проверки, которая фактически не выполнялась.

Создано встроенным imagegen. Промпт: два одинаковых портретных Android-экрана практики кандзи на русском, один обычный, другой затемнённый под Material-диалогом. Тёплый белый фон, зелёные успешные/красные ошибочные значения. Над полем три компактные нажимаемые карточки 48–52dp: подписи «Читаемость», «Форма», «Черты» сверху, значения «日», «92%», «4» снизу; первые две зелёные, третья красная. Отступ до поля20dp, никаких галочек, кружков и дополнительной строки ошибок. Диалог «Отчёт: черты», строки «Количество — 4 из 4», «Порядок — Нарушен», «Направление — Верное», пояснение «Черты 2 и 3 написаны в обратном порядке.», кнопка «Понятно». Сохранить доминирование поля ввода, аккуратную типографику и отсутствие аппаратной рамки телефона.
