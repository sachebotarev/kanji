# Каталог — варианты интерфейса

Дата обсуждения: 20 октября 2026 года.

Сравнение трёх вариантов просмотра одного источника Basic Kanji Book:

1. По главам: глава → кандзи → связанные слова.
2. Все слова: уникальные записи, поиск по написанию, чтению и переводу; фильтры по главе и кандзи.
3. Два представления: вкладки «По главам» и «Все слова», первая открывается по умолчанию.

Общий вход: «Каталог» → список источников Tobira и Basic Kanji Book → выбранный источник. Тома не выделяются в отдельные источники. Каталог предназначен только для просмотра: поиск, фильтры и переходы без изменения данных и пользовательских отметок.

Модель: ../database/words.md. Числа и примеры в визуальном концепте иллюстративные, не результат запроса БД. Длинные выражения и предложения должны поддерживаться наравне со словами. Русский — язык подстановки при отсутствии перевода.

Предварительная рекомендация — вариант 3. Это концепт для обсуждения, реализация не начата.
