# Стикеры кота-маскота — набор 1

21 октября 2026. Восемь отдельных иллюстраций для интерфейса, созданных встроенным `image_gen` по утверждённому персонажу [из иконки](../launcher-icon-cat-v2-source.png).

| Ресурс Android | Поза и эмоция | Возможное применение |
| --- | --- | --- |
| `mascot_sticker_wave` | Приветствие, взмах лапой | Вход и знакомство |
| `mascot_sticker_celebrate` | Радость, победный прыжок | Завершение и успех |
| `mascot_sticker_think` | Задумчивость | Размышление, подсказка |
| `mascot_sticker_surprised` | Удивление | Открытие нового |
| `mascot_sticker_encourage` | Спокойная поддержка | Повторная попытка |
| `mascot_sticker_sad` | Лёгкое огорчение | Неудачная попытка |
| `mascot_sticker_rest` | Сон, отдых | Перерыв |
| `mascot_sticker_confident` | Уверенность, подмигивание | Готовность начать |

Каждая иллюстрация — отдельный PNG с прозрачным фоном в `core/designsystem/src/main/res/drawable-nodpi/`, доступна через `ru.mobui.kanji.core.designsystem.R.drawable.mascot_sticker_*`. Исходники также сохранены здесь отдельно. Нет надписей или встроенных переводимых текстов. При использовании декоративный стикер получает `contentDescription = null`; смысловой — локализованное описание на языке интерфейса с русским fallback. Размещение на конкретных экранах в этот набор не входит.

Во всех вариантах сохраняются светлый кот, зелёная ученическая шапка с красной полосой и золотой кокардой, тёмно-зелёный контур и хвост-крючок. Фон отсутствует, поэтому стикеры работают в обеих темах. Полные промпты сохраняются рядом в `prompts.json`.
