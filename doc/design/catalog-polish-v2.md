# Каталог: спокойный дизайн и адаптивная панель

20 октября 2026 года. Уточнения по обратной связи пользователя.

## Визуальная иерархия

- Названия учебников увеличены до 25sp/30sp, контрастнее метаданных; у карточки одна область нажатия и один слой внутренних отступов. Существующая иллюстрация книжки связывает экран с главной.
- Маскот представлен редким узором лапок на фоне с прозрачностью 4,5%, разными поворотами и смещением рядов. В заголовке лапки нет: там она воспринималась как кнопка. Непрозрачные карточки защищают текст от фонового узора.
- Все карточки используют зелёную `surface` палитру приложения вместо не переопределённой фиолетовой `surfaceContainer` Material. Тонкие контуры и скругления, без теней и градиентов.
- У вкладок есть нижний индикатор и semantic selected state. Поиск — спокойное поле с placeholder; главы имеют раздельные заголовок, статистику и предпросмотр знаков. Японское написание слов заметнее чтения и перевода.
- Сетки адаптивные, значения ограничены двумя строками с многоточием, полные значения остаются в карточке/semantics. Длинные названия источников переносятся, не обрезаются.

## Прокрутка

Верхняя панель использует стабильный Compose `NestedScrollConnection`: движение по списку вперёд сначала скрывает заголовок, затем вкладки, поиск и фильтры, отдавая освободившуюся высоту списку. Обратное движение сразу возвращает панель. Никаких experimental TopAppBar API или opt-in.

Состояние скрытия сохраняется для каждого destination; высоты измеряются по фактическому содержимому, без фиксированных предположений о языке или масштабе шрифта. Карточки с длинным содержимым также прокручиваются, системная кнопка «Назад» работает при скрытой панели.

## Согласованные фильтры

Ключи для выбора вычисляются из кандзи текущего учебника/главы. Выбор ключа ограничивает доступные главы; при выборе кандзи для слов также учитываются текущие ограничения. Фасета игнорирует собственное выбранное значение, но учитывает остальные — можно менять значение, не сбрасывая всю форму. Поисковый запрос применяется к уже доступным вариантам. Полный справочник ключей остаётся отдельным справочником из 214 записей.
