# Карта экранов и виджетов проекта

Каноническая карта для обсуждения правок. Например: **«измени DICT.W03.W02»** или **«измени общий UI-FILTER»**. ID не зависят от языка интерфейса, положения элемента и пользовательских данных.

## Как читать и поддерживать карту

- ID организованы по фичам: `HOME`, `BOOKS`, `REFS`, `DICT`, `RECIPE`, `SHARED`, `SELECT`, `PRACTICE`, `SETTINGS`. Например, `BOOKS.01` — учебник, `BOOKS.01.03` — глава; `RECIPE.01.02` — материал. Канонические ID совпадают с [реестром HTML](design-system/theme/screens.json). [Таблица прежних ID](screen-id-migration.md) сохраняет совместимость обсуждений и ссылок.
- `.W01`, `.W02`… — уникальный экземпляр смыслового виджета на данном экране. Вложенные ID обозначают его части. Заголовки, надписи и кнопки описаны внутри соответствующего виджета; технические `Spacer`/`Box` не являются отдельными пользовательскими виджетами.
- Повторяемые данные: `DICT.W05.W01[word_id=123]`, `RECIPE.W04.W01[recipe_id=…]`; ключ — реальный ID записи, не позиция в списке. Суффикс данных — адрес экземпляра, не новый ID типа.
- `UI-…` — общий компонент/явно помеченное семейство; ниже перечислены все его размещения в карте. **Правка экземпляра** локальна только при изменении параметров/адаптера; **правка реализации общего компонента** влияет на остальные его применения и транзитивных потребителей.
- `.D01`, `.D02`… — диалоги внутри фичи или экрана (`DICT.04.D01` — создание тега). Дополнительные/архивные экраны отмечены описанием; `LEGACY` отделён от текущего UI. Контексты источников и режимы создания/редактирования не означают копии общего компонента.
- После согласованных миграций 2026-11-05 и 2026-11-06 (`TRAIN`→`RECIPE`) ID постоянны: не перенумеровывать при перестановке; новые элементы получают свободный ID. Старые префиксы виджетов переводятся по таблице экранов. Список/секция → карточка/строка → части; list-level действия (ещё, undo, FAB, статус) остаются на уровне секции. Эталон: `BOOKS.W03.W01`, `DICT.W05.W01`. При удалении сохранять запись в разделе «Выведенные ID», при разделении — старый ID с указателем на новые.
- При изменении UI обновлять иерархию, описание, источник и список повторных применений **в том же изменении**. Сходство внешнего вида не доказывает общую реализацию. Карта не заменяет спецификации и не объявляет макет реализованным.
- Структурная проверка: `python3 doc/verification/check-project-map.py` — уникальность ID, родители, охват реестра экранов и локальные ссылки. Проверка не доказывает полноту визуальных состояний или соответствие макету.
- BOOKS/REFS/DICT сопоставлены с HTML в RU/EN, двух темах и при шрифте 100%/150%; [кадры, 67 регрессионных тестов и границы](verification/roots-html-parity.md). Это проверка трёх корней, не всех вложенных экранов. Настройки не менять по ошибочному HTML-значку.

## Устройство проекта

- `app` — сборка DI и переходы между feature; [AppDestinations.kt](../app/src/main/java/ru/mobui/kanji/AppDestinations.kt).
- `feature/dashboard` — главная и конструктор; `feature/catalog` — учебники/справочники; `feature/dictionary` — личный словарь; `feature/practice` — существующий тренировочный прототип/проверка; `feature/settings` — настройки.
- `core/wordui` — общие слова, выборы, сетки и чипы; `core/designsystem` — тема/изображения; `core/writingpad` — рисование.
- `domain/catalog`, `domain/practice`, `domain/handwriting` — бизнес-модели/контракты; `data/catalogdb`, `data/settings`, `data/kanjivg` — данные. Полные границы: [архитектура](architecture.md).
- Конструктор сохраняет рецепты; исполнение тренировок, `HOME.W02`/`HOME.W03` и следы тренировок `HOME.02`/`HOME.02.01` подключены. Приоритет: функциональность, затем визуальная доводка.

## Иерархия экранов

## Главная · HOME

### HOME — Главная

Маршрут макета: `#home/HOME`. Статус: **согласовано 2026-11-07**. Android: запуск и рецепты тренировок разделены; `HOME.01` / `HOME.D03` подключены.

- **`HOME.W01` — Панель заголовка.** Стикер настроек `art_settings` (шестерёнка с ушками), как в HTML.
  - **`HOME.W01.W01` — Название главной.** 
  - **`HOME.W01.W02` — Настройки.** Открывает SETTINGS (сам SETTINGS не согласован).
- **`HOME.W02` — Статистика слов.** Кольцо за сегодня: зелёный — верно, жёлтый — с подсказкой, красный — пропуск или таймаут; подпись «слова дня». Тап → `HOME.02` с фильтром «Сегодня». Данные из `TrainingsRepository`. Общий: `UI-DASH-CARD`.
- **`HOME.W03` — Активность.** Календарь за шесть недель: яркость клетки — число завершённых заданий (`correct`/`assisted`/`skipped`/`timed_out`) за день; сверху streak и мотивационная фраза. Тап → `HOME.02`. Данные из `TrainingsRepository`. Общий: `UI-DASH-CARD`.
- **`HOME.W06` — Запуск / продолжение тренировки.** Выбранный макет: диалог при незавершённой. Общий: `UI-START-TRAINING`.
  - **`HOME.W06.W01` — Призыв.** Без `in_progress`: «Ня! Начнём?» / «Начать тренировку» → HOME.01. С незавершённой: та же кнопка → HOME.D03.
  - **`HOME.W06.W02` — Маскот.** Декоративный; скрыт при крупном тексте.
  - **`HOME.W06.W03` — Предупреждение.** Контрастная строка под призывом: «Незавершённая тренировка» / «Unfinished training». Детали — в HOME.D03.
- **`HOME.W07` — Рецепты тренировок.** Отдельный вход в список RECIPE; не запускает тренировку. Общий: `UI-HOME-ENTRY`.
- **`HOME.W05` — Учебные материалы.** VocabularyWidget.
  - **`HOME.W05.W01` — Учебники.** Книжная иллюстрация; BOOKS. Общий: `UI-HOME-ART`.
  - **`HOME.W05.W02` — Справочники.** Тушечница; REFS. Общий: `UI-HOME-ART`.
  - **`HOME.W05.W03` — Мой словарь.** Блокнот; DICT. Общий: `UI-HOME-ART`.

#### HOME.01 — Выбор рецепта

Маршрут макета: `#home/HOME.01` (`training-pick`). Открывается из: `HOME.W06`. Android: `TrainingPickScreen` / корневой route `TrainingPick`. Статус: **согласовано 2026-11-07**.

- **`HOME.01.W01` — Панель заголовка.** Название «Выбор рецепта» и возврат на HOME.
- **`HOME.01.W02` — Поиск.** Как в RECIPE.W02. Общий: `UI-SEARCH`.
- **`HOME.01.W03` — Список рецептов.** Тап по карточке выбирает рецепт и открывает PRACTICE. Если у рецепта нет слов с записываемыми кандзи — диалог без запуска. Без радиокнопки, без перестановки и без шевронов перехода.
  - **`HOME.01.W03.W01` — Карточка рецепта.** Название рецепта и сводка (число слов/время).
    - **`HOME.01.W03.W01.W01` — Штамп мастера.** Красный японский штамп кошачьей лапки справа при наличии тренировки на «Отлично» для текущей ревизии рецепта; сбрасывается при изменении рецепта.
- **`HOME.01.W04` — Пустой список.** Как обычный empty-state: маскот по центру, заголовок и пояснение, CTA «Создать первый рецепт» → RECIPE.01. После сохранения рецепта — сразу PRACTICE (без списка RECIPE). «Назад» из редактора → HOME.01; с HOME.01 → HOME.

#### HOME.02 — Следы тренировок

Маршрут: `TrainingHistory(period)` / макет `#training-history`. Открывается из: `HOME.W02` (период «Сегодня»), `HOME.W03` (все). Статус: **Android**. Спека: [training-history.md](design-system/05-screens/home/training-history.md). Источник: `TrainingsRepository.observeHistory` / `deleteTraining`.

- **`HOME.02.W01` — Поиск.** Лупа; по названию рецепта. Общий: `UI-SEARCH`.
- **`HOME.02.W02` — Фильтр дат.** Чип периода с шевроном вниз: Сегодня / 7 дней / 30 дней / Все. Общий: `UI-FILTER` (`SelectionFilterChip`).
- **`HOME.02.W03` — Список по дням.** Секции с заголовком даты.
  - **`HOME.02.W03.W01` — Карточка тренировки.** Мини-кольцо как W02, название рецепта, время/длительность или «Незавершённая · слово N из M», справа — красный штамп-лапка при «Отлично». Включает `in_progress`. Тап → HOME.02.01; свайп EndToStart → HOME.02.D01.
- **`HOME.02.W04` — Пустой / нет совпадений.** Маскот и пояснение.

##### HOME.02.D01 — Удалить тренировку

Открывается из: `HOME.02.W03.W01` (свайп карточки или a11y «Удалить»). Подтверждение удаления записи истории; учебные материалы не трогаются.

- **`HOME.02.D01.W01` — Отмена.** 
- **`HOME.02.D01.W02` — Удалить.** Деструктивное действие.

#### HOME.02.01 — Подробности тренировки

Маршрут: вложенный `HistoryDetail` / макет `#training-history-detail`. Открывается из: `HOME.02.W03.W01`. Статус: **Android**.

- **`HOME.02.01.W01` — Сводка.** Дата, длительность, мини-кольцо и счётчики слов.
- **`HOME.02.01.W02` — Список слов.** Написание, чтение, перевод, статус и время на слово.
- **`HOME.02.01.W03` — Штамп-лапка «Отлично».** Красный японский штамп (инкан) при результате `TrainingGradeLevel.Excellent` в заголовке списка слов.

#### HOME.D03 — Выбор при незавершённой тренировке

Открывается из: `HOME.W06` при `in_progress`. Макет HTML — черновик. Заголовок: «Продолжить или начать новую?» / «Continue or start new?».

- **`HOME.D03.W01` — Контекст.** Название рецепта и прогресс.
- **`HOME.D03.W02` — Продолжить.** Primary; открывает PRACTICE (resume).
- **`HOME.D03.W03` — Начать новую.** Secondary (не danger); прерывает `in_progress`, открывает HOME.01.
